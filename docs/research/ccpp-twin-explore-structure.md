# 탐색: LLM은 "그쪽에 꺾임이 있는가"를 아는가 (2026-11-12)

상태: **탐색(사후)**. 판정 아님. 새 seed `explore_struct1`. 9,720행.

코드: `analysis/ccpp_twin/explore/structure_judgment.py`. 산출물: `analysis/ccpp_twin/runs/explore_structure/{cells.csv.gz,summary.txt}`.

읽은 답: 아홉 모델의 본 수집, 전략 단계, 새 세계 단계. 새 네 모델의 이 답들은 [확인 실험 §11](ccpp-twin-outside-confirmation.md)에서 이미 채점했다. 따라서 여기의 "새 모델" 수치도 확인이 아니다. **새 발전소 단계(`runs/cleanworld/`) 답은 읽지 않았다.**

## 1. 질문

[앞 탐색](ccpp-twin-explore-robust-bound.md)은 위치 없이 "외삽 쪽에 꺾임이 있다"는 판단만 맞으면 정답 진술과 같은 이득이 난다고 보였다. 그러면 LLM의 그 판단은 얼마나 맞는가. 그 판단만 쓰는 규칙은 지금 규칙보다 나은가.

## 2. 방법

모델, 설명 수준, 세계, 쪽(아래/위)마다:

- `pS0`: 직접 질문 답 중 그쪽에 경계를 둔 비율.
- `pS2`: 분해 질문 답 중 그쪽에 작용하는 장치가 있다고 한 비율.
- 판단 네 가지: `S0`(pS0 > 0.5), `S2`(pS2 > 0.5), `AND`, `OR`.

정답은 일곱 세계 × 두 쪽 = 14개 중 참 6개, 거짓 8개. `gen_hot`은 평평 언어에서 꺾임 없음으로 센다.

규칙(위치는 LLM에서 받지 않는다):

- 판단이 "있다"면 "창 끝부터 평평, 혼합 0.5". 아니면 `R0`.
- `CONF`: 혼합 비율을 0.5 × min(pS0, pS2)로.

## 3. 결과 1: 판단 정확도

| 묶음 | 판단 | 맞게 "있다" (TPR) | 틀리게 "있다" (FPR) |
|---|---|---|---|
| 기존 다섯 모델 | `S0` | 0.72 | 0.38 |
| | `S2` | 0.98 | 0.61 |
| | `AND` | 0.70 | 0.24 |
| | `OR` | 1.00 | 0.75 |
| 새 네 모델 | `S0` | 0.69 | 0.47 |
| | `S2` | 0.94 | 0.66 |
| | `AND` | 0.65 | 0.30 |
| | `OR` | 0.98 | 0.83 |

- 장치가 있을 때 "있다"고 하는 것은 잘한다. 문제는 없을 때도 "있다"고 하는 것이다.
- 가장 엄격한 `AND`도 잘못된 긍정이 0.24–0.30이다. L2 설명에서는 0.18–0.19로 준다.
- 장치가 없는 `base` 세계에서 "고온 쪽에 경계가 있다"는 답의 비율: 직접 질문 0.67–0.90, 분해 질문 0.60–0.82. 설명에 "흡기 조절 장치 없음, 발전기 제한에 닿지 않음"이라고 적혀 있는데도 그렇다.

과제별 같은 무게 평균. 상대 RMSE는 규칙 / `R0`.

|---|---|---|---|---|---|
| 기존 | `HA_fb_gt` | 6.53 | 2.25 | 4.39 | 10 / 10 |

- 판단만 쓰는 규칙은 꺾임 과제에서 고정 규칙보다 훨씬 낫다(0.62–0.74 대 0.80–0.87). 꺾임 없는 과제에서 그만큼 잃는다.
- MW로 합치면 고정 규칙과 거의 같다(기존 4.25–4.31 대 4.39, 새 모델 4.58–5.10 대 4.72). 순이득이 없다.
- 해 비율은 0.18–0.37로 등록 기준 0.10을 크게 넘는다. 기준을 넘지 않은 칸은 규칙별 18칸 중 1–5칸이다.
- 확신도에 맞춘 혼합(`CONF`)은 최악을 조금 줄이지만 결론을 바꾸지 못한다.

## 5. 해석

1. **LLM은 꺾임 유무를 가려내지 못한다.** 있다고 말하는 쪽으로 치우쳐 있다. 이득을 내는 답과 해를 내는 답이 같은 성향에서 나온다.
2. **지금까지의 고정 규칙이 안전했던 이유는 엄격해서 거의 침묵했기 때문이다.** 침묵을 풀면 이득과 해가 함께 온다. 2026-11-04의 첫 관찰(거짓 경보가 위험, 창 밖 주장은 검사 불가)과 같은 결론이다.
3. **조립 규칙을 더 다듬어도 이 교환은 사라지지 않는다.** 정보가 창 밖에 있고 LLM의 판단 정확도가 그대로인 한 그렇다. 바뀔 수 있는 것은 LLM에 주는 정보(설명의 구체성)와 모델이다. L2에서 잘못된 긍정이 준 것이 그 방향의 약한 증거다.
4. **쌍둥이의 `base` 세계가 현실과 다를 수 있다.** 실제 CCPP는 27°C 위에서 기울기가 −2.06에서 −0.81로 줄어든다([실제 자료 기록](ccpp-real-data.md)). LLM이 "고온 쪽은 약해진다"고 답하는 성향은 실제 발전소에는 맞고, 장치 없는 쌍둥이 세계에는 틀린다. 쌍둥이의 꺾임 없는 고온 과제가 LLM에게 불리한 반사실일 가능성이 있다. 확인하지 않았다.
