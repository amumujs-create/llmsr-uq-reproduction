## 현재 판단

**관련 연구 목록과 후보는 확보했으나, 가장 가까운 선행연구와 비교해 구체적인 추가 기여를 충분히 뒷받침한 추천 주제는 아직 제시하지 못했다.** 이전의 “박사 연구로 진행할 가치가 있다”는 넓은 방향의 의견을 개별 후보의 신규성 검증처럼 표현한 것은 성급했다. [논문 기여 검토 기준](publication-assessment.md)은 달성한 결과가 아니라 조건부 기준이다.

현재 유지되는 목표는 제한된 관측의 외삽을 외부 물리 지식으로 개선하고 시뮬레이션부터 평가하는 것이다. 개별 알고리즘과 논문 주제는 미확정이다.

**LLM + 물리 지식 + 신경망**, **조건별 gating**, **적응 가중치**, **잔차 보정**, **불확실한 식의 유지**는 가까운 선행연구가 있다. 같은 구성요소가 있다는 사실과 우리가 주장할 기여까지 이미 해결됐다는 사실도 구별해야 한다.

검증할 후보는 다음과 같다.

> 목표 영역의 정답 없이, 문헌에서 물리 관계와 적용 조건을 함께 추출하고 관측 입력·공정 정보와 대조할 때, 같은 물리 지식을 전 영역에 적용하는 방법보다 외삽 예측을 개선하고 부적절한 지식의 피해를 줄일 수 있는가?

핵심은 식의 생성 능력보다 **어떤 근거로 그 식을 현재 조건에 적용하는가**이다. 이것이 독창적 기여인지, 단순한 기존 방법의 자동화인지는 아직 미확정이다.

## 문제 범위

| 구분 | 내용 | 이번 연구의 위치 |
|---|---|---|
| A. 핵심 입력 누락 | 학습과 추론에 필요한 변수가 관측되지 않음 | 주 연구 범위에서 제외 |
| B1. 관측 가능한 조건의 외삽 | 입력은 관측되지만 학습 범위 밖의 관계를 데이터만으로 식별하기 어려움. 문헌 조건을 입력 또는 이용 가능한 메타데이터로 확인 가능 | 우선 연구 대상 |
| B2. 숨은 상태에 따른 변화 | 같은 관측 입력·메타데이터에서도 미관측 상태에 따라 결과가 다름 | 식별 불가능성을 드러내는 대조 조건 |

B1에서도 전이 임계값·물성치가 소스 데이터에 의해 식별된다는 보장은 없다. 외부 근거로 알 수 없는 값은 추정 가능하다고 가정하지 않고 범위나 미확인 항목으로 보존한다.

여기서 “물리법칙이 바뀐다”는 표현은 대개 **지배 메커니즘, 유효 근사식, 구성 관계의 적용 영역이 달라짐**을 뜻한다. 기본 보존법칙 자체가 운전 조건에 따라 임의로 바뀐다는 주장이 아니다.

## 정보가 부족하다는 말의 의미

표본 수가 적음, 학습 범위가 좁음, 노이즈가 큼, 입력이 누락됨은 서로 다른 문제다. 따라서 “데이터가 부족할수록 좋다”라는 한 축으로 실험하지 않는다. 행렬의 낮은 rank도 곧바로 낮은 운전 범위 coverage를 의미하지 않는다.

예를 들어 학습 구간이 x ≤ 1일 때 아래 두 함수는 그 구간에서 같다.

```text
f_A(x) = x
f_B(x) = x - k * max(x - 1, 0)^3,  k > 0
```

x > 1에서는 다르지만 소스 표본을 무한히 늘려도 두 함수를 구별할 수 없다. 같은 소스 자료와 같은 외부 정보만 주어진 예측기는 두 세계에서 같은 판단을 한다. 두 값 사이 차이를 Δ라 하면, 최소한 한 세계에서 점 예측의 절대오차는 Δ/2 이상이다. 이 예는 본 문서의 설명용 구성이다.

따라서 LLM은 없는 관측값을 만들어내는 장치가 아니라 **외부 지식이라는 추가 정보원**으로 다룬다. “우리에게 외삽이지만 LLM에게 내삽”이라는 직관은 유용한 출발점이지만, 실제로 해당 물리를 알고 적용할 수 있는지는 실험해야 한다.

## 기여 후보와 아직 주장할 수 없는 것

기여 후보:

1. 식·가정·적용 조건·상수 범위·출처·미확인 항목을 함께 표현하는 지식 추출 절차.
2. 적용 조건의 확인 가능성과 불확실성을 반영하는 물리 지식 전달 방법.
3. 표본 수와 범위, 노이즈, 관계식 오류와 조건 오류를 분리한 평가.
4. 같은 정보를 받은 단순 방법 및 강한 선행방법과의 공정한 비교.
5. 시뮬레이션에서 효과와 실패 경계를 먼저 검증하고, 확보 가능한 실제 제조 데이터로 현장 타당성을 추가 평가하는 증거.

아직 주장할 수 없는 것:

- LLM이 알려지지 않은 영역의 참 법칙을 일반적으로 알아낸다.
- 학습 오차가 작으면 목표 영역에서도 물리식이 맞는다.
- 물리 제약을 끄면 데이터 신경망이 안전하게 외삽한다.
- 적용 조건을 붙이면 조건 자체의 오류도 해결된다.
- 여러 LLM의 동의나 좁은 후보 분산이 물리적 진실성을 보증한다.
- 목표 영역에서 데이터 모델보다 항상 나빠지지 않는다.

## 시뮬레이션부터 시작하는 평가 방향

사용자는 실제 데이터가 아직 충분히 확보되지 않았고 전체 관계를 100% 해석할 수도 없으므로 시뮬레이션으로 먼저 검토하는 방향을 제안했다. 이를 우선 평가 경로로 둔다.

간단한 정답식을 연구자가 직접 정한 함수 문제만 사용할 필요는 없다. 수치 시뮬레이터가 출력은 계산하지만 입력–출력 관계를 간단한 닫힌 식으로 표현하기 어려운 문제도 사용할 수 있다. 전체 메커니즘의 완전한 해석은 예측 성능 평가의 전제 조건이 아니다.

평가자가 별도로 확보한 시뮬레이션 출력과 모델에 제공하는 정보를 구분한다. 학습기는 좁은 운전 범위의 데이터와 허용된 물리 지식만 받고, 바깥 범위의 출력은 최종 평가에만 사용한다. 시뮬레이터는 설정된 가정 안의 기준값을 제공하며 현실의 절대적 참값으로 취급하지 않는다.

실제 데이터 미확보는 시뮬레이션 방법 연구의 중단 조건이 아니다. 이 경우 결과의 주장 범위를 시뮬레이션에서의 일반화로 한정한다. 구체적인 시뮬레이터·공정은 아직 선정하지 않았다.

## 잠정 방법

문헌별로 관계, 적용 조건, 필요한 관측량, 상수의 출처, 예외와 불확실성을 구조화한다. 조건은 가능하면 관측 입력과 알려진 메타데이터에서 계산되는 명시적 규칙으로 변환한다. 확인되지 않은 조건을 임의로 참으로 처리하지 않는다.

우선 작은 예측기에 조건부 물리 제약을 추가해 효과를 확인한다. 교사–학생 구조는 지식 전달의 효과가 확인된 뒤 비교·확장한다. 정답 없는 입력점은 사전 선언한 운전 범위에서 생성할 수 있으나, 이것은 새로운 관측 증거가 아니다.

조건이 불명확하면 복수 가설·조건부 시나리오를 유지하는 설계를 검토한다. 이 역시 자동으로 보정된 예측 구간이나 안전 보장이 되지는 않는다.

## 연구 운영 원칙

- 모든 모델 선택은 소스 데이터 또는 별도 개발 시스템에서 수행한다.
- 최종 시험 정답을 프롬프트, 후보 순위, 가중치 조정에 사용하지 않는다.
- LLM의 지식 획득 효과와 예측 모델의 결합 효과를 따로 측정한다.
- 수동으로 주어진 동일 조건을 쓰는 간단한 규칙 모델을 필수 비교군으로 둔다.
- 실험 결과, 가설, 문헌에서 확인된 사실을 구분한다.
- 새 대화에서 방향이 정해지면 이 문서와 결정 기록을 함께 갱신한다. 이 문서 생성은 별도 백그라운드 자동 갱신을 설정한 것이 아니다.
