# 메모: 외삽이 망가지는 네 가지 상황 (2026-11-12)

상태: 논의 정리. 실험 없음. 문헌 검색 없이 적었다. 수치는 기존 기록에서 가져왔고 출처를 옆에 적었다.

## 1. 출발점

연구자가 든 세 경우:

1. 데이터에 외삽 정보가 없다.
2. 정보가 조금밖에 없어서 모델이 엉뚱한 것을 학습한다.
3. 정보는 많은데 헷갈리는 정보가 많다.

두 번째에 원인이 둘 섞여 있어 나눴다. 결과는 네 가지다.

| 연구자 분류 | 정리한 분류 |
|---|---|
| 첫 번째 | A |
| 두 번째 | B와 C |
| 세 번째 | D |

## 2. 네 가지 상황

| | 상황 | 정의 | 통계 용어 | 데이터를 늘리면 | 우리 실험의 예 |
|---|---|---|---|---|---|
| A | 정보 없음 | 구간 밖에서 생기는 일의 흔적이 학습 데이터에 전혀 없다 | 식별 불가 | 안 풀림 | 강한 출력 제한, δ ≥ 2. 구간 안 최대 차이 0.2–1.1 MW |
| B | 정보 약함 | 흔적은 있는데 작아서 잡음에 묻힌다 | 약한 식별 | 풀림 | 증발 냉각기, δ = 4. 구간 안 행의 23–51%만 0.5 MW 넘게 다름 |
| C | 모형이 못 담음 | 흔적은 충분한데 모형 모양이 틀려 못 배운다 | 모형 오지정 | 안 풀림 | 우리 과제에서는 아직 확인된 예가 없다(아래 정정) |
| D | 정보가 엉킴 | 변수들이 같이 움직여 효과를 엉뚱한 변수에 준다 | 교란, 허위 상관 | 안 풀림 | 기온과 복수기 진공. 탐색에서 부분 계수 0.728, 단순 기울기 0.628 |

수치 출처: A, B, C는 [확인 실험 §10.2](ccpp-twin-outside-confirmation.md), D는 [시뮬레이터 도움 탐색](ccpp-twin-explore-sim-assist.md). D의 수치는 탐색이며 판정에 쓰지 않는다.

## 3. 가리는 법

| | 확인 방법 |
|---|---|
| A | 잡음 없는 값으로 꺾임 있는 세계와 없는 세계를 비교한다. 구간 안 차이가 거의 0이면 A |
| B | 차이는 있으나 잡음보다 작다. 표본 수를 늘리면 오차가 준다 |
| C | 표본을 늘려도 오차가 줄지 않는다. 유연한 모형으로 바꾸면 준다 |
| D | 구간 안 적합은 좋다. 변수 간 관계가 달라지는 구간에서만 무너진다 |

## 4. 필요한 것

| | 데이터만으로 가능한가 | 바깥 지식의 역할 |
|---|---|---|
| A | 불가능 | 유일한 정보원. 틀려도 데이터가 못 잡는다 |
| B | 데이터가 많으면 가능 | 약한 신호를 밀어주는 사전 지식. 데이터가 일부 검증한다 |
| C | 모형을 바꾸면 가능 | 어떤 모양을 쓸지 알려 준다 |
| D | 구간 안 자료만으로는 불가능 | 어느 변수가 진짜 원인인지 알려 준다 |

## 5. 드러난 점

- A와 D는 데이터를 늘려도 풀리지 않는다. 바깥 지식이 꼭 필요한 곳이다. B와 C는 원칙적으로 데이터와 모형만으로 풀 수 있다.
- 지금까지 실험은 A, B, C가 섞여 있었다. 기준선이 직선 회귀라서 증발 냉각기 과제의 이득 중 B와 C의 몫이 갈리지 않는다. 꺾임을 그릴 수 있는 데이터 기준선이 있어야 갈린다.
- 실제 자료는 보통 겹친다. 실제 CCPP는 D가 깔려 있고 그 위에 A나 B가 얹힌다.
- 원래 목표는 A였다. 확인 실험은 A에서 실패했다([확인 실험 §11](ccpp-twin-outside-confirmation.md)).

## 6. 정하지 않은 것

- 논문이 A, B, C, D 중 어디를 겨냥할지.
- 이 틀을 방향으로 잡으면 문헌 검토가 필요하다. D는 허위 상관, 불변 학습, LLM의 인과 지식 활용 쪽 선행연구가 많을 것으로 예상하나 확인하지 않았다.

## 7. 정정 (2026-11-12, 탐색 뒤)

처음에는 C의 예로 "증발 냉각기, δ = 1에 직선 회귀"를 적었다. [탐색](ccpp-twin-explore-robust-bound.md)에서 꺾임을 그릴 수 있는 모형을 넣어 보니 창 안 흔적을 살리지 못했다(꺾임 항 채택 1–6%, n = 500에서도 선형과 같음). 이 잡음 수준에서 증발 냉각기 δ = 1은 C가 아니라 B다. 표의 C 예시를 고쳤다. §5의 "A, B, C가 섞여 있었다"는 "A와 B가 섞여 있었고 C의 몫은 작다"로 읽어야 한다.
