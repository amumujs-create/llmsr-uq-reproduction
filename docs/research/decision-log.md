## 2026-11-03 — 시뮬레이션 우선 방향으로 구체화

### 사용자의 제안

정답식을 이미 아는 함수 문제에 한정하지 않고 시뮬레이션으로 먼저 연구하자고 제안했다. 실제 데이터가 아직 충분히 확보되지 않았고 실제 데이터의 전체 관계를 100% 해석할 수도 없다는 점을 지적했다.

### 반영한 변경

- 수치 시뮬레이션을 우선 평가 경로로 지정했다. 해석기와 대상 공정은 아직 미정이다.
- 평가용 출력 확보와 참 관계의 완전한 해석을 구분했다. 예측 연구에 후자는 필수 조건이 아니다.
- 모델에는 제한된 운전 데이터와 허용된 문헌 지식을 제공하고, 외삽 범위의 시뮬레이션 출력은 평가에만 사용한다.
- 시뮬레이터의 가정·수치 오차와 현실 타당성을 구분한다.
- 실제 데이터 미확보를 연구 중단 조건에서 제외했다. 현장 성능 주장의 범위를 조절한다.
- 수동 정답식 pilot은 필수 단계에서 선택적 진단으로 변경했다.

이번 갱신은 평가 계획 수정이며 시뮬레이터 구현이나 실험 실행을 수행한 기록은 아니다.

## 2026-11-03 — 박사 연구의 논문 기여 기준 명시

사용자는 연구 가능 여부와 함께, 성공했을 때 SCI(E) 저널 논문으로 발전시킬 학술적 가치가 있는지를 명확히 판단해 달라고 요청했다.

현재 권고는 박사 연구의 한 축으로 진행할 가치가 있다는 것이다. 시뮬레이션 기반 방법론 논문을 목표로 하며 실제 데이터를 연구 착수의 필수 조건으로 삼지 않는다. 다만 구성요소 조합만의 신규성은 확보되지 않았다.

[논문 가능성 판단 문서](publication-assessment.md)에 단순 정확도 향상과 방법론 기여의 차이, 동일정보 비교, 조건 오류 대응, 예상 심사 질문, 시뮬레이션 평가의 주장 범위를 추가했다. 게재 보장이나 구현·성능 결과로 기록하지 않는다.

## 2026-11-03 — 주제 탐색과 추천의 기준 보완

사용자는 후보 추천 뒤 선행연구와의 겹침을 이유로 철회하는 과정이 반복되어 주제 선정이 지연되는 점을 지적했다.

- 충분한 비교 전에 “유망한 공백”으로 추천하는 것과, 관련 연구가 발견될 때마다 후보를 전면 철회하는 것 모두 피한다.
- 목적·구성요소의 중복과 같은 문제·정보·방법·결론까지 이미 다룬 중복을 구분한다.
- 문헌조사만으로 전 세계의 선행연구 부재나 제안 방법의 효과를 완전히 증명한 뒤에만 실험할 수 있다는 기준은 두지 않는다.
- 다음 후보 검토는 가장 가까운 3–5개 방법을 먼저 고정하고, 이미 해결한 부분·가정·추가 정보·예상 차이·이를 가르는 작은 실험을 한 장으로 명시한다. 후보와 방법의 개수는 작업 범위를 제한하기 위한 권고이며 학술적 기준이 아니다.
- 탐색 실험도 차별점을 구체화하는 과정에 포함한다. 동시에 차이의 가설도 없이 큰 구현과 장기 실험에 착수하지 않는다.

사용자가 공유한 후속 대화의 “관측에서 약하지만 외삽에서 중요해지는 항의 보존”은 차별점 미확정 후보로 기록한다. 이를 새 추천이나 폐기 확정으로 승격하지 않는다. 공유된 8편 비교의 세부 수치와 외부 로컬 파일은 이번 갱신에서 독립적으로 재검증하거나 가져오지 않았다. 기존의 조건부 물리 지식 방향과 이 후보를 동일한 방법으로 합쳐 서술하지 않는다.

현재 목표는 새 후보를 계속 추가하는 것이 아니라, 하나의 후보에 대해 유지·수정·중단의 근거를 일관되게 축적하는 것이다.

조건부 물리 지식 전달과 약한 항 보존은 별도 후보로 관리한다. 실제 데이터가 없어도 시뮬레이션으로 검토한다는 사용자의 방향은 유지한다. 제안 실험·예상 일정·모델 구조를 실행 완료로 기록하지 않는다.

이번 작업은 전달된 내용을 포함한 연구 기록의 통합이다. 외부 컴퓨터의 로컬 파일을 업로드한 것이 아니고, 모든 연결 논문을 새로 정독하거나 코드를 재현한 것도 아니다. 기존 실행 코드·결과·환경 기록은 변경하지 않는다.

## 2026-11-03 — 첫 논문 후보로 탐색 반복 간 불일치를 검토

### 사용자의 요청

SCI 논문을 쓰기 위해 연구 주제를 다시 정하자고 요청했다. 후보 3개(탐색 반복 간 불일치, 조건부 물리 지식 전달, 외부 지식 효과의 평가 연구) 가운데 첫 논문 후보로 권고한 “외삽 예측을 언제 믿으면 안 되는가”의 선행연구 확인을 요청했다.

### 권고 — 사용자가 최종 확정한 주제는 아님

- 첫 논문 후보: 같은 데이터로 LLM 식 탐색을 반복할 때 탐색 간 OOD 예측 불일치가 탐색 내부 불일치로 포착되지 않는 오차를 알려 주는지.
- 조건부 물리 지식 전달은 박사 연구의 긴 줄기로 유지한다. 두 후보를 하나의 방법으로 합치지 않는다.

### 선행연구 확인 결과

[비교 기록](reviews/2026-11-03-search-disagreement.md)에 정리했다.

- LLM-SR-UQ는 한 번의 탐색 buffer 안에서 후보식 불일치를 쓰고, held-out은 문제당 seed 1개로 평가한다. 불일치와 OOD 오차의 직접 관계(상관·AUROC·risk–coverage)는 보고하지 않는다.
- ProAug는 LLM-SR의 큰 seed 민감도를 보고하지만 불확실성 신호로 쓰지 않는다.
- 기호식 앙상블 합의를 신뢰 지표로 쓰는 개념은 Kotanchek et al.(2007)에 있다. 따라서 개념 자체를 신규성으로 주장하지 않고 기여 형태를 진단 연구로 한정한다.

판정은 **조건부 유지**다. 파일럿(dev3 × 5회 반복)에서 탐색 간 불일치가 탐색 내부 σ_S와 학습 범위 거리 기준보다 OOD 오차를 더 잘 예측하지 못하면 보류한다. 파일럿과 분석 스크립트는 아직 없다.

## 2026-11-03 — 구별되지 않는 식과 물리 지식 설계의 겹침 검토

### 사용자의 제안

빠른 실험으로 물리 도메인 하나를 골라, 데이터에 정보가 없어 외삽이 실패하는 경우 물리 지식이나 LLM 식의 도움을 받는 방법을 제안했다. 학습 구간에서는 틀린 식도 맞아서 데이터로 식을 구별할 수 없다는 문제를 지적하고, 이 설계가 논문이 되는지와 겹침을 확인해 달라고 요청했다.

### 권고 — 확정 주제는 아님

복사 냉각(대류 선형 + 복사 T⁴)을 파일럿 시스템으로 권고했다. 물리 지식으로 식을 고르기, 상수 범위로 외삽 묶기, 불일치 경보, 측정 위치 제안, 틀린 지식 피해를 하나의 설계로 묶었다.

### 겹침 검토 결과

[비교 기록](reviews/2026-11-03-indistinguishable-candidates.md)에 정리했다. 물리 조건 선택은 shape-constrained SR, PG-SR, KeplerAgent, PiSR와 겹친다. 측정 위치 제안은 고전 실험설계다. 남는 것은 학습 구간 식별 불가능성을 실험 축으로 조작하고 필요한 지식의 종류와 출력 형태를 분리 비교하는 통제 분석이다.

판정은 **조건부로 논문 가능, 방법론 신규성 약함**이다. “정답을 주면 당연히 된다”는 반론을 넘을 비자명한 결과가 필요하다. 첫 결정 실험은 물리 설명을 받은 LLM-SR이 저온 데이터에서 T⁴ 항을 유지하는지다. 미실행.

## 2026-11-03 — 정답 형태 없이 위험 감지, 그리고 외삽 실패 원인 분해로 이동

### 사용자가 명확히 한 조건

- LLM에 정답 형태를 주지 않는다. 학습 구간에서는 맞지만 외삽에서 틀리는 식의 **위험을 어떻게 감지하고 극복할지**가 관심이다.
- LLM은 가중치 학습(fine-tuning) 없이 추론만 사용한다.
- 데이터에 정보가 없을 때 LLM이 정보를 줄 수 있는지, LLM 생성물을 어떻게 믿을지 질문했다.
- 외삽을 잘 가르치는 방법으로 모듈화와 LLM 활용을 묻고, 각 모듈을 정의해 피팅 시 어느 부분이 망가졌는지 진단해 외삽을 강화하자고 제안했다.

### 대화에서 정리한 입장 — 실험으로 확인되지 않음

- 데이터에 없는 외삽 정보는 어떤 방법도 데이터에서 만들 수 없다. 외삽 개선은 외부 정보를 넣는 통로(구조, 제약, 무차원화, 저정밀 모델, 유사 시스템, 합성 데이터, 측정)의 선택이다.
- LLM은 다른 데이터에서 학습한 외부 정보원으로서 **가능한 메커니즘과 대략적 범위**를 줄 수 있지만 시스템별 정확한 계수나 미지의 현상은 줄 수 없다.
- LLM 출력은 **결정이 아니라 의심에 쓴다.** 경쟁 가설을 만들고 데이터 배제 검사로 거르면 LLM이 틀려도 비용이 오경보로 제한된다. LLM의 신뢰도는 숨은 메커니즘 재현율과 오경보율로 측정한다. 여러 LLM의 동의는 진실성의 증거가 아니다.
- 적합도 기반 탐색의 불일치(LLM-SR-UQ, 탐색 반복)는 학습 구간에서 맞는 단순 식으로 모여 “확신하면서 틀린” 경우를 놓칠 수 있다. LLM 지식으로 경쟁 메커니즘을 의도적으로 생성하고 학습 데이터가 배제하지 못하는 가설의 OOD 갈라짐을 위험 점수로 쓰는 설계를 검토했다. 검색 한 번에서는 같은 방법을 찾지 못했으나 본격 확인은 하지 않았다.

### 현재 권고 — 사용자가 최종 확정한 주제는 아님

외삽 실패를 생성·피팅·선택·식별 불가·지식 오류로 분해하고 정답 없는 증상으로 유형을 추정해 처방하는 방향을 [후보 기록](reviews/2026-11-03-failure-attribution.md)에 정리했다. 이전 후보(탐색 반복 간 불일치, 경쟁 가설 위험 감지, 조건부 물리 지식)는 이 틀의 처방 또는 유형으로 들어간다.

모듈화와 진단 피드백(SAGE-Fit, LLM-PySR, IGSR, A1)은 기존이다. 확인 범위에서 외삽 실패 원인 분해는 찾지 못했다. 1층 분석은 정답식과 기존 실행 산출물로 109문제 × 1회 실행부터 시작할 수 있다. 분석·실험은 미실행이다.

## 2026-11-03 — 외삽 실패 원인 분해의 신규성 재검토

사용자가 “외삽 실패의 원인을 모듈별로 분해하고 정답 없이 유형을 추정해 맞춤 처방한다는 부분이 비어 있다”는 판단을 다시 확인해 달라고 요청했다.

검색 범위를 일반 SR 실패 분석, 자기진단형 SR 에이전트, LLM 에이전트 실패 원인 추적으로 넓혔다. 그 결과 **이전 판정을 수정한다.**

- PostDiag(2026-10-17 preprint)가 정답 없이 bootstrap 편향·분산으로 실패 상태를 진단하고 상태별 처방을 LLM에 전달하며 LSR-Synth에서 OOD 개선까지 보고한다. 정답 없는 진단·맞춤 처방은 비어 있지 않다.
- 탐색 실패 vs 피팅 실패 분류는 SurfaceBench·SAGE-Fit에 있다.
- 확인 범위에서 남은 것은 외삽 실패에 한정한 원인 분해(특히 식별 불가능성 분리)와, 학습 구간 진단이 정상으로 판정하지만 외삽에서 실패하는 사각지대를 외부 정보로 진단하는 부분이다.

이전 기록의 “확인 범위에서 비어 있다”는 표현은 검색 범위가 좁았던 판단이다. 후보는 유지하되 범위를 좁히고 PostDiag를 핵심 비교군으로 둔다. 이번 재검토도 전수 조사가 아니다.

## 2026-11-03 — 물리 행동 모듈 설계와 겹침 검토

### 사용자가 정한 것

- 출력은 점 예측으로 한다.
- 모듈은 수식만이 아니라 줄 수 있는 다양한 정보로 정한다.
- LLM은 추천만 하고, LLM이 놓치는 것에 대한 대책을 설계해야 한다.
- 데이터셋은 나중에 정하고 아이디어부터 논의한다.
- 논의하면서 선행연구와 겹쳐 논문이 되지 않는 아이디어는 걸러낸다.

### 아이디어 필터링 결과 — 권고

걸러냄(주 기여 불가): RAG로 식 탐색 개선, 조건부 지식 전달 게이트, 물리 조건으로 식 고르기, 일반 모듈화·진단 피드백, 정답 없는 진단·처방(PostDiag), LLM 역할 분리, LLM 모듈 조립 자체(BoxLM 등), 레이어 결합(GenCANN, UDE 등), 감시 LLM 자체, 측정 위치 제안.

부품으로 사용: 탐색 반복 간 불일치, 상수 범위, 틀린 지식 피해 측정, 측정 제안, 잔차 신경망, 감시 단계.

살아 있음: 질적 행동 모듈로 외삽, 신뢰도 폭의 모듈별 출처, 학습 구간 진단의 사각지대, LLM 경쟁 가설.

### 겹침 검토

[검토 기록](reviews/2026-11-03-behavior-modules.md)에 정리했다. 모듈 분류와 통합 역할은 Informed ML 서베이와 겹친다. LLM prior 추출(AutoElicit), 전문가 형상 지식(von Kurnatowski, Kronberger), LLM 모델 제안·비평(BoxLM)도 있다. 확인 범위에서 남은 것은 LLM 질적 외삽 지식의 체크리스트 추출과 형식화, 학습 데이터가 정보를 주지 않는 외삽에서의 평가, LLM 누락의 체계적 처리와 누락률 측정, 신뢰도 폭의 모듈별 출처다.

판정은 **조건부 신규성(결합·평가 수준)**이다. 구현·실험은 미실행이다.

## 2026-11-03 — 기울기 변화 추종과 준비된 가설 아이디어 검토

### 대화에서 정리한 내용 — 실험으로 확인되지 않음

- 범위 밖 기울기 변화를 **전조가 있는 변화**(학습 구간에 약하게 존재하는 항이 커짐)와 **전조가 없는 변화**(임계값에서 일어남)로 구분했다. 전조가 있으면 국소 지수 등 기울기 공간에서 데이터 추세와 LLM 모듈의 한계를 결합하고, 전조가 없으면 지식·다른 조건의 무차원 정렬·요동 신호가 필요하다.
- LLM 후보를 학습 구간 적합 → 전조 검사 → 물리 제약 → 다른 조건과의 일관성 → 지식 가중의 순서로 좁히는 절차를 논의했다.
- 저랭크 구조는 조합 외삽을 돕고 범위 외삽은 혼자 돕지 못한다는 점, 단변수 행동 모듈의 곱의 합을 조립 문법으로 쓰는 안을 논의했다.
- 사용자는 데이터에 정보가 전혀 없을 때 사람의 강한 확신 외에 방법이 있는지 물었다. 지식은 다른 실험의 데이터라는 점, 확신의 실적 보정, 최악 오차 최소화, 측정 가치, 미리 준비한 가설, 정직한 “모름”으로 정리했다.

### 겹침 검토

사용자가 논문 관점에서 무엇이 나은지 묻고 준비된 가설 + 소수 관측 확정 아이디어의 겹침 확인을 요청했다. [검토 기록](reviews/2026-11-03-prepared-hypotheses.md)에 정리했다.

판정: 메커니즘은 고전 실험설계와 LLM-AutoSciLab과 겹친다. 남는 것은 학습 시스템 어디에도 없는 레짐이라는 설정, k에 따른 외삽 오차 평가, LLM 레짐 가설의 재현율 중심 평가다. **독립 주 기여로는 약하므로 행동 모듈 설계의 평가 축으로 넣는 것을 권고한다.** LLM-AutoSciLab 본문 확인이 남아 있다.

## 2026-11-04 — 주 실험을 CCPP 좁은 학습 창 외삽으로 설정

### 사용자가 정한 것

- 실데이터는 마지막에 쓰고 시뮬레이션으로 먼저 개발한다. 해석이 가능해야 하기 때문이다.
- 시뮬레이터가 있고 개선 여지를 확실히 주장할 수 있는 데이터셋으로 한다.
- 출력은 점 예측, LLM은 추천만 한다(이전 결정 유지).
- 설계마다 왜 그렇게 했는지와 가정을 기록한다. 가정이 맞아야 주장이 성립하기 때문이다.

### 분석과 판단

[CCPP 외삽 기록](ccpp-extrapolation.md)에 분석, 설계 결정, 가정, 배제할 대안 설명, 사전 고정 격자를 정리했다.

- CCPP 출력은 양 끝이 평평한 S자 곡선이다. 좁은 학습 창이 평평한 끝에 걸리면 데이터 기울기가 외삽 경로를 대표하지 못하고, 기울기를 물리로 고정한 비례식(출력 ∝ 공기 밀도)이 크게 이긴다. 좁은 창에서는 양방향 모두 그랬다. 넓은 창에서는 데이터 적합이 이겼다.
- 이득은 좌표가 아니라 물리로 고정한 기울기에서 왔다.
- 사용자 관찰: 저온 쪽은 거의 선형이라 직선이 잘 맞아 보이고 고온 끝은 표본이 적어 틀려도 드러나지 않는다. 거리 구간별 지표와 행 수를 함께 보고하기로 했다.
- 심사 대응: 방향이 아니라 조건(창 폭, 국소 기울기의 대표성)으로 주장하고 모든 조건을 보고한다.
- 가장 시급한 미확인 가정은 공변량(V) 범위 이탈의 통제(A4)와, 정답 없는 지표가 물리식 우세 조건을 예측하는지(A6)다.

판단용 분석에는 시험 정답을 사용했다. 분석 스크립트는 `analysis/ccpp/`에 있다. 쌍둥이 시뮬레이터와 격자 실험은 미실행이다. 비공개 저장소 실험의 상세 감사 기록은 이 공개 저장소에 두지 않는다.

## 2026-11-04 쌍둥이 격자 실험

[사전 등록과 결과](ccpp-twin-grid.md). 사전 등록 문서를 결과 전에 커밋했다(`055322d`).

- 레짐이 없는 쌍둥이 세계에서는 물리 고정 기울기(비례식)가 거의 항상 진다(승률 2%). 이기는 조건은 학습 창과 시험 구간 사이에 레짐 경계(저온 상한, 고온 증발냉각)가 있을 때다.
- 비례식은 맞아서 이기는 것이 아니라 경계를 넘는 경로의 평균 기울기에 우연히 가까워서 이긴다. 거리가 멀어지면 다시 진다.
- 창 안 데이터만으로 계산한 판단 지표(A6)는 AUROC 0.63–0.64에 그치고 세계가 바뀌면 쓸 수 없다. 원인이 창 밖의 정보이기 때문이다.
- 판단: A6을 “레짐에 대한 사전 진술(LLM 추천)을 입력으로 받는 판단 규칙”으로 재정의할지 검토한다. 진술이 틀린 경우의 손실을 함께 재야 한다.

## 2026-11-04 레짐 진술 규칙

[사전 등록과 결과](ccpp-regime-statement.md). 사전 등록 문서를 결과 전에 커밋했다(`1972963`).

- 진술이 맞고 레짐이 뚜렷하면 이득이 크다(`cap_strong` 12.3 → 6.7 MW). 구간별 기울기 조립(`R2_compose`)이 칸별 oracle 선택보다 나은 세계도 있었다.

## 2026-11-04 레짐 진술 분해 — 겹침 검토

[검토 기록](reviews/2026-11-04-regime-statement-overlap.md).

- 판정은 조건부로 비어 있음이다. LLM 계수 prior(LoID, Langseth 외), prior–data conflict, 외삽의 검증 불가능한 가정(Pfister & Bühlmann, 부분 식별)은 각각 기존이다.
- LoID는 CCPP 온도 외삽에서 계수 prior가 실패했다고 보고했다. 우리 동기의 직접 근거이자 비교군 후보다.
- 기여는 진술을 검사 가능/불가능으로 나눈 뒤 **검사 불가능 부분의 위험을 묶는 방법**에 있어야 한다. 다음 단계로 이 규칙을 설계한다.

## 2026-11-04 검사할 수 없는 진술의 위험 제한

[사전 등록과 결과](ccpp-risk-limit.md). 사전 등록 문서를 결과 전에 커밋했다(`8d95d0e`).

- 위험 제한 규칙 두 가지를 비교했다.
  - `blend`: 진술이 바꾸는 양을 비율 λ만큼만 반영한다.
  - `budget`: 진술 때문에 늘어나는 오차를 행마다 ε 이하로 보장한다.
- 엄격한 정의(탐색 분석, 사전 등록 외)에서 진술을 전부 반영하는 `R2g`는 진술 신뢰도 p ≥ 0.55에서만 데이터 적합보다 낫다. `blend_0.25`는 p ≥ 0.30에서 낫다. 가장 좋은 규칙은 p에 따라 바뀐다.
- 진술 없이 계수 prior나 데이터 기반 외삽 한계를 쓰는 비교군은 개선이 없었다.
- 판단: 다음 핵심 질문은 실제 LLM 진술의 신뢰도 p와, p를 정답 없이 추정할 수 있는지다.

## 2026-11-04 LLM 진술 본 수집 첫 결과 (`gpt-oss-120b`)와 계열 추가

- `gpt-oss-120b`의 구조 신뢰도 p는 `L2`에서 0.67이다. 소형 모델 네 계열(`mistral`, `qwen`, `llama`, `gemma`)은 0.2 안팎이다. `L2` 진술을 쓰면 다섯 세계 평균 오차가 약 12% 준다.
- 소형 모델의 병목은 가스터빈 온도 민감도라는 정량 지식이다. 네 계열 모두 같은 양상이다.
- 창 요약(D1)을 주면 없는 저온 경계 주장이 크게 준다(`base` 0.60 → 0.15–0.30).
- 사전 예측: P1·P2 부분적으로 맞음, P3 맞음, P4·P6 틀림, P5 대체로 맞음, P7 보류.
