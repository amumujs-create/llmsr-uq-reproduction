# 아이디어와 결정 기록

[현재 연구 방향](README.md) · [겹침 검토](reviews/2026-11-03-overlap.md) · [실험 계획](pilot-plan.md)

## 기록 방식

새 대화에서 바뀐 방향, 그 이유, 확인한 근거, 남은 질문을 기록한다. 과거 대화의 날짜가 확인되지 않으면 임의 날짜를 붙이지 않는다. 현재 권장안을 사용자가 최종 확정한 결정처럼 쓰지 않는다.

## 2026-11-03 — 이전 대화 요약과 첫 저장소 반영

### 사용자가 명확히 한 목표

- 주 목표는 물리·제조 예측의 외삽 개선이다.
- 수치 데이터만으로 발견한 식은 좁은 범위와 노이즈에 민감할 수 있다는 문제의식이 있다.
- LLM의 넓은 사전 지식을 교사처럼 활용하고 싶다.
- 식 생성·검증이나 불확실성 구간만으로 목표가 끝나는 것은 아니다.
- 데이터에 이미 충분한 정보가 있는 경우와 없는 경우를 구분해야 한다.
- 필요한 feature 자체가 빠진 문제와, 학습 밖의 운전 조건을 구별할 정보가 부족한 문제를 구분했다.
- 두 문제 중 후자를 우선 검토한다.
- 이 저장소에 대화에서 발전하는 연구 아이디어와 근거를 계속 기록한다.

### 이번 검토의 권고 — 아직 실험으로 확정되지 않음

넓은 “LLM 물리 교사로 외삽 개선”에서 “적용 조건을 확인할 수 있는 외부 물리 지식의 선택적 전달”로 좁힌다. 관측 정보가 없는 숨은 전이까지 해결한다고 주장하지 않는다.

이유:

- PDNN과 제조 분석식 연구가 넓은 아이디어와 직접 겹친다.
- KernelMix는 조건별 물리 의존도 조절을 이미 다룬다.
- GenCANN 계열은 LLM이 물리 신경망을 만들고 검사하는 접근까지 확장했다.
- adaptive loss·discrepancy 보정도 기존 연구다.
- 최근 LLM prior 연구는 OOD 개선과 단순 정규화 효과를 구별하는 질문도 다룬다.

### 현재 작업과 새 가설의 관계

기존 재현 실행기와 upstream 코드는 현재 연구 가설을 검증한 구현이 아니다. 수식 후보의 민감도·불확실성은 기반 경험으로 활용할 수 있지만, 아직 조건 지식 전달 실험 결과는 없다. 이번 반영은 연구 문서와 README 안내 추가다.

### 다음에 결정할 항목

1. 첫 제조 대상과 확보 가능한 실제 운전 범위·메타데이터.
2. 조건의 변화가 관측 입력에서 계산 가능한지.
3. 관련 문헌과 상수의 출처, 사용 가능한 라이선스.
4. 수동 지식 pilot 결과에 따른 방법 연구/추출 연구/평가 연구 선택.
5. 선행방법 구현 가능성과 공정한 동일정보 비교.

### 향후 갱신 형식

- 날짜와 변경된 주장.
- 사용자의 결정 / 권고안 / 검증된 결과의 구분.
- 근거 문헌과 확인 범위.
- 반증·실패 결과 및 그에 따른 범위 축소.
- 실험 코드 commit, 데이터 분할, 프롬프트·모델 버전.

## 2026-11-03 — 시뮬레이션 우선 방향으로 구체화

### 사용자의 제안

정답식을 이미 아는 함수 문제에 한정하지 않고 시뮬레이션으로 먼저 연구하자고 제안했다. 실제 데이터가 아직 충분히 확보되지 않았고 실제 데이터의 전체 관계를 100% 해석할 수도 없다는 점을 지적했다.

### 반영한 변경

- 수치 시뮬레이션을 우선 평가 경로로 지정했다. 해석기와 대상 공정은 아직 미정이다.
- 평가용 출력 확보와 참 관계의 완전한 해석을 구분했다. 예측 연구에 후자는 필수 조건이 아니다.
- 모델에는 제한된 운전 데이터와 허용된 문헌 지식을 제공하고, 외삽 범위의 시뮬레이션 출력은 평가에만 사용한다.
- 시뮬레이터의 가정·수치 오차와 현실 타당성을 구분한다.
- 실제 데이터 미확보를 연구 중단 조건에서 제외했다. 현장 성능 주장의 범위를 조절한다.
- 수동 정답식 pilot은 필수 단계에서 선택적 진단으로 변경했다.

이번 갱신은 평가 계획 수정이며 시뮬레이터 구현이나 실험 실행을 수행한 기록은 아니다.

## 2026-11-03 — 박사 연구의 논문 기여 기준 명시

사용자는 연구 가능 여부와 함께, 성공했을 때 SCI(E) 저널 논문으로 발전시킬 학술적 가치가 있는지를 명확히 판단해 달라고 요청했다.

현재 권고는 박사 연구의 한 축으로 진행할 가치가 있다는 것이다. 시뮬레이션 기반 방법론 논문을 목표로 하며 실제 데이터를 연구 착수의 필수 조건으로 삼지 않는다. 다만 구성요소 조합만의 신규성은 확보되지 않았다.

[논문 가능성 판단 문서](publication-assessment.md)에 단순 정확도 향상과 방법론 기여의 차이, 동일정보 비교, 조건 오류 대응, 예상 심사 질문, 시뮬레이션 평가의 주장 범위를 추가했다. 게재 보장이나 구현·성능 결과로 기록하지 않는다.

## 2026-11-03 — 주제 탐색과 추천의 기준 보완

사용자는 후보 추천 뒤 선행연구와의 겹침을 이유로 철회하는 과정이 반복되어 주제 선정이 지연되는 점을 지적했다.

- 충분한 비교 전에 “유망한 공백”으로 추천하는 것과, 관련 연구가 발견될 때마다 후보를 전면 철회하는 것 모두 피한다.
- 목적·구성요소의 중복과 같은 문제·정보·방법·결론까지 이미 다룬 중복을 구분한다.
- 문헌조사만으로 전 세계의 선행연구 부재나 제안 방법의 효과를 완전히 증명한 뒤에만 실험할 수 있다는 기준은 두지 않는다.
- 다음 후보 검토는 가장 가까운 3–5개 방법을 먼저 고정하고, 이미 해결한 부분·가정·추가 정보·예상 차이·이를 가르는 작은 실험을 한 장으로 명시한다. 후보와 방법의 개수는 작업 범위를 제한하기 위한 권고이며 학술적 기준이 아니다.
- 탐색 실험도 차별점을 구체화하는 과정에 포함한다. 동시에 차이의 가설도 없이 큰 구현과 장기 실험에 착수하지 않는다.

사용자가 공유한 후속 대화의 “관측에서 약하지만 외삽에서 중요해지는 항의 보존”은 차별점 미확정 후보로 기록한다. 이를 새 추천이나 폐기 확정으로 승격하지 않는다. 공유된 8편 비교의 세부 수치와 외부 로컬 파일은 이번 갱신에서 독립적으로 재검증하거나 가져오지 않았다. 기존의 조건부 물리 지식 방향과 이 후보를 동일한 방법으로 합쳐 서술하지 않는다.

현재 목표는 새 후보를 계속 추가하는 것이 아니라, 하나의 후보에 대해 유지·수정·중단의 근거를 일관되게 축적하는 것이다.

## 2026-11-03 — 누적 검색 자료 통합과 추천 상태 정정

사용자가 지금까지의 검색 내용을 저장소에 반영하라고 요청했다.

추가한 자료:

- [검색·검토 자료 통합 목록](literature-map.md): 기존 핵심 12편, 후속 8편과 예측 프로파일 우도, 주변 검색 후보, 확인 수준과 미해결 질문.
- [전달된 8편 비교·약한 물리항 후보](reviews/2026-11-03-weak-term-candidate.md): 실험 조건 수치, 미실행 설계, 추천 철회 이유. 잘린 목표 외삽 범위는 미확정으로 보존.

현재 상태는 관련 연구와 후보를 확보했지만, 가장 가까운 선행연구 대비 구체적인 추가 기여를 충분히 뒷받침한 추천 주제는 아직 제시하지 못했다는 것이다. 이전의 긍정적 기획 의견을 개별 주제의 검증 결과처럼 표현한 판단을 바로잡았다.

조건부 물리 지식 전달과 약한 항 보존은 별도 후보로 관리한다. 실제 데이터가 없어도 시뮬레이션으로 검토한다는 사용자의 방향은 유지한다. 제안 실험·예상 일정·모델 구조를 실행 완료로 기록하지 않는다.

이번 작업은 전달된 내용을 포함한 연구 기록의 통합이다. 외부 컴퓨터의 로컬 파일을 업로드한 것이 아니고, 모든 연결 논문을 새로 정독하거나 코드를 재현한 것도 아니다. 기존 실행 코드·결과·환경 기록은 변경하지 않는다.

## 2026-11-03 — 첫 논문 후보로 탐색 반복 간 불일치를 검토

### 사용자의 요청

SCI 논문을 쓰기 위해 연구 주제를 다시 정하자고 요청했다. 후보 3개(탐색 반복 간 불일치, 조건부 물리 지식 전달, 외부 지식 효과의 평가 연구) 가운데 첫 논문 후보로 권고한 “외삽 예측을 언제 믿으면 안 되는가”의 선행연구 확인을 요청했다.

### 권고 — 사용자가 최종 확정한 주제는 아님

- 첫 논문 후보: 같은 데이터로 LLM 식 탐색을 반복할 때 탐색 간 OOD 예측 불일치가 탐색 내부 불일치로 포착되지 않는 오차를 알려 주는지.
- 조건부 물리 지식 전달은 박사 연구의 긴 줄기로 유지한다. 두 후보를 하나의 방법으로 합치지 않는다.

### 선행연구 확인 결과

[비교 기록](reviews/2026-11-03-search-disagreement.md)에 정리했다.

- LLM-SR-UQ는 한 번의 탐색 buffer 안에서 후보식 불일치를 쓰고, held-out은 문제당 seed 1개로 평가한다. 불일치와 OOD 오차의 직접 관계(상관·AUROC·risk–coverage)는 보고하지 않는다.
- ProAug는 LLM-SR의 큰 seed 민감도를 보고하지만 불확실성 신호로 쓰지 않는다.
- 기호식 앙상블 합의를 신뢰 지표로 쓰는 개념은 Kotanchek et al.(2007)에 있다. 따라서 개념 자체를 신규성으로 주장하지 않고 기여 형태를 진단 연구로 한정한다.

판정은 **조건부 유지**다. 파일럿(dev3 × 5회 반복)에서 탐색 간 불일치가 탐색 내부 σ_S와 학습 범위 거리 기준보다 OOD 오차를 더 잘 예측하지 못하면 보류한다. 파일럿과 분석 스크립트는 아직 없다.
