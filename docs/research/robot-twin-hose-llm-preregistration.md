## 0. 요약과 결론
- **무엇을 묻나:** 유압 호스에 사용 압력을 걸면 길이가 몇 % 바뀌는지(부호와 크기)를 묻는다. LLM에게 J6 각도는 묻지 않는다. 각도는 쌍둥이가 기하로 계산한다. 그래야 기하 계산 능력이 아니라 "호스가 압력에 어떻게 반응하는가"라는 지식을 재게 된다.
- **정답을 정하는 물리:** 와이어 꼰 각도가 중립각(약 54.7°)보다 크면 호스가 늘어나고, 작으면 줄어든다(Dýrr 외, MATEC 2022). L2 설명에는 꼰 각도만 주고 이 규칙은 주지 않는다. 웹에도 이 방향을 반대로 적은 업체 글이 있다. 그래서 지식의 질을 가를 수 있는 질문이다.
- **판정할 것:**
  - 방향 정답률 p_dir이 손익분기 기준(`R2` 0.6, `safe` 0.25)을 넘는가
  - 답이 기본값("줄어든다")에 끌리는가(C2 재현)
  - 관문의 숨은 전제가 실제 진술에서도 나타나는가(C3)

## 1. 질문
1. **H-a:** 실제 LLM 진술의 방향 정답률 p_dir과 크기 오차는 얼마인가? 설명 수준(L0–L2)에 따라 어떻게 달라지는가?
2. **H-b:** 설명이 세계를 구분하지 못하는 L0·L1에서, 모델마다 기본 답(예: "줄어든다")이 있는가? L2에서도 그 기본 답이 남는가?
3. **H-c:** 실제 진술을 규칙(`R0`, `R2`, `blend_0.5`, `budget_5/10`, `safe`, `gate_nom`, `gate_cal`, `gate_cal_infl`)에 넣으면 어느 규칙이 `R0`보다 나은가? 가상 진술 실험의 손익분기 예측과 맞는가?
4. **H-d:** 공칭 관문이 실제 진술 중 기본값·틀린 진술을 통과시키는가? 보정·부풀림 관문이 그것을 막는가?

## 2. 쌍둥이 세계와 정답
| 세계 | 꼰 각도 (L2 설명) | 정답 ε (사용 압력에서의 길이 변화) | 방향 |
|---|---|---|---|
| `shrink4` | 51° | −4% | 줄어든다 |
| `shrink2` | 53° | −2% | 줄어든다 |
| `neutral` | 54.5° | 0% | 거의 그대로 (|ε| ≤ 0.5%면 정답) |
| `grow2` | 57° | +2% | 늘어난다 |

- **각도와 크기의 대응은 쌍둥이 가정이다.** 방향(중립각 기준의 부호)만 문헌 근거가 있다. 크기 범위 +2%~−4%는 업계 기사 값이다. 크기 채점은 보조 지표로만 쓴다.
- 자세 3 × 여유 길이 4는 [가상 진술 실험](robot-twin-hose-statements.md)과 같다. 결과 채점용 진실은 세 가지다.
  - `exact`: hose.py
  - `cable`: MuJoCo 케이블, 예측 모형의 감김 항 0
  - `cable+wrap`: 같은 케이블, 감김 항 불일치

## 3. 설명 수준
| 수준 | 내용 | 세계 구분 |
|---|---|---|
| `L0` | 협동로봇(6축, 중부하)의 손목에 유압 툴이 달려 있고, 공급 호스가 전완 클램프에서 툴로 이어진다. 사용 압력에서 작업한다. | 불가. 기본 prior를 잰다 |
| `L1` | L0 + 호스 규격(SAE 100R2AT형 2층 와이어 꼰 호스, 내경 1/4"), 호스 길이와 여유(현 길이의 1.05–1.35배), 사용 압력(정격 사용 압력의 100%) | 불가. 호스 종류를 알면 답이 달라지는지 본다 |
| `L2` | L1 + 와이어 꼰 각도(세계별 51°, 53°, 54.5°, 57°) | 가능. 중립각 규칙을 알아야 한다 |

- 설명에 다음 말을 쓰지 않는다: neutral angle, magic angle, 54.7, elongate, contract, shorten, lengthen, zero length change. 테스트로 확인한다.
- **누설 처리(연구자 결정 2026-11-12):** neutral 세계 각도를 교과서 값 54.7° 대신 54.5°로 둔다. 숫자 자체가 힌트가 되지 않게 하기 위해서다. 54.5°는 중립각에서 0.2° 떨어져 있어 정답을 "거의 그대로"(|ε| ≤ 0.5%)로 둔다. 금지어에 "54.7"을 넣어 테스트로 확인한다.

## 4. 질문 문구와 응답 형식 (초안)
> 이 호스에 사용 압력을 걸었을 때 호스 길이가 압력이 없을 때와 비교해 어떻게 바뀌는지 추정하라. 그 결과 툴을 J6 축으로 돌릴 수 있는 범위가 넓어지는지, 좁아지는지, 그대로인지도 답하라.

```json
{"length_change_pct": -3.0, "direction": "shorter", "j6_range": "narrower",
 "confidence": 0.6, "rationale": "one or two sentences"}
```

- `direction` ∈ {shorter, longer, unchanged}. `j6_range` ∈ {narrower, wider, unchanged}.
- `direction`과 `length_change_pct`의 부호가 다르면 "내부 불일치"로 기록한다. 채점에는 `length_change_pct`를 쓴다.
- `j6_range`는 일관성 확인용이다. 정답 관계는 짧아짐 → 좁아짐이다.
- 형식이 틀린 응답은 파싱 실패로 기록하고 다시 묻지 않는다(CCPP와 같다).

## 5. 모델과 표본
- 모델: CCPP 본 수집과 같은 다섯 개(`models.tsv`): gpt-oss-120b, qwen3-30b-a3b-instruct, gpt-oss-20b, gemma3-27b, llama33-70b. 비교 가능성을 위해 바꾸지 않는다.
- 표본: 조건마다 temperature 0.7로 20회, temperature 0으로 1회.
- 프롬프트: L0 1 + L1 1 + L2 4 = 6개. 모델당 6 × 21 = 126회, 합계 630회 호출.
- 데이터 조건은 `D0`(데이터 없음)만이다. 창 요약을 주는 `D1`은 넣지 않는다(연구자 결정 2026-11-12, §12).
- 실행: 서버(H200) vLLM, `analysis/llm_statements/run_all.sh`와 같은 방식. 수집 코드 `collect_hose.py`는 아직 없다(§11).

## 6. 구조 채점
- **방향:** 정답 세계에서 `length_change_pct`의 부호가 맞으면 정답이다. neutral 세계는 |값| ≤ 0.5%면 정답이다. **p_dir = 방향 정답 비율.**
- **엄격한 오답:** 부호가 반대인 경우다. neutral 세계에서는 |값| > 2%면 오답이다.
- **크기 오차:** |값 − ε|, 퍼센트포인트. 보조 지표다.
- L0·L1 진술은 세계와 무관하게 받는다. 그래서 네 세계의 정답에 각각 채점한다.

## 7. 결과 채점
- 진술 ε_s = `length_change_pct`/100을 [−8%, +4%]로 자른다. 자른 비율을 보고한다.
- 넣을 곳: `hose_statements.py`(과제 B)와 `hose_gate_mismatch.py`의 파이프라인. 실제 진술을 받는 연결부를 새로 만든다.
- 집계 방식:
  - (가) 표본 하나씩
  - (나) 20개 표본의 중앙값
  - (다) temperature 0
- 잡음 σ ∈ {0.2, 1.0} Nm, 진실 ∈ {exact, cable, cable+wrap}, 반복 20회. seed는 수집 전에 고정한다.
- 지표: 평균 오차(°), 넘침 비율(> 2°), 비대칭 손실(c ∈ {1, 3, 10}), 관문 통과율.
- **비교군(G2와 같은 원칙):**
  - `D_shrink`: 도메인 기본값 −4%(업계 범위의 수축 끝)
  - `D_zero`: 압력 무시. `R0`와 같다.
  - `P_rand`: 부호 무작위 ±2%
  - `ORACLE`: 정답 ε

## 8. 사전 예측
| # | 예측 |
|---|---|
| HP1 | L0·L1에서 다섯 모델 중 셋 이상이 세계와 무관하게 "줄어든다"를 낸다. 그래서 L0·L1의 p_dir ≤ 0.5다 |
| HP2 | L2에서 p_dir ≥ 0.75를 내는 모델은 둘 이하다. 가장 큰 모델(120b)이 그중 하나다 |
| HP3 | L2에서 세계와 무관하게 같은 방향을 내는 모델이 셋 이상이다(C2의 "기본 답에 끌림" 재현) |
| HP4 | 크기 오차의 중앙값이 1 퍼센트포인트를 넘는다 |
| HP5 | p_dir < 0.6인 모델에서 `R2`의 평균 오차가 `R0`보다 크다. `safe`는 p_dir ≥ 0.25인 모든 모델에서 `R0` 이하다(σ = 1, `exact` 진실) |
| HP6 | `cable+wrap` 진실에서, 기본값 진술(−4% 근처)의 통과율은 `gate_nom`이 `gate_cal_infl`보다 높다 |
| HP7 | `j6_range`와 `length_change_pct` 부호의 내부 불일치율이 10%를 넘는 모델이 하나 이상 있다 |

## 9. 이 수집이 주장하지 않는 것
- 실제 호스에서 LLM이 맞는다는 주장은 하지 않는다. 정답은 쌍둥이 가정(각도와 크기의 대응)과 문헌의 방향 규칙에서 나온다.
- 크기 정답은 가정값이다. 크기 오차로 모델을 순위 매기지 않는다.
- 실데이터가 없으므로 C4에 해당하는 주장은 없다.

## 10. 위험
- 중립각 규칙은 교과서에 있는 지식이다. 큰 모델은 L2에서 쉽게 맞힐 수 있다. 그래도 p_dir이 높게 나오는 것 자체가 결과다. 이때는 기준선(`safe` 0.25, `R2` 0.6)과 비교해 "어떤 모델이면 써도 되나"를 답한다.
- L2의 각도 숫자가 세계마다 달라서, 모델이 각도 크기에 따라 단순히 비례로 답할 수 있다. HP3과 크기 오차로 확인한다.
- 다섯 모델 중 셋이 같은 `weaker` 계열이라는 C2의 지적이 여기에도 그대로 적용된다.
