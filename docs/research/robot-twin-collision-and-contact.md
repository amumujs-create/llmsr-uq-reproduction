# 로봇 쌍둥이: 충돌 감지 오탐 탐색 결과와 접촉 물리(PyBullet/MuJoCo) 후보 (2026-11-12)

**상태: 설계용 탐색 + 후보 비교.** LLM 답 미사용, 채점 없음, 사전 등록 아님.
관련: [토크 포화](robot-twin-saturation-design.md), [저속 마찰](robot-twin-friction-design.md), [아이템 비교](reviews/2026-11-12-doosan-extrapolation-items.md)

## 결론
- **충돌 감지 오탐은 속도 축 외삽 과제로 쓸 수 없다.** 무접촉 잔차가 속도에 거의 반응하지 않는다(시나리오 18개 중앙값 max/min 1.01, 최대 1.48). 오탐 여부는 **미등록 페이로드의 중력 토크**가 정한다. 속도 0.1–1.0 사이에서 오탐이 시작되는 시나리오는 0/18이다. 토크 포화와 같은 이유다. H2017은 정격 속도에서 관성 토크가 중력보다 훨씬 작다.
- **로봇 자체(관절 동역학)보다 로봇이 다루는 물체의 접촉 물리가 레짐 과제에 더 맞다.** 미끄러짐과 넘어짐은 문턱(꺾임)이 분명하다. 문턱 위치가 물체 질량·마찰·크기에 따라 움직인다. 물리 지식(μg, 무게중심 높이 대 폭)으로 위치를 짐작할 수 있다. PyBullet이나 MuJoCo의 접촉 시뮬레이션이 필요한 영역이다.

## 1. 오탐 쌍둥이 결과
코드 `analysis/robot_twin/collision.py`, `explore_collision.py`, 출력 `runs/explore_collision.txt`.

가정: 감지 임계 = 쌍둥이 토크 한계의 10%, 마찰 Fc = 한계의 2%, Fs/Fc 1.5, vs 0.03 rad/s, 등록 페이로드 10 kg, 미등록 1/3/5 kg. 모두 두산 값이 아니다.

| 결과 | 값 |
|---|---|
| y(s)의 속도 민감도(max/min, 18시나리오) | 중앙값 1.01, 최대 1.48(`lift_reach`) |
| 모든 속도에서 오탐 / 오탐 없음 / 범위 안에서 시작 | 4 / 14 / **0** |
| s = 1에서 성분(미등록 3 kg): 페이로드 중력 / 페이로드 전체 / 저속 마찰 | 0.42–0.65 / 0.42–0.91 / 0.10 |

미등록 페이로드 축으로 보면 잔차가 거의 정확히 비례한다(테스트로 확인: 3 kg/1 kg = 3.000). 꺾임이 없는 직선이라 외삽이 쉽다. 레짐 과제가 아니다.

검증: `tests/test_robot_twin.py` 12개 통과(오탐 테스트 2개: 모델 오차 0이면 잔차 0, 정적 잔차가 미등록 질량에 비례), 전체 168 passed.

## 2. 접촉 물리 후보 (PyBullet/MuJoCo)
| 후보 | 외삽 축 | 꺾임(레짐) | 위치를 정하는 물리 | 기본값 하나로 맞히나 |
|---|---|---|---|---|
| **A. 쟁반 운반(비파지)** | 운반 가속도 ↑ | 미끄러짐 시작 a ≈ μg, 넘어짐 시작 a ≈ g·(w/2)/h | 마찰계수, 무게중심 높이/폭 | 아니오(물체마다 다름) |
| B. 그리퍼 파지 운반 | 가속도 ↑ | 파지 미끄럼 a ≈ μ·F_grip/m − g 성분 | 마찰, 파지력, 질량 | 아니오 |
| C. 물체 밀기 | 미는 높이·속도 ↑ | 미끄러짐 → 넘어짐 전환 | 높이/폭, μ | 아니오 |

A는 같은 질문에 두 레짐(미끄러짐, 넘어짐)이 있고, 어느 쪽이 먼저 오는지가 물체 비율에 따라 바뀐다. "위치는 맞히고 모양·종류는 기본 답에 끌린다"(C2)를 시험하기 좋다.

## 3. 선행연구 (빠른 확인, 검색 각 1회)
- 쟁반 운반: "Hearing the Slide"(2506.09169)는 빠른 운반에서 쿨롱 마찰 제약이 부정확하다는 점을 들어 음향으로 마찰계수를 학습한다. OOD 물체 실험이 있다. CV-MPC(2412.00086)는 앙상블로 OOD 상태를 벌점 처리한다. DART(2604.17833)도 있다. **넘어짐은 부수적으로만 다뤄진다.** 학습 범위(가속도) 밖으로 레짐 위치를 외삽하는 연구는 찾지 못했다.
- 파지 미끄럼: 미끄럼 시작 마찰비가 가속도에 따라 변한다는 보고(TUM)가 있다. 처음 보는 물체로의 일반화(SlipSense 2609.15910)도 있다. 빠른 운반 가속도로의 외삽은 찾지 못했다.

## 4. 실행 환경
- PyBullet은 이 Mac(시스템 Python 3.9)에서 빌드가 실패했다(2026-11-05). Python 3.11 환경을 따로 만들거나 MuJoCo(3.2.3 설치 확인, 접촉 지원)를 쓴다.
- 쟁반·물체는 단순 상자로 충분하다. H2017 URDF는 끝단 궤적을 만드는 데만 쓴다.
