# 사전 등록: 창 밖 구간 — 위치가 걸러져도 "장치가 있다"는 답은 버리지 않는 조립 (`HA_fb`)

작성: 2026-11-11 (계산 전, 코드 작성 전). 연구자 지시("등록하고 실행")로 확정.  
관련: [창 밖 구간 전용 등록·결과·§11 사후 진단](ccpp-twin-outside-regime.md), [검토](reviews/2026-11-11-data-silent-regime.md).

새 LLM 수집 없음. 이 문서를 커밋한 뒤 코드를 쓰고 한 번만 계산한다.

## 1. 지위: 개발 자료에서의 판정 (확증 아님)

**이 규칙은 [§11 사후 진단](ccpp-twin-outside-regime.md)에서 같은 수집 답을 본 뒤 만들었다.** 그래서 이 등록의 판정은 "규칙을 고치면 같은 답에서 결과가 어떻게 바뀌는가"이고, **독립 확증이 아니다.** seed는 새것(`outside2|`)이지만 진술이 같으므로 seed만으로는 독립이 되지 않는다. 원고에서 확증으로 인용하지 않는다. 확증에는 새 모델 또는 새 세계의 수집이 필요하다(§8).

그래도 등록하는 이유: 규칙·지표·기준을 계산 전에 고정해 두어야, 결과를 보고 규칙을 다시 손보는 일을 막을 수 있다. 그리고 아래 §2의 일반 규칙에는 아직 보지 않은 부분이 있다.

## 2. 규칙 `HA_fb`

`HA`([힌트 조립](ccpp-hint-assembly.md), `assemble`)의 결과에서 시작해 한 단계만 더한다.

- S2 답에서 어떤 장치를 **"있다/도달한다"고 한 답이 과반**(답 수의 절반 초과)인데, `HA` 결과에 그 장치 쪽(아래/위) 경계가 **없으면**, 그쪽에 **기본 위치**의 경계를 넣는다.
- 기본 위치는 `D_real`의 숫자 그대로: 아래쪽 8°C, 위쪽 27°C.
- `HA`가 이미 그쪽 경계를 냈으면 그 위치(LLM 위치)를 그대로 쓴다.
- **네 장치 모두에 같은 규칙을 적용한다**: 가스터빈 출력 제한(아래), 흡기 결빙 방지 가열(아래), 흡기 증발 냉각(위), 배기·증기 쪽 제한(위). "있다"의 정의는 `assemble.s2_parts`가 읽는 필드와 같다(`reached_in_range` 또는 `active`가 참).
- 그 뒤는 `HA`와 같다: 창 검사 관문(`GUARD_MARGIN` 2.0) + blend 0.5.
- S2 답이 없는 칸은 `HA`와 같다.

**이미 본 것과 아직 안 본 것.** 가스터빈 출력 제한의 "도달한다" 비율은 봤다(상한 세계 0.90–1.00, 다른 세계 0.00). **나머지 세 장치의 "있다" 비율은 보지 않았다.** 모델이 장치가 없는 세계에서 결빙 방지나 배기 제한을 "있다"고 하면 이 규칙은 틀린 경계를 넣고 꺾임 없는 과제에서 해를 끼친다. 그래서 H1(해 없음)은 결과를 모르는 판정이다.

보고용 변형 `HA_fb_gt`: 가스터빈 출력 제한에만 대체를 적용한 것(본 것에만 맞춘 좁은 규칙). 판정에 쓰지 않는다.

## 3. 과제·비교군·지표

[창 밖 구간 전용 등록 §3–§5](ccpp-twin-outside-regime.md)와 **완전히 같다**: 과제 7개(꺾임 3, 꺾임 없음 4), δ ∈ {1, 2, 4}, w ∈ {5, 10}, n ∈ {50, 150, 500}, σ ∈ {2.15, 4.3, 8.6}, 반복 20, 7,560행. 비교군 `R0`, `ORACLE`, `D_real`, `D_aware`, `P_side`. 지표는 과제마다 같은 무게의 상대 RMSE, 해 = > 1.10. 검증 6칸.

seed 접두만 `outside2`로 바꾼다(잡음 `outside2|noise|…`, 표본 `outside2|sample|…`).

같은 seed에서 원래 `HA`도 계산해 나란히 보고한다(판정 아님).

## 4. 예측과 판정

기준은 앞 등록과 같다. `HA` 자리에 `HA_fb`를 넣는다.

| | 기준 | 계산 전 예상 |
|---|---|---|
| H0 전제 (LLM 무관) | `ORACLE` 꺾임 평균 < 0.75 그리고 `D_real` 꺾임 없음 해 비율 ≥ 0.30 | 성립(앞 실행과 같은 구조) |
| H1 해 없음 | 전체 행 해 비율 ≤ 0.10인 칸 ≥ 5/6 | **모름.** 안 본 세 장치의 거짓 "있다"에 달렸다 |
| H2 선형보다 낫다 | 꺾임 평균 ≤ 0.95인 칸 ≥ 4/6 | 성립 예상(상한 과제가 0.70 근처로) |
| H3 세계를 모르는 고정값보다 낫다 | 전체 평균 < `D_real` 전체 평균인 칸 ≥ 4/6 | H1에 달렸다 |
| H4 무작위 위치보다 낫다 | 꺾임 평균 < `P_side` 꺾임 평균인 칸 ≥ 4/6 | 성립 예상 |
| H5 설명을 읽는 고정 규칙보다 낫다 | 꺾임 평균 < `D_aware` 꺾임 평균인 칸 ≥ 4/6 | 4/6 근처, 불확실. 상한 과제는 `D_aware`와 같아지고 차이는 증발 위치에서만 난다 |

종합: H0–H4 모두 성립이면 "1단계(개발 자료)", H5까지면 "강한 주장(개발 자료)".

## 5. 미리 적는 해석

- **H1 불성립**: 모델이 없는 장치를 "있다"고 한다 → 일반 대체 규칙은 안전하지 않다. `HA_fb_gt`(보고용)가 안전하더라도 그것은 본 것에 맞춘 규칙이므로 주장으로 쓰지 않는다. "장치 유무 읽기는 출력 제한에서만 믿을 만하다"는 진단으로 적는다.
- **H1–H4 성립, H5 불성립**: 조립을 고쳐도 LLM은 사람 규칙과 비긴다. LLM의 추가 값은 증발 위치뿐이라는 뜻.
- **H5 성립**: 좋은 숫자지만 §1의 지위 때문에 확증이 아니다. "새 모델·새 세계에서 등록할 가치가 있다"까지만 말한다.
- 결과를 본 뒤 대체 규칙·기본 위치·과반 기준을 바꾸지 않는다.

## 6. 한계

- §1: 같은 답에서 만든 규칙을 같은 답으로 잰다.
- 기본 위치(8, 27°C)는 `D_aware`와 같은 숫자다. 대체가 일어난 칸은 그 과제에서 `D_aware`와 같아진다. 즉 이 규칙이 `D_aware`를 넘는 부분은 LLM이 낸 위치(주로 증발)뿐이다.
- "평평" 진술의 모양은 고정이다. 결빙 방지처럼 정답 모양이 다른 장치는 이 등록의 세계에 없다.
- 쌍둥이 한정.

## 8. 확증에 필요한 것 (이 등록 밖)

`HA_fb`를 고정한 채, 이 규칙을 만들 때 보지 않은 진술로 판정한다: (a) 새 모델의 S0·S2 수집, 또는 (b) 기본값이 정해지지 않는 새 세계. 둘 다 연구자 서버가 필요하다.

### 9.3 왜 H1이 무너졌나

미리 적은 경우 그대로다: **모델이 없는 장치를 "있다"고 한다.** 보지 않았던 세 장치의 "있다" 비율에서 드러났다.

- 배기·증기 쪽 제한: gemma는 `base`에서도 10/10이 "있다". 그래서 장치가 없는 세계에 "27°C 위 평평"이 들어간다.
- 결빙 방지 가열·추운 쪽: llama는 `base`에서 "8°C 아래"가 들어갔다(`base|cold` 평균 3.54, `D_real`과 같은 해).
- 대체된 진술 표(`summary.txt`)에서 `base` 세계의 열 칸 중 여덟 칸이 틀린 경계를 얻었다.
- 반대로 가스터빈 출력 제한의 "도달한다"는 열 칸 모두 세계를 정확히 가렸다(§11 진단과 같음).

즉 **"장치가 있다"는 답을 믿을 수 있는지는 장치마다 다르다.** 설명에 명시된 장치(출력 제한, 증발 냉각기)는 정확히 읽고, 설명에 없는 장치(배기 제한, 결빙 방지)는 기본으로 "있다"고 하는 모델이 있다. 원래 `HA`가 이런 장치에 S0 일치(3°C 이내)를 요구한 것은 이 거짓 "있다"를 거르는 역할을 하고 있었다.

### 9.4 보고용 `HA_fb_gt` (판정 아님, 본 것에 맞춘 좁은 규칙)

출력 제한에만 대체를 적용하면: 꺾임 평균 0.654–0.903, 전체 해 비율 0.001–0.025, 꺾임 없음 해 비율 0.000(검증 6칸). `D_aware`(0.818)보다 낮은 칸은 4/6. **이 수치는 주장으로 쓰지 않는다**(§5에 미리 적음). 답을 본 장치에만 맞춘 규칙이기 때문이다.

### 9.5 해석과 다음

- 조립을 고치면 꺾임 과제의 침묵은 풀린다(H2 4/6 → 6/6, H4·H5 3/6 → 4/6). 그러나 일반 규칙으로는 안전을 잃는다(H1 6/6 → 0/6).
- 얻은 진단: LLM의 "장치 유무 읽기"는 **설명에 명시된 장치에 한해** 정확하다. 설명에 없는 장치에 대해서는 모델 기본 답이 나온다(C2 "기본 답에 끌린다"와 같은 현상이 장치 유무에서도 나타남).
- 규칙을 "설명에 명시된 장치에만 대체"로 다시 좁히는 것은 이 결과를 본 뒤의 두 번째 사후 설계다. **같은 답으로 더 돌리지 않는다.** 그 규칙의 검정은 새 모델 또는 새 세계 수집에서만 한다(§8).
