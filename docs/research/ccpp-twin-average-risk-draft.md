# 평균 오차로 다시 읽기: 사후 기록, 냉정한 재검토, 등록 설계 초안 (2026-11-12)

**정정(같은 날, [독립 검토](reviews/2026-11-12-independent-review.md) 뒤): 아래 `READ_EDGE`는 정답 라벨을 쓴 상한이다. 단어 찾기 규칙을 실제로 구현해 돌린 값이 아니다. "LLM 없이 설명만 읽는 규칙이 모든 LLM 규칙보다 낫다"는 측정이 아니라 가정이다. §3 초안은 검토자가 "긍정 결과가 나와도 설득되지 않는다"고 판단했다. 등록에 쓰기 전에 검토 문서 §4를 반영해야 한다.**

상태: **사후 기록과 초안. 등록 아님. 판정 아님.** [깨끗한 창 진단 확인](ccpp-twin-clean-diagnostic.md)의 판정(C1–C7 성립, P1–P3 불성립)은 바뀌지 않는다.

코드: `analysis/ccpp_twin/explore/average_risk_posthoc.py`. 산출물 `analysis/ccpp_twin/runs/explore_average_risk/summary.txt`. LLM 답을 새로 읽지 않고 이미 채점한 산출물만 다시 집계한다.

## 1. 사후 기록

확인 채점의 상대 오차를 절대 오차(MW)로 바꿔 평균했다. 꺾임 과제 여섯 개의 평균과 꺾임 없는 과제 여섯 개의 평균을 반반으로 합쳤다("균형 평균").

### 1.1 확인 묶음 (새 네 모델)

| 규칙 | LLM | 꺾임 과제 | 꺾임 없는 과제 | 균형 평균 | R0 대비 |
|---|---|---|---|---|---|
| R0 (데이터만) | 없음 | 11.06 | 2.24 | 6.65 | 0 |
| 항상 꺾임 가정 (`EDGE_h`) | 없음 | 4.37 | 7.56 | 5.97 | −10% |
| 정답 위치 진술 (`ORACLE`) | 없음 | 6.76 | 2.24 | 4.50 | −32% |
| 설명을 읽어 위치 진술 (`READ`) | 없음 | 8.84 | 2.24 | 5.54 | −17% |
| 설명에서 쪽만 읽고 창 끝부터 평평 (`READ_EDGE`) | 없음 | 4.37 | 2.24 | 3.30 | −50% |
| deepseek `AND` | 있음 | 4.37 | 2.97 | 3.67 | −45% |
| phi4 `AND` | 있음 | 4.37 | 4.27 | 4.32 | −35% |
| mistral `AND` | 있음 | 6.79 | 3.00 | 4.89 | −26% |
| granite `AND` | 있음 | 7.83 | 2.24 | 5.03 | −24% |
| 네 모델의 고정 규칙 (`FROZEN`) | 있음 | 9.31–10.88 | 2.24–2.59 | 5.89–6.56 | −1%–−11% |

`READ_EDGE`는 이 문서에서 새로 정의한 기준선이다. 설명에 적힌 장치의 쪽만 사람이나 단어 찾기 규칙으로 읽고, 그 쪽에 "창 끝부터 평평, 절반 반영"을 쓴다. 이 과제 묶음에서는 꺾임 과제에서 `EDGE_h`, 꺾임 없는 과제에서 R0와 같다.

## 2. 냉정한 재검토

직전 대화에서 "평균 오차로 보면 LLM이 네 모델 모두에서 도움이 됐다"고 말했다. R0 대비로는 사실이다. 그러나 그 문장은 오해를 부른다. 아래 여섯 가지를 함께 봐야 한다.

1. **아무 지식 없이 "항상 꺾임이 있다"고 가정해도 R0보다 10% 낫다.** 균형 평균이라는 기준이 그만큼 느슨하다. 꺾임 과제의 R0 오차(11 MW)가 꺾임 없는 과제(2 MW)보다 훨씬 크고, 꺾임 비율을 반으로 놓았기 때문이다. "R0를 이겼다"는 LLM의 공이 아니다. 과제 설계의 공이다.
2. **LLM 없이 설명만 읽는 규칙이 모든 LLM 규칙보다 낫다.** `READ_EDGE` 3.30 MW. 확인 묶음에서 가장 좋은 LLM 규칙이 3.67 MW다. 이 과제에서 LLM은 사람이 한 줄 읽으면 되는 일을 덜 정확하게 했다.
3. **LLM의 고유한 몫은 "항상 가정"(5.97)과 "읽기"(3.30) 사이다.** 그 간격 중 회수한 비율은 deepseek 86%, phi4 62%, mistral 40%, granite 35%다. 정보는 있다. 그러나 상한은 LLM 없이 닿는 값이다.
4. **이득 크기가 부풀려져 있다.** 정답 위치를 주면 4.50 MW인데 위치 없이 창 끝부터 평평하게 하면 3.30 MW다. 정답을 알 때보다 모를 때가 낫다는 것은 혼합 0.5와 시험 구간 위치의 상쇄 효과다. 상쇄가 없는 조건에서 이득은 −32% 근처가 상한일 수 있다.
5. **기준을 결과를 본 뒤에 바꿨다. 세 번째다.** 고정 규칙이 떨어진 뒤 `AND`를 골랐고, `AND`가 안전 기준에서 떨어진 뒤 평균 기준을 꺼냈다. 실패할 때마다 다른 잣대로 다시 읽는 것은 전형적인 사후 합리화의 모양이다. 이 표는 주장의 근거가 될 수 없다.
6. **통계적 뒷받침이 약하다.** 발전소 여섯 개 중 셋은 숫자만 다른 출력 제한이다. 모델 네 개. 구간 추정이 없다. 쌍둥이 한정이고, 깨끗한 창이 나오도록 급하게 켜지는 세계를 골랐다.

### 2.1 감시에 대하여

- 이 대화의 검토자는 독립적이지 않다. 같은 맥락을 공유하고, 연구자가 기대를 말한 직후에 유리한 재해석을 내놓았다. 위 5번이 그 예다.
- 등록과 "한 번 채점"은 지켜졌고, 그래서 긍정 주장이 두 번 떨어졌다. 절차는 작동했다. 약한 곳은 떨어진 뒤의 재해석이다.
- 독립적인 감시가 필요하다. §4에 방법을 적는다.

## 3. 등록 설계 초안 (초안. 연구자 결정 필요)

### 3.1 질문

데이터에 정보가 없을 때 LLM을 쓰면, (가) 지식 없는 규칙보다, (나) 설명을 기계적으로 읽는 규칙보다 평균 오차가 줄어드는가. 틀렸을 때의 손실은 한도 안인가.

### 3.2 §2에서 나오는 설계 요건

| 요건 | 이유 |
|---|---|
| 기준선에 "항상 꺾임 가정"과 "기계적 읽기"를 넣는다. R0만 이기는 것은 주장으로 삼지 않는다 | §2의 1, 2 |
| LLM이 필요한 설명 조건을 만든다. 기계적 읽기가 실패하는 설명이어야 한다 | §2의 2 |
| 장치 없는 발전소를 넣고, 꺾임 비율을 여러 값으로 보고한다 | §2의 1 |
| 상쇄 효과를 걷어낸다 | §2의 4 |
| 새 모델, 새 발전소. 판정 기준은 답을 열기 전에 고정 | §2의 5 |
| 구간 추정을 낸다. 서로 다른 종류의 발전소를 늘린다 | §2의 6 |

### 3.3 초안 내용

**자료**

- 발전소: 장치 종류를 넷 이상으로 늘린다(출력 제한, 증발 냉각, 냉각기, 결빙 방지, 고온 발전기 제한). 장치 없는 발전소를 전체의 1/3 이상 넣는다. 지금까지 쓴 열 개 발전소는 개발용이다.
- 설명 조건 둘:
  - 깨끗한 설명. 지금과 같은 한 문단.
  - 지저분한 설명. 같은 사실을 여러 문단에 흩고, 무관한 설비 문장과 "검토했으나 설치하지 않음" 같은 헷갈리는 문장을 섞는다. 장치 이름을 쓰지 않고 기능으로만 적는 경우를 포함한다. 문장은 답을 열기 전에 고정하고, 기계적 읽기 규칙도 같은 시점에 고정한다.
- 모델: 한 번도 쓰지 않은 모델 넷 이상. 지금의 아홉 모델은 모두 개발용이 된다.

**규칙** (답을 열기 전에 하나로 고정)

- 질문 형식은 근거 인용 탐색 결과를 보고 개발 모델에서 하나를 고른다.
- 결합은 "창 끝부터 평평"이다. 혼합 비율은 하나로 고정한다.

**기준선**

| 이름 | 내용 |
|---|---|
| R0 | 데이터만 |
| ALWAYS | 양쪽 모두 꺾임 가정 |
| KEYWORD | 미리 고정한 단어 찾기 규칙으로 설명을 읽음 |
| HUMAN | 설명을 읽은 사람의 유무 판단(가능하면 연구자 외 1인) |
| EXIST | 정답 유무를 아는 상한 |

**지표**

- 주 지표: 절대 오차의 평균. 꺾임 비율 0.25, 0.5, 0.75에서 각각 보고한다. 주 판정에 쓸 비율은 등록 때 하나로 정한다.
- 상쇄 효과 통제: 시험 구간을 창 끝에서 가까운 띠와 먼 띠로 나눠 따로 보고한다. 혼합 1.0에서 정답 위치를 쓴 값을 참고 상한으로 함께 낸다.
- 안전: 과제별 최악 비율과 손실 한도 성립 비율.
- 구간: 발전소 단위 재표집으로 낸다.

**주장 후보**

| | 주장 | 판정 방식 초안 |
|---|---|---|
| A1 | LLM 규칙이 ALWAYS와 R0보다 낫다 | 모델 넷 중 셋 이상에서 구간이 0을 넘지 않음 |
| A2 | 지저분한 설명에서 LLM 규칙이 KEYWORD보다 낫다 | 위와 같음. **이 주장이 논문의 핵심이다** |
| A3 | 깨끗한 설명에서 LLM 규칙이 KEYWORD에 크게 뒤지지 않는다 | 미리 정한 허용 폭 안 |
| A4 | 틀렸을 때의 손실이 한도 안이다 | 한도 성립 비율 0.99 이상 |
| A5 | 이득이 나는 최소 꺾임 비율 | 판정 없이 보고 |

A2가 떨어지면 "LLM이 필요하다"는 주장은 못 한다. 그 경우의 해석도 등록 때 미리 적는다.

### 3.4 초안의 약점 (미리 적음)

- 지저분한 설명을 연구자가 직접 쓴다. KEYWORD가 지도록 쓸 수 있다. 문장 작성자와 KEYWORD 규칙 작성자를 나누거나, 실제 설비 문서의 문장을 가져와야 한다.
- 여전히 쌍둥이다. 실제 자료가 없으면 상위 저널에서 약하다.
- 수집량이 크다. 발전소 수 × 설명 조건 둘 × 모델 넷 이상.

## 4. 감시를 세우는 방법

| 방법 | 막는 것 | 비용 |
|---|---|---|
| 등록 문서를 OSF 같은 외부 등록소에 시간 기록과 함께 올린다 | 등록 내용의 사후 수정 | 낮음 |
| 등록 전에 지도교수나 동료 한 명이 주장과 기준선을 검토한다 | 유리한 과제 설계, 약한 기준선 | 중간 |
| 맥락을 공유하지 않는 별도 검토자에게 등록 문서만 주고 반박을 시킨다 | 이 대화 안의 확증 편향 | 낮음 |
| 판정 뒤의 재해석은 "사후" 절에만 쓰고, 다음 등록의 근거로만 쓴다 | 사후 합리화 | 이미 시행 중 |
| 기준선과 지저분한 설명의 작성자를 연구자와 분리한다 | 허수아비 기준선 | 중간 |

깃 커밋 기록은 지금도 시간 증거가 된다. 다만 저장소 주인이 연구자 본인이라 외부 등록소보다 약하다.
