# 깨끗한 창 실험: 발전소 묶음과 수집 (2026-11-12)

**상태: 수집 준비. 실험 등록 전.** 여기서 정하는 것은 발전소 설명문과 수집 방법뿐이다. 방법, 과제 창, 지표, 판정 기준은 아직 정하지 않았고 별도 문서로 사전 등록한다. 진행 중인 확증([등록](ccpp-twin-outside-confirmation.md))과는 별개다.

배경: [과제 후보 탐색](ccpp-twin-explore-clean-tasks.md), [과제 선별 검토](reviews/2026-11-12-info-free-task-selection.md), [구조와 숫자 분리 탐색](ccpp-twin-explore-sim-assist.md).

## 1. 목적

학습 구간에 레짐 흔적이 없고(잡음 없는 값으로 0.5 MW 이하), 데이터만 쓰면 외삽이 9–13 MW 틀리는 과제에서, LLM 진술이 도움이 되는지 본다. 꺾임 위치가 발전소마다 달라서 고정 기본값(8°C, 27°C)으로는 따라올 수 없게 한다.

## 2. 발전소 묶음

쌍둥이 설정: `analysis/ccpp_twin/clean_worlds.py`. 급하게 켜지도록 `cap_softness_mw` 0.5(기본 2.0), `evap_ramp_c` 0.3(기본 3.0)을 쓴다.

| 발전소 | 방향 | 설명에 적는 숫자 | 꺾임(1 MW 도달 온도) | LLM 답 출처 |
|---|---|---|---|---|
| `base` | 대조 | 없음 | 없음 | 기존 수집 |
| `cap357` | 저온 | 제한 357 MW | 9.5°C | 기존 `cap_strong` 답(설명문 동일) |
| `cap353` | 저온 | 제한 353 MW | 11.0°C | **새 수집** |
| `cap350` | 저온 | 제한 350 MW | 12.5°C | **새 수집** |
| `cap346` | 저온 | 제한 346 MW | 14.5°C | **새 수집** |
| `evap22` | 고온 | 22°C 넘으면 가동 | 21.5°C | **새 수집** |
| `evap24` | 고온 | 24°C 넘으면 가동 | 23.5°C | 기존 `evap` 답(설명문 동일) |
| `evap26` | 고온 | 26°C 넘으면 가동 | 25.5°C | **새 수집** |
| `chill20` | 고온 | 설정 20°C | 20.0°C | 새 세계 단계의 `chill` 답 |
| `chill24` | 고온 | 설정 24°C | 24.0°C | **새 수집** |

- `cap357`, `evap24`는 설명문이 기존 것과 글자 그대로 같아서 다시 묻지 않는다. 쌍둥이만 급하게 켜지는 설정으로 바뀐다.
- L1 설명(숫자 없음)은 같은 종류 발전소끼리 글자 그대로 같으므로 다시 묻지 않는다. 숫자가 없으면 발전소를 구별할 수 없다는 점은 L1의 한계로 적는다.

## 3. 질문문

코드: `analysis/llm_statements/collect_cleanworld.py`. 테스트: `tests/test_collect_cleanworld.py`.

- 설명 = L0 + 기존 L1 문장 + 15°C 출력 문장 + L2 문장. L2 문장은 기존 문장에서 숫자 하나만 바꾼 것이다. 코드가 "숫자가 정확히 한 번 나온다"를 확인하고 바꾼다.
- 질문은 `QUESTION`(S0)과 `S2_QUESTION`(S2) 그대로다.
- 발전소 6개 × (S0 21회 + S2 11회) = **모델당 192회.** 온도 0.7 표본에 온도 0 한 번을 더한다.
- 정답 꺾임 위치는 LLM에게 주지 않는다. 금지어 검사를 통과한다.

## 4. 모델과 자료 분리

| 묶음 | 모델 | 용도 |
|---|---|---|
| 개발 | 기존 다섯(`models.tsv`) | 방법을 고르고 다듬는 탐색. 판정에 쓰지 않음 |
| 확인 | 새 넷(`models_new.tsv`) | 등록 후 한 번 채점 |

**규칙: 새 모델의 `runs/cleanworld/` 답은 깨끗한 창 실험을 사전 등록하고 커밋하기 전에는 열어 보지 않는다.** 파일 줄 수와 수집 점검 출력(오류 수, 파싱 실패 수)만 본다. 진행 중인 확증 채점(`outside_confirm.py`)은 이 폴더를 읽지 않는다.

## 6. 한계 (미리 적음)

- 발전소를 급하게 켜지도록 만든 것은 설계 선택이다. 기준을 통과하지 못한 등록 세계(`evap`, `gen_hot`)의 결과도 함께 싣는다.
- 실제 설비가 얼마나 급하게 켜지는지는 문헌으로 확인하지 않았다.
- 꺾임 위치 표는 "평균 차이 1 MW 도달 온도"다. 채점용 정답 위치 정의는 등록 때 정한다.
- 새 모델의 기존 답(본 수집, 새 세계)은 진행 중인 확증에서 먼저 채점된다. 깨끗한 창 실험의 방법은 그 전에 개발 모델만으로 고정하는 것이 가장 깨끗하다. 순서가 바뀌면 그 사실을 등록 문서에 적는다.
