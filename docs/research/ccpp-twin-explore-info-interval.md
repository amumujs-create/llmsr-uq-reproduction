# 탐색: 정보량 I의 검정력과 제약류 구간 (사전 등록 아님)

작성: 2026-11-10  
**지위: 탐색.** 사전 등록 없이 설정을 넓혀 본 계산이다. 여기의 수치는 모두 "탐색" 수치이고 **어떤 판정에도 쓰지 않는다.** 등록 결과는 [정보 축 등록 §9](ccpp-twin-information-axis.md)가 유일하다.  
코드: `analysis/ccpp_twin/explore/info_interval.py` · 결과: `analysis/ccpp_twin/runs/explore_info_interval/{summary.txt, cells.csv.gz}` (6,120행, seed 접두 `explore|`, 등록 seed와 겹치지 않음)

## 1. 왜 했나

정보 축 등록 결과에서 두 후보가 남았다. (A) I가 쌍둥이 꺾임을 못 집은 것이 설정 탓인지(완만한 꺾임·큰 잡음), (B) 제약류 구간이 L을 창 기울기로 잡으면 서는지. 연구자가 "둘 다 해보고 되는 쪽으로 판단"을 요청했다.

## 2. 설정 (등록과 다른 점)

| 항목 | 등록 | 탐색 |
|---|---|---|
| 세계 | `evap`(ramp 3.0), `cap_strong`(softness 2.0), `base` | 여기에 날카로운 변형 `ramp0.5`, `soft0.5` 추가 |

| 구간 L | 물리 기울기 | 물리 / 창 기울기(\|b_AT\| + 2se) / 둘 중 큰 값, 가장자리 예측 오차 덧붙임 유무 |
| 반복 | 20 | 10 |

## 3. 결과 A — I의 검정력과 변화점 외삽

**I는 꺾임이 창 안·가장자리에 있고 꺾임이 날카롭거나 잡음이 작으면 켜진다.** I > 0 비율(n 합침):

| 세계 | δ | σ 0.5 | σ 1.0 | σ 2.15 | σ 4.3 |
|---|---|---|---|---|---|
| `soft2.0`(등록 세계) | −2 | 1.00 | 1.00 | 0.88 | 0.68 |
| | 0 | 1.00 | 0.96 | 0.66 | 0.24 |
| | +2 | 0.10 | 0.00 | 0.00 | 0.00 |
| `ramp3.0`(등록 세계) | −2 | 0.77 | 0.60 | 0.40 | 0.18 |
| | 0 | 0.84 | 0.56 | 0.38 | 0.12 |
| `ramp0.5` | −2 | 1.00 | 1.00 | 0.95 | 0.82 |
| `base`(거짓 양성) | — | 0.29 | 0.06 | 0.02 | 0.01 |

- 등록 계산에서 I가 거의 안 켜진 것은 n ≤ 500, σ ≥ 2.15, 최소 조각 5점 조합 탓이 컸다. n = 2000이면 `ramp3.0`도 0.66–0.90까지 켜진다.
- σ = 0.5에서는 `base` 거짓 양성이 0.29다. 쌍둥이 기본 곡선 자체가 약하게 휘어 있기 때문이다. 문턱 I > 10이면 0.16으로 준다.

**변화점 외삽은 추운 쪽 상한 세계에서만 선다.** I_seg > 10인 행의 상대 RMSE(평균, 괄호는 해 > 1.10 비율):

| 세계 | δ | `R_cp_seg` | `ORACLE` | 꺾임 추정 오차(평균 °C) |
|---|---|---|---|---|
| `soft0.5` | −2 | **0.34** (0.01) | 0.67 | +0.7 |
| | 0 | **0.42** (0.00) | 0.57 | +1.2 |
| `soft2.0` | −2 | **0.40** (0.01) | 0.66 | +1.1 |
| | 0 | **0.43** (0.02) | 0.55 | +1.6 |
| `ramp3.0` | −2 | 0.75 (0.02) | 0.69 | −2.0 |
| | 0 | 0.76 (0.02) | 0.56 | −4.2 |
| `ramp0.5` | −4 | 1.44 (0.55) | 1.42 | −0.5 |
| | −2 | **2.04 (0.97)** | 0.94 | −1.2 |
| | 0 | 0.86 (0.21) | 0.60 | −1.2 |

- 상한 세계: 꺾임이 창 안·가장자리에 있으면 데이터만으로 한 변화점 외삽이 **위치 정답을 받은 진술 조립보다 좋다**(0.34–0.43 대 0.55–0.67). 조립은 섞기 0.5라 절반만 가기 때문이다.
- 증발 세계: 날카로운 변형에서 크게 해롭다. 쌍둥이의 증발 냉각은 켜진 뒤 냉각량이 (AT − 습구온도)에 비례해 계속 커지므로 "꺾인 뒤 한 기울기"가 맞는 꼴이 아니다. 날카로우면 24°C에서 계단처럼 뛰고, 꺾임 직후 좁은 조각에서 잡은 기울기를 창 밖으로 늘리면 틀린다. `ORACLE`도 같은 δ에서 해롭다(평평 가정이 틀림).
- 꺾임이 창 밖(δ > 0)이면 I가 안 켜지고(정상) `R_cp` = `R0`다. 이때는 위치 지식만 도움이 된다(`ORACLE` 0.46–0.62).
- 최소 조각을 키운 `_seg`가 `_5`보다 안정적이다(전체 평균: `base` 1.00 대 1.46, `evap` 1.09 대 1.26, `cap_strong` 0.79 대 0.88).

**LLM 진술은 여기서도 고정값을 못 이긴다.** `cap_strong` 전체 평균: `gpt-oss-120b|L1` 0.67–0.83, `D_real` 0.65–0.70, `ORACLE` 0.55–0.67.

## 4. 결과 B — 제약류 구간

L = 창 기울기 + 가장자리 덧붙임, 표준 쌍둥이(`ramp3.0`, `soft2.0`, `base`), 커버리지 / 평균 폭(MW):

| 세계 | δ | 진술 없음 | `ORACLE` 진술 | `D_real` |
|---|---|---|---|---|
| `evap` | −2 | 0.94 / 9.2 | 0.03 / 1.2 | 0.16 / 3.4 |
| | 0 | 0.95 / 10.1 | 0.04 / 1.3 | 0.81 / 8.3 |
| | +4 | 1.00 / 22.4 | 0.34 / 12.5 | 0.99 / 20.4 |
| `cap_strong` | −2 | 0.33 / 8.3 | 0.20 / 1.5 | 0.20 / 1.5 |
| | 0 | 0.61 / 10.2 | 0.14 / 1.3 | 0.44 / 3.9 |
| | +4 | 1.00 / 21.9 | 0.63 / 12.4 | 0.89 / 15.2 |
| `base` | −2 | 0.87 / 10.9 | (같음) | 0.00 / 2.7 |
| | +4 | 0.75 / 22.7 | (같음) | 0.35 / 18.3 |

- L을 창 기울기로 바꾸면 "진술 없음" 구간의 커버리지는 물리 L(≈0–0.5)보다 크게 오른다. 그러나 `base`에서 0.75–0.87, `cap_strong` 가장자리에서 0.33–0.61로 **보장 수준에 못 미친다.** 참 곡선이 창 밖에서 창 기울기보다 가팔라지거나(휘어짐), 다른 변수 몫이 섞인다.
- 폭이 9–22 MW로 "평평 ~ 선형 연장" 사이 전부다. 정보가 거의 없다.
- **진술로 좁히면 커버리지가 무너진다. 위치 정답(`ORACLE`)으로도 0.03–0.63.** "x_c 너머는 정확히 평평"이 실제(부드러운 전이·남은 기울기)보다 강한 가정이라서다.

## 5. 판단 (탐색 수준)

| 방향 | 판단 | 근거 |
|---|---|---|
| B 제약류 구간 | **서지 않는다.** 접는다 | 좁히면 정답 위치로도 커버리지 붕괴, 안 좁히면 폭이 무의미 |
| A 정보 축(I 전환) | **절반만 선다.** LLM 기여는 없음 | 상한 세계에서 I가 켜지고 변화점 외삽이 큰 이득. 증발 세계에서는 꼴이 틀려 해로움. 꺾임이 창 밖이면 I는 침묵 |

A가 주는 것은 방법의 승리가 아니라 **경계 지도**다. (1) 꺾임이 창 안에 있고 꼴이 조각 선형이면 데이터로 충분하고 LLM이 필요 없다. (2) 꺾임이 창 밖이면 데이터는 침묵하고 위치 지식만 도움이 된다. (3) 그 위치를 LLM이 고정값보다 잘 주지 못한다(등록 결과들과 같음). 이것은 C1·C2(진단)와 C5("δ로만")를 보강하지만, "LLM 조립이 이긴다"는 긍정 결과는 아니다.

## 6. 확증하려면

탐색 수치는 원고 판정에 쓸 수 없다. 원고에 넣으려면 새 seed로 별도 등록이 필요하다. 후보 문장: "꺾임이 창 안·가장자리(δ ≤ 0)인 상한 세계에서 `R_cp_seg`(I_seg > 10)가 `R0`·`ORACLE` 조립을 이기고, `base`에서 해 ≤ 0.10, δ > 0에서 `R0`와 같다." 증발 세계의 실패는 범위 한계로 함께 등록한다. 실행 여부는 연구자 결정.
