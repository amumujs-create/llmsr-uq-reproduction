# 사전 등록: 쌍둥이 정보 축 — 창 데이터가 창 밖을 아는 만큼 LLM 이득이 사라지는가

작성: 2026-11-09 (계산 전). 관련: [정보 축 검토](reviews/2026-11-08-information-axis.md), [BDG2 결과 §10](bdg2-regime-extrapolation.md), [위험 제한](ccpp-risk-limit.md)(`risk_limits.run`), [세계를 모르는 대조군](ccpp-world-blind-controls.md), [양방향 일치](ccpp-bidirectional-consistency.md).

새 LLM 수집 없음. 기존 S0·S2 답(`analysis/llm_statements/runs/*.jsonl`)과 같은 `HA` 규칙을 쓴다. 이 문서를 커밋한 뒤 코드를 쓰고, 한 번만 계산한다.

## 1. 질문

BDG2(§10)에서 정보 구간(`evidence`/`outside`/`inside_hidden`)은 "꺾임까지의 거리"와 섞여 LLM 고유 이득을 분리하지 못했다. 모든 규칙이 `evidence`에서 이득이 가장 컸다. 쌍둥이에서는 **세계와 정답을 고정하고 창만 옮겨** δ(꺾임이 창 안/밖)를 정하고, 같은 δ에서 **표본 수 n과 잡음 σ만 바꿔** 정보량 I를 조절한다. 그래야 "I가 크면 데이터 규칙이, I가 작으면 진술 규칙이 이긴다"를 δ와 분리해서 볼 수 있다.

## 2. 세계와 꺾임

| 세계 | 꺾임 k | 외삽 방향 | δ 격자 | 이유 |
|---|---|---|---|---|
| `evap` | 24.0°C ("above") | 더운 쪽 | −6, −4, −2, 0, +2, +4, +8 | **주 축.** 모든 δ에서 시험 행 146–975개 |
| `cap_strong` | 9.0°C ("below") | 추운 쪽 | −2, 0, +2, +4, +8 | δ ≤ −4는 시험 행 ≤ 2개(자료 하한 1.8°C) |
| `base` | 없음 | 둘 다 | `evap`과 같은 창(가짜 k = 24), `cap_strong`과 같은 창(가짜 k = 9) | 꺾임이 없는 대조군: 어떤 진술도 틀리고, I > 0은 거짓 양성 |
| `cap_mild` (6°C), `evap+cap_mild` | — | — | 제외 | 6°C 꺾임은 시험 행 15개; 두 꺾임 세계는 δ가 둘 |

V는 실제값(`realV`)만 쓴다(`fixedV`는 잡음을 낮추는 효과뿐이고, σ 축이 그 역할을 한다). 잡음 σ ∈ {2.15, 4.3, 8.6} MW(기존 4.3의 ½·1·2배). 세계 수 = 3 모듈 × 3 σ = 9.

## 3. 창·시험·축 (고정)

- **δ = (외삽 쪽 창 끝) − k**, BDG2와 같은 부호: δ > 0 꺾임이 창 밖(데이터가 모름), δ < 0 꺾임이 창 안. 추운 쪽: 창 = [k + δ, k + δ + w]; 더운 쪽: 창 = [k − δ − w, k − δ].
- 폭 w ∈ {5, 10}°C. 창 표본 수 **n ∈ {50, 150, 500}**(풀에서 비복원 추출; 풀 < n이면 칸 없음). 반복 20, seed는 `grid._seed` 규약(`sample|info|{module}|{δ}|{w}|{n}|{rep}`, 잡음 `noise|{world}|{rep}`).
- **시험 구간**: m = 창 끝과 k 중 외삽 쪽에 가까운 것(추운 쪽 min, 더운 쪽 max). 시험 = m에서 2.5°C 떨어진 폭 2.5°C 띠(추운 쪽 (m − 5, m − 2.5], 더운 쪽 [m + 2.5, m + 5)). 시험 행 < 30이면 칸 없음. 시험 오차는 clean 출력 기준(기존과 같음).
- **정보 통계량 I** (창 데이터만): AT에 연속 두 기울기 변화점(매듭은 창 안 AT 값, 양쪽 ≥ 5점) + V·AP·RH 선형 대 AT 선형의 BIC 차, `I = BIC(선형) − BIC(변화점)`(변화점은 모수 2개 더: 기울기·매듭). I > 0이면 "창이 꺾임을 보인다".
- 정보 구간은 BDG2와 같은 셋으로도 보고한다: `evidence`(I > 0), `outside`(I ≤ 0, δ > 0), `inside_hidden`(I ≤ 0, δ ≤ 0).

## 4. 규칙 (모두 같은 창·반복·seed)

| 이름 | 정의 |
|---|---|
| `R0` | 창 OLS(AT, V, AP, RH) 그대로 외삽 |
| `R_cp` | I > 0이면 창 안 변화점 적합을 그대로 외삽(바깥 쪽 기울기로), I ≤ 0이면 `R0`. 데이터만 쓰는 상대 |
| `HA` | 칸(모델 × 수준)별 조립 진술(`assemble`) + 창 검사 관문(`GUARD_MARGIN` 2.0) + blend λ = 0.5. 기존 규칙 그대로 |
| `SWITCH` | **I > 0이면 `R_cp`, 아니면 `HA`.** 문턱 I* = 0은 미리 고정(BIC가 변화점을 고르면 데이터를 믿는다) |
| `ORACLE` | 정답 진술(`TRUTH`)을 `HA` 기계로(관문 + blend 0.5). 진술이 완벽할 때의 상한이자, 관문의 거짓 거부를 재는 자 |
| `M`, `D_real`, `P` | [대조군 규약](ccpp-world-blind-controls.md) 그대로: 모델 기본 답, "8°C 아래 + 27°C 위", 가짜 경계 17개(평균 `P_mean`) |

**보고용 열(2026-11-10 추가, 계산 전, LLM 무관).** 판정 T1–T8에는 쓰지 않는다. [구조·제약 검토](reviews/2026-11-10-llm-proposed-architecture-constraints.md) §3의 제약류 구간을 같은 실행에서 함께 적는다. 창 끝 e의 선형 예측 y_e(공변량 포함)에서 거리 Δ = |t − e|인 시험점의 출력이 "AT에 대해 비증가 ∧ 기울기 크기 ≤ L" 아래 들어가는 구간. L = |물리 기울기|(관문과 같은 −ȳ/(T̄+273.15)).
- `IV_none`: 진술 없음 → 더운 쪽 [y_e − L·Δ, y_e], 추운 쪽 [y_e, y_e + L·Δ].
- `IV_<진술>`: 진술 "x_c 너머 평평"이 외삽 쪽을 가리키면 Δ를 min(Δ, |x_c − e|⁺)로 줄인다(x_c가 창 안이면 폭 0). 진술이 외삽 쪽을 말하지 않으면 `IV_none`과 같다. 관문·blend는 적용하지 않는다(구간은 가정의 결과이지 추정이 아니다).
- 열: 커버리지(clean 참값이 구간 안인 비율), 폭 평균(MW), 중점 RMSE / `R0`. `ORACLE`과 각 `HA` 칸, `D_real`에 대해.
- 이유: 제약류 구간은 다음 등록(진술 집합 → 외삽 구간)의 후보이고, 같은 창·seed에서 기술 통계를 미리 보면 그 등록의 예측을 수치로 쓸 수 있다. 여기서는 기술만 하고 판정하지 않는다.

**판정 시 축 고정(2026-11-10, 계산 전).** 등록 §6이 축을 적지 않은 곳: T2·T3·T4·T8·T7·`base` 거짓 양성은 σ·n·w를 모두 합쳐 계산한다. T5는 σ = 4.3, w = 5로 고정하고 n만 비교한다. T6은 n = 150, w = 5로 고정하고 σ만 비교한다. T1은 등록대로 기준 설정. `base`의 seed 토큰은 축을 구분하기 위해 `base|k24`, `base|k9`로 쓴다(같은 δ·w·n에 창이 둘이라서).

## 5. 지표

- 칸 행(세계 × δ × w × n × rep × 규칙)마다 **상대 RMSE = 규칙 / `R0`**. 집계는 평균과 중앙값 둘 다(BDG2 교훈). 해 = 상대 RMSE > 1.10.
- `ORACLE`의 **거부율**(관문이 정답 진술을 거부한 비율) — δ별.
- `base`에서 I > 0 비율(거짓 양성)과 `R_cp` 해 비율.
- 판정은 검증 6칸(gemma3-27b, llama33-70b, gpt-oss-20b × L1·L2). 개발 칸(gpt-oss-120b, qwen)도 보고. LLM과 무관한 판정은 1회.
- 기준 설정(표 요약용): σ = 4.3, n = 150, w = 5. 모든 축의 표를 `summary.txt`에 남긴다.

## 6. 예측과 판정 기준

| | 예측 | 판정 |
|---|---|---|
| T1 I가 δ를 따른다 | 기준 설정에서 I 중앙값: `evap`·`cap_strong` 모두 δ ≤ −2에서 > 0, δ ≥ +2에서 ≤ 0 | LLM 무관, 1회(두 세계 모두) |
| T2 데이터가 알면 데이터가 이긴다 | `evap` δ ≤ −2: `R_cp` 상대 RMSE 중앙값 < 1, 그리고 `R_cp` 평균 < `HA` 평균 | 중앙값 1회 + 4/6칸 |
| T3 데이터가 모르면 진술이 이긴다 | δ ≥ +2(`evap`+`cap_strong` 합침): `HA` 평균 < `R_cp` 평균 | 4/6칸 |
| T4 전환 규칙 | 전체(세 세계·모든 δ): `SWITCH` 평균 < `HA` 평균 **그리고** < `R_cp` 평균 | 4/6칸 |
| T5 n 불변(AutoElicit류와의 차이) | δ ∈ {+4, +8}: \|`ORACLE`(n=500) − `ORACLE`(n=50)\| < 0.05(1회), `HA`도 같은 기준(4/6칸). 반면 `evap` δ ∈ {−4, −2}: `R_cp`(n=500) < `R_cp`(n=50) − 0.05(1회) | 1회 + 4/6 + 1회 |
| T6 잡음 | `evap` δ ≤ −2: `R_cp`(σ=8.6) > `R_cp`(σ=2.15) + 0.05; `ORACLE`은 \|차\| < 0.05 | LLM 무관, 1회 |
| T7 관문은 가장자리에서 가장 많이 틀린다 | `evap` `ORACLE` 거부율: δ ∈ {−2, 0} 평균 > δ = +8 **그리고** > δ = −6 | LLM 무관, 1회 |
| T8 꺾임 없는 세계 | `base`에서 `HA` 해 비율 ≤ 0.10(모든 δ 합침) | 4/6칸 |

**미리 적는 해석.**
- T1 실패: I가 δ를 못 따른다 → 통계량이 틀렸거나(매듭 격자·모수 벌점) 잡음이 너무 크다. I를 바꾸지 않고 δ별 I 분포를 그대로 보고하고, 축을 δ로 읽는다.
- T2 성공 + T3 성공 + T4 성공: **주장이 선다.** "I를 재라. 크면 데이터(변화점)를, 작으면 진술을 써라"가 데이터에서 계산되는 결정 규칙이 된다. BDG2 §10에서 못 가른 이유(거리와 섞임)를 쌍둥이가 분리했다고 적는다.
- T2 성공 + T3 실패: 진술이 데이터가 모르는 곳에서도 이득이 없다 → 기존 `HA` 결과(δ > 0에서의 이득)와 모순이므로 창·시험 정의 차이를 먼저 의심한다. 그래도 실패면 LLM 진술의 이득은 창 정의에 민감하다고 적는다.
- T2 실패(`R_cp`가 δ < 0에서도 못 이김): 가장자리 변화점 추정이 불안정하다(BDG2 `R_cp`의 평균 5.58이 같은 현상). 수축 변형은 **이 등록 뒤 별도 등록**으로만 둔다. T4도 실패할 것이다.
- T4 실패(전환이 둘 중 하나보다 못함): I* = 0이 틀린 문턱이다. I*를 사후에 고르지 않고, I 분위수별 `R_cp` − `HA` 곡선을 보고해 교차점을 **기술**만 한다.
- T5 실패(n이 늘면 `HA` 이득이 줌): 창 밖 정보가 n으로 들어온다는 뜻 — 시험 구간이 창과 겹치거나 I > 0인 행이 섞였을 것이다. `outside` 구간만으로 다시 보고한다(사후, 표시).
- T7 실패: 관문의 거짓 거부가 가장자리에 몰리지 않는다 → 관문은 δ와 무관하게 작동한다고 적고, 거부율 곡선을 그대로 보고한다.
- T8 실패: 꺾임 없는 세계에서 진술 규칙이 해를 끼친다 → H1("해 없음")을 "`R0` 대비 평균"으로만 좁힌다(대조군 K4와 같은 처리).

## 7. 한계 (미리 적음)

- 추운 쪽 꺾임은 자료 하한에 붙어 δ < 0을 거의 만들 수 없다. 더운 쪽 하나(`evap`)가 δ 축 전부를 진다. 두 세계의 결과가 다르면 세계 차이인지 방향 차이인지 가르지 못한다.
- δ > 0에서는 시험 구간이 k 기준으로 고정돼 창에서 멀어진다(거리 δ + 2.5). `R0` 오차가 δ와 함께 커지므로 **상대 RMSE**로만 비교하고 절대 MW는 보고만 한다.
- LLM 진술은 창을 모르고 수집됐다(세계 설명만). 그래서 `HA`의 진술은 δ와 무관하고 관문·blend만 δ를 본다 — 이것이 의도다. "LLM이 창 데이터를 보고 답을 바꾸는" 설정은 이 등록 밖이다.
- `SWITCH`의 I* = 0은 BIC 규약이지 최적값이 아니다. 교차점은 기술로만 보고한다.
- `base`의 가짜 꺾임 위치는 비교용 창을 맞추기 위한 것이고 `base`에는 정답 진술이 없다(`ORACLE` = 빈 진술 = `R0`).
