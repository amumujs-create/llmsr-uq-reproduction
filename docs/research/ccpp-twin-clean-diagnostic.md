## 1. 질문

학습 구간에 꺾임의 흔적이 전혀 없는 과제에서:

1. 데이터만으로는 못 고치고, 꺾임이 있다는 사실만 알면 고쳐지며, 거짓 경보는 한도 있는 큰 손해를 낸다는 진단이 새 발전소와 새 seed에서 다시 성립하는가.
2. LLM은 꺾임이 있는 쪽을 알지만 없는 쪽에도 경보를 내는가.
3. 위치를 받지 않고 "그쪽에 꺾임이 있는가"만 받는 규칙이 해 없이 이득을 내는가.

## 3. 발전소와 과제

발전소 여섯 개. 설명은 L2 한 수준이며 [수집 준비 §3](ccpp-twin-clean-collection.md)의 문장 그대로다.

| 발전소 | 꺾임 쪽 | 명목 꺾임 k | 정답 위치 | 설명에 적힌 숫자 |
|---|---|---|---|---|
| `cap353` | 저온 | 11.0°C | 11.0 | 353 MW |
| `cap350` | 저온 | 12.5°C | 12.5 | 350 MW |
| `cap346` | 저온 | 14.5°C | 14.5 | 346 MW |
| `evap22` | 고온 | 21.5°C | 22.0 | 22°C |
| `evap26` | 고온 | 25.5°C | 26.0 | 26°C |
| `chill24` | 고온 | 24.0°C | 24.0 | 24°C |

발전소마다 과제 둘:

- **꺾임 과제**: 꺾임 쪽으로 외삽. k는 위 표.
- **꺾임 없는 과제**: 반대쪽으로 외삽. 출력 제한 발전소는 고온 쪽 k = 28°C, 나머지는 저온 쪽 k = 9°C. 이 쪽에서 발전소는 기본 발전소와 같다.

창과 시험 띠의 정의는 [창 밖 구간 전용 §3](ccpp-twin-outside-regime.md)과 같다(δ ∈ {1, 2, 4}, w ∈ {5, 10}, n ∈ {50, 150, 500}, σ ∈ {2.15, 4.3, 8.6}, 반복 20).

**창 선별(잡음 없는 값만 사용, LLM 무관, 규칙 점수 미사용).** `task_cells`:

- 공통: 시험 행 30개 이상, 창 행 500개 이상, 창 안에서 기본 발전소와의 최대 차이 ≤ 0.5 MW.
- 꺾임 과제: 창 OLS의 시험 오차가 기본 발전소에서보다 3 MW 이상 크다.
- 꺾임 없는 과제: 시험 띠에서 기본 발전소와의 평균 차이 ≤ 0.5 MW.

선별 결과는 (δ, w) 조합 기준으로 꺾임 과제 30개, 꺾임 없는 과제 33개다. 코드가 실행 때 이 수를 확인하고 다르면 멈춘다. 총 11,340행.

## 4. 규칙

모든 규칙은 기존 기계(`predict_statement`: 창 보호 장치 + 혼합 0.5)를 그대로 쓴다.

| 규칙 | 정의 | LLM |
|---|---|---|
| `R0` | 창 OLS 외삽 | 없음 |
| `ORACLE` | 꺾임 과제에서 정답 위치 진술. 꺾임 없는 과제에서는 빈 진술 | 없음 |
| `READ` | 설명에 적힌 온도(22, 26, 24°C). 출력 제한은 온도가 없으므로 기본값 8°C 아래 | 없음 |
| `EDGE_h` | 항상 "창 끝부터 평평" | 없음 |
| `HINGE` | 선형 + 기온 꺾임 항 하나(창 십분위 탐색, BIC로 채택) | 없음 |
| `QUAD` | 선형 + 기온 제곱 | 없음 |
| `FROZEN` | 확인 실험의 고정 규칙 `HA_fb_gt`를 새 발전소 답에 적용 | 위치 |
| `S0` | 직접 질문 답의 과반이 외삽 쪽에 경계를 두면 "창 끝부터 평평", 아니면 `R0` | 유무만 |
| `S2` | 분해 질문 답의 과반이 외삽 쪽에 작용하는 장치를 주장하면 같음 | 유무만 |
| **`AND`** | `S0`와 `S2`가 모두 "있다"일 때만 | 유무만 |
| `OR`, `CONF` | 둘 중 하나, 혼합 0.5 × min(두 비율) | 유무만 |

`AND`가 이 등록의 주 규칙이다. 개발 자료(§7)를 본 뒤 골랐다.

지표: 상대 RMSE = 규칙 / `R0`. 과제 평균을 같은 무게로 평균한다(꺾임 평균 = 꺾임 과제 6개). 해 = 행의 상대 RMSE > 1.10. "꺾임 없는 과제 해 비율"은 꺾임 없는 과제 행을 모두 모은 비율이다.

seed: 개발 `cleandiag1`, 확인 `cleandiag2`. 개발 실행에서 LLM과 무관한 수치(C1–C3)를 이미 봤으므로 확인은 계산한 적 없는 seed를 쓴다.

## 5. 판단 정의

모델, 발전소, 쪽마다:

- `pS0` = 직접 질문 답 20개 중 그쪽에 경계를 둔 비율.
- `pS2` = 분해 질문 답 10개 중 그쪽에 작용하는 장치(저온: 출력 제한, 방빙. 고온: 증발 냉각, 배기 제한)를 주장한 비율.
- 과반은 0.5 초과.

칸 = 모델 × 발전소 = 24개. 참인 쪽 24개, 거짓인 쪽 24개.

## 8. 미리 적는 예상

- C1–C3: 성립 예상. 개발 seed에서 여유가 컸다.
- C4: 성립 예상. 냉동기는 분해 질문에 항목이 없어 약할 수 있다.
- C5, C6: 성립 가능성 높음. 확인 모델은 이미 채점한 세계에서 없는 장치 주장이 더 많았다.
- C7: 성립 예상.
- **P1–P3: 불확실.** 확인 모델은 이미 채점한 세계의 L2에서 직접 질문 거짓 경보가 0.41, `AND` 거짓 경보가 0.19였다([구조 판단 탐색](ccpp-twin-explore-structure.md)). 개발 모델보다 작고 약한 모델들이다. 4개 중 2개 이상이 될지 모른다.

## 9. 미리 적는 해석

- **진단 성립, 긍정 성립**: "학습 데이터가 모르는 꺾임에서, 위치를 받지 않고 유무 판단 두 개가 일치할 때만 쓰는 규칙이 해 없이 이득을 낸다"를 쓴다. §10의 범위 제한을 함께 쓴다.
- **진단 성립, 긍정 불성립**: 진단 논문. "유무 판단의 가치와 거짓 경보의 비용, 현재 LLM의 한계"까지만 쓴다. 개발 모델의 결과는 탐색으로 보고한다.
- **C5 또는 C6 불성립**: 확인 모델의 분해 질문 거짓 경보가 예상보다 적다는 뜻이다. 진단 문장을 "모델에 따라 다르다"로 약하게 쓴다.
- **C1–C3 중 불성립**: 진단의 뼈대가 새 발전소에서 깨진 것이다. 어느 과제에서 깨졌는지 보고하고 주장을 그 범위로 줄인다.
- **P1 성립, P2 또는 P3 불성립**: "해 없이 이득"은 쓰되 "기존 규칙이나 사람 읽기보다 낫다"는 쓰지 않는다.
- 판정 뒤의 다른 집계는 모두 "사후"로 표시한다. 규칙과 문턱은 바꾸지 않는다.

## 10. 한계 (미리 적음)

1. **장치가 전혀 없는 발전소가 판정에 없다.** 꺾임 없는 과제는 꺾임이 있는 발전소의 반대쪽이다. 이미 채점한 자료에서 거짓 경보가 가장 많았던 곳은 기본 발전소의 고온 쪽이다(확인 모델 L2 직접 질문 0.90). 따라서 긍정 주장이 성립해도 "한쪽에 장치가 있는 발전소"에 한한다.
2. **`EDGE_h`와 `AND`의 수치는 혼합 0.5와 시험 띠 위치에 기대고 있다.** "창 끝부터 평평"을 절반만 반영하면 선형 외삽의 과대 오차와 평평 가정의 과소 오차가 일부 상쇄된다. 그래서 정답 위치 진술(`ORACLE` 0.61)보다 좋게 나온다. P2, P3의 차이에는 이 효과가 섞여 있다. P1(선형 외삽 대비)은 방향이 이 효과에 좌우되지 않는다.
3. `AND` 규칙과 문턱은 개발 다섯 모델의 같은 발전소 답을 본 뒤 골랐다. 독립인 것은 확인 모델의 답과 seed다. 발전소, 설명 문장, 질문, 쌍둥이는 같다.
4. 설명은 L2 한 수준이다. 숫자가 없는 설명(L1)에서는 확인하지 않는다.
5. 발전소 여섯 개 중 셋이 출력 제한이고 숫자만 다르다. 모델 내 답이 서로 비슷할 가능성이 높아 칸 24개는 독립이 아니다.
6. 급하게 켜지는 세계는 깨끗한 창을 만들려고 고른 설정이다. 실제 설비는 더 완만할 수 있다.
7. `deepseek-r1d-32b`는 qwen 계열과 가깝다.
8. 쌍둥이 한정. 실제 자료는 이 등록 밖이다.
