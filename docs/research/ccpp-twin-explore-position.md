# 탐색: 위치를 버리지 않는 규칙, 그리고 정보 제시 실험 설계안 (2026-11-12)

상태: **탐색(사후). 판정 아님.** 기존 다섯 모델(`models.tsv`)의 이미 본 깨끗한 창 답만 쓴다. 새 seed `explore_pos1`. 확인 모델 답은 쓰지 않았다. 결과가 좋아도 주장이 아니다.

코드: `analysis/ccpp_twin/explore/position_rule.py`. 산출물 `analysis/ccpp_twin/runs/explore_position/`.
배경: [독립 검토](reviews/2026-11-12-independent-review.md) A4, A7, A8. [구조와 숫자 분리 탐색](ccpp-twin-explore-sim-assist.md).

## 1. 요약과 결론

- **위치를 쓰고 전부 반영하면 정답 위치 수준에 닿는다.** 정답 위치 0.360, 설명의 숫자와 학습 구간 기울기로 계산한 위치 0.361.
- **그런데 그 계산에는 LLM이 필요 없다.** 사람이 쓴 식 하나(`CALC`)가 정답 위치와 같은 성적을 낸다. LLM의 분해 질문 답은 설명의 제한 값을 그대로 옮겨 적은 것이었다(여유 2.92%, 2.04%, 0.87%가 설명 숫자와 일치).
- **위치 없는 규칙("창 끝부터 평평")은 전부 반영하면 무너진다.** 절반 반영 0.415가 전부 반영에서 0.766이 된다. 오늘 등록 확인의 C2와 `AND` 규칙의 좋은 수치는 절반 반영의 상쇄 효과였다. 독립 검토의 지적이 맞았다.
- **LLM 규칙 중에서는 두 질문이 모두 지목한 쪽만 쓰고 위치는 계산하는 규칙(`BOTH`)이 가장 낫다.** 다섯 모델 중 둘이 정답 수준에 해 없음, 하나가 0.497에 해 없음, 둘은 실패.
- **다음 실험의 초점은 "식을 주지 않아도 LLM이 그 계산을 해내는가"가 되어야 한다.** §5에 정보 제시 실험 설계안을 적는다.

## 2. 규칙

모두 창 보호 장치를 거치고, 반영 비율 0.5(등록값)와 1.0(전부) 두 가지로 채점했다. 2~37도 밖의 위치는 버린다(조립 코드와 같다).

| 이름 | LLM | 내용 |
|---|---|---|
| `ORACLE` | 없음 | 정답 위치 |
| `EXIST` | 없음 | 정답 쪽, 창 끝부터 평평. 위치 없는 규칙의 상한 |
| `CALC` | 없음 | 설명의 숫자를 식 하나에 넣음. 출력 제한: 15 − 여유 ÷ 민감도. 여유 = 제한 ÷ 343 − 1, 민감도 = 창의 온도 기울기 ÷ 평균 출력. 냉각 장치: 설명의 가동 온도 |
| `AND_EDGE` | 있음 | 확인에서 떨어진 규칙 |
| `S0POS` | 있음 | 직접 질문이 과반으로 지목한 쪽, 답한 위치의 중앙값 |
| `S2POS` | 있음 | 분해 질문이 과반으로 지목한 장치. 출력 제한은 모델이 말한 제한 값으로 위와 같은 식, 나머지는 모델이 말한 온도 |
| `BOTH` | 있음 | `S2POS`의 위치 중 `S0POS`도 지목한 쪽만 |

## 3. 결과

R0 절대 오차: 꺾임 과제 11.11 MW, 꺾임 없는 과제 2.27 MW, 균형 평균 6.69 MW.

### 3.1 LLM 없는 기준

| 규칙 | 반영 | 꺾임 과제 | 꺾임 없는 과제 해 | 균형 평균 |
|---|---|---|---|---|
| `ORACLE` | 0.5 | 0.609 | 0 | 4.53 MW |
| `ORACLE` | 1.0 | **0.360** | 0 | 2.99 MW |
| `EXIST` | 0.5 | 0.415 | 0 | 3.31 MW |
| `EXIST` | 1.0 | 0.766 | 0 | 4.87 MW |
| `CALC` | 0.5 | 0.628 | 0 | 4.63 MW |
| `CALC` | 1.0 | **0.361** | 0 | 3.03 MW |

- 전부 반영하면 정답 위치가 가장 좋다. 절반 반영에서 위치 없는 규칙이 더 좋아 보였던 것은 왜곡이다.
- 학습 구간에서 잰 민감도는 평균 0.686 %/도(10~90% 구간 0.599~0.769)다. 이 값으로 계산한 위치가 정답과 거의 같은 성적을 낸다.

### 3.2 LLM 규칙 (반영 1.0)

| 모델 | `AND_EDGE` 꺾임 / 해 | `S0POS` 꺾임 / 해 | `S2POS` 꺾임 / 해 | `BOTH` 꺾임 / 해 |
|---|---|---|---|---|
| llama33-70b | 0.766 / 0 | 0.469 / 0 | 0.361 / 0 | 0.361 / 0 |
| gpt-oss-20b | 0.766 / 0 | 0.648 / 0 | 0.361 / 0.380 | 0.361 / 0 |
| gpt-oss-120b | 0.766 / 0 | 0.463 / 0 | 0.497 / 0.660 | 0.497 / 0 |
| qwen3-30b | 0.917 / 0 | 0.688 / 0.380 | 0.497 / 0 | 0.823 / 0 |
| gemma3-27b | 0.858 / 0.477 | 0.954 / 0.476 | 0.361 / 0.380 | 0.688 / 0.380 |

읽는 법:

- `S2POS`의 꺾임 과제 성적은 좋다. 출력 제한 세 과제에서 다섯 모델 모두 `CALC`와 같은 값이다. 모델이 설명의 제한 값을 그대로 옮겼기 때문이다.
- `S2POS`의 해는 "배기 또는 증기 쪽 제한이 30도 위에서 작동"이라는 지목에서 나온다. 설명에 없는 장치다. 출력 제한 발전소의 고온 과제가 3.5배가 된다. 범위 끝(37도)이 아니라 30도라서 위치를 유지해도 걸러지지 않는다.
- `BOTH`는 직접 질문이 그 쪽을 지목하지 않으면 버리므로 그 해가 사라진다. 대신 직접 질문이 반대쪽을 지목한 qwen과 gemma에서는 출력 제한을 놓친다.
- gpt-oss-120b는 냉각기를 분해 질문에서 지목하지 않아 0.497이다. 분해 질문에 냉각기 항목이 없다.
- 창 보호 장치의 기각률은 모든 규칙에서 0이다. 위치가 모두 창 밖이어서 데이터로 걸러지는 주장이 없었다.

## 4. 냉정하게 본 것

1. **LLM의 몫이 여기서도 보이지 않는다.** `CALC`는 사람이 쓴 식이다. `S2POS`가 같은 성적을 낸 것은 우리 조립 코드가 그 식을 대신 계산해 줬기 때문이다. LLM은 숫자를 옮겨 적었다.
2. **쓸 만한 것은 "구조는 설명에서, 숫자는 데이터에서"라는 결합이다.** LLM이 서너 배 틀리던 민감도를 데이터가 잘 잰다. 다만 이것은 회색상자 모형에서 오래된 생각이고 그 자체로 새롭지 않다.
3. **이 수치는 이미 본 답으로 만든 규칙의 성적이다.** `BOTH`를 고른 것도 사후다. 오늘 `AND` 규칙이 개발 3/5에서 확인 1/4로 떨어진 것과 같은 일이 생길 수 있다.
4. **상쇄 효과가 확인됐으므로 반영 0.5로 낸 지금까지의 이득 크기는 다시 봐야 한다.** 등록 판정은 바뀌지 않지만, "유무만 알면 충분하다"는 문장은 쓸 수 없다.
5. **민감도는 순 출력으로 쟀다.** 가스터빈 출력의 민감도와 다르다. 이 묶음에서는 잘 맞았지만 일반적으로 맞는다는 근거는 없다.
6. 가상 발전소 현실성 문제는 그대로다.

## 5. 정보 제시 실험 설계안 (초안. 연구자 결정 필요)

### 5.1 왜 필요한가

§3이 보여 주듯 지금 설명에서는 식 하나가 정답에 닿는다. LLM이 필요한지 보려면 **식과 행동 문장을 주지 않고** 같은 결론에 이르는지 봐야 한다. 이것이 "어떻게 주면 LLM이 잘 답하는가"의 핵심 요인이다.

### 5.2 요인 (미리 고정, 더 늘리지 않음)

| 요인 | 수준 | 보는 것 |
|---|---|---|
| 정보 단계 | 0 없음 / 1 창의 데이터 통계 / 2 간접 사양 / 3 직접 설명 | LLM의 지식, 데이터 단서, 추론, 읽기의 몫 |
| 답 형식 | 쪽과 온도 / 구간("몇 도부터 몇 도까지 약하다") | 쪽 표기 혼동 |
| 묻는 범위 | 장치 나열 / 나열하지 않고 스스로 들게 함 | 질문이 없는 장치를 꺼내는 문제 |

- 간접 사양의 예: "발전기 정격 얼마, 역률 얼마. 터빈은 15도에서 343 MW." 한계에 도달한다는 문장과 제한 MW 값은 주지 않는다. 쌍둥이의 정답은 같은 숫자에서 물리로 정해진다.
- 근거 인용과 "적혀 있지 않다" 변형은 이미 수집 중인 탐색에서 따로 본다. 여기에 섞지 않는다.
- 4 × 2 × 2 = 16 조건. 발전소 7개(장치 없는 발전소 포함), 조건당 표본 10이면 모델당 약 1,200회다. 줄이려면 답 형식과 묻는 범위는 단계 2와 3에서만 본다.

### 5.3 채점 (미리 고정)

- 위치를 유지한다. 반영 1.0을 주 결과로, 0.5를 참고로 낸다.
- 기준선: R0, 정답 위치, `CALC`(사람이 쓴 식), 꺾임 비율만 아는 상수 혼합.
- 대조: 모델이 말한 위치를 ±2도, ±4도 옮긴 값과 쪽을 뒤집은 값. 말한 위치에서 가장 좋아야 한다.
- 단계 2가 단계 0, 1보다 뚜렷이 좋고 `CALC`에 가까우면 "간접 정보에서 구조를 끌어냈다"고 읽는다.

### 5.4 한계 (미리 적음)

- 개발 모델만 쓰는 탐색이다. 확인에는 새 모델과 새 발전소가 필요하다. 아홉 모델의 답은 모두 열었다.
- 간접 사양 문장과 쌍둥이의 대응을 연구자가 쓴다. 쌍둥이 코드가 정격과 역률을 실제 입력으로 받는지 아직 확인하지 않았다.
- 요인이 셋이라 갈림길이 생긴다. 조건을 본 뒤 유리한 조합을 고르지 않도록 주 비교(단계 2 대 단계 0, 1)를 미리 하나로 정한다.
