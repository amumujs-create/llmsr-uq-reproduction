# via 점 → 최적 궤적을 AI가 빠르게 뽑기 (H2017) — 겹침·논문성 검토

작성: 2026-11-05
상태: 방향 검토만 함. 실험은 하지 않음.

## 제안 (사용자)
via 점을 주면 그 점들을 지나는 궤적과 IK 해는 여러 가지가 있다. 그중 원하는 기준(시간, 토크, 에너지 등)으로 최적인 것을 시뮬레이션과 최적화로 찾으려면 느리다. 이 과정을 AI 모델이 학습해서 빠르게 뽑게 하고, 외삽 관점에서 본다.

## 가까운 선행연구
| 분야 | 연구 | 겹치는 부분 |
|---|---|---|
| 학습형 IK, 다중 해 | IKFlow, GGIK(AAAI 2026) | 여러 IK 해를 생성. GGIK는 학습에 없던 로봇으로 일반화 |
| 궤적 최적화 warm start | TOAST(2312.14336), DiffusionSeeder, flow matching(2510.03460), 2505.05588 | 학습 모델이 초기값을 주고 최적화기가 마무리 |
| 신경망 모션 플래너 정리 | 2603.24318(survey) | 일반화 한계를 정리 |
| 학습 정책의 OOD 실패 감지 | FAIL-Detect(2503.08558), 2510.09459, 2505.00779 | 정책 수준의 실패 감지. 궤적 최적화의 최적성 격차는 다루지 않음 |

## 판정
- **"AI로 IK와 궤적을 빠르게 뽑는다" 자체는 겹친다.** 게다가 H2017 같은 6축 로봇은 해석적 IK가 있다(컨트롤러 `ikin`, `sol_space` 0–7). IK만 학습하는 건 의미가 약하다. 의미가 있는 부분은 via 점 사이의 해 가지 선택, 시간 배분, 토크·에너지 최적화다.
- **외삽 관점에서 비어 있을 수 있는 부분:** 학습 모델이 낸 궤적은
  - *실행 가능성*(FK 오차, 관절·토크 한계, 충돌)은 싸게 **검사할 수 있다.**
  - *최적성*(더 좋은 궤적이 있는지)은 최적화를 다시 풀지 않으면 **검사할 수 없다.**
  - 학습 분포 밖의 via 점에서 "실행은 되지만 최적이 아닌" 조용한 실패가 생기는지, 그리고 정답을 풀지 않고 그 격차를 예측하거나 상한을 줄 수 있는지가 질문이 된다. 이 구조는 현재 주 연구의 "검사 가능/불가능 분해, 검사 불가능 부분의 위험 제한"과 같은 틀이다.
- 조건부 신규성. warm-start와 OOD 감지 문헌에 최적성 격차를 직접 다룬 연구가 정말 없는지는 CoRL·ICRA·RSS 2025–2026을 추가로 검색해야 한다.

## 최소 기여 조건
1. 외삽 축을 정의한다. 예: 학습 작업공간 밖의 via 점, via 점 개수 증가, 페이로드 증가.
2. 최적화기(정답)와 비교해 실행 가능성과 최적성 격차를 따로 측정한다.
3. 정답 없이 최적성 격차를 예측하거나 상한을 주는 방법을 제시한다. 그리고 warm start + 최적화기, 앙상블 불확실성 같은 기준선과 비교한다.

## 추가 (2026-11-05): 선행연구가 외삽을 검증했는가, 특이점 관점
- **2604.13405 (2026-04, 학습형 IK 특이점 회피 통합 검토)가 가장 가깝다.** Franka에서 학습 분포, 특이점 근처 OOD, 작업공간 이동 OOD를 따로 평가했다.
  - IKFlow 성공률은 63%에서 33%로 떨어졌다(특이점 근처). 순수 학습 모델(MLP, CycleIK, GGIK)은 모든 분포에서 0%였다. 학습 모델 + DLS 하이브리드는 93–100%를 유지했다.
  - 특이점 근처에서 IKFlow의 해 다양성이 무너진다(관절 표준편차 2.3 → 0.4 rad).
  - 저자들이 밝힌 공백: 위치만 다룸(3D IK). 손목 특이점은 범위 밖. 조건수 100 이상 구간에는 목표점이 없음. OOD 이동은 두 가지뿐. 실기와 다른 플랫폼 실험은 없음. 학습형 IK의 형식적 속도 상한은 미해결 문제.
- **2505.05588 (warm start, Astrobee):** 처음 보는 장애물(OOD)에서는 warm start 이득이 없었다. 반복 수가 cold start와 같거나 더 많았다(3065 대 2855).
- **2510.03460 (flow matching warm start):** 초록에는 "unseen environments에 강하게 일반화한다"고 쓰여 있지만, 테스트 장면을 어떻게 구성했는지는 초록에 없다. 확인이 필요하다.
- IKFlow와 GGIK 원문의 테스트 분포 구성은 아직 확인하지 않았다(GGIK는 처음 보는 로봇으로의 일반화를 평가함).

### 수정된 판정
- "학습형 IK가 학습 범위 밖과 특이점에서 무너진다"는 2604.13405가 IK 수준에서 이미 보였다. 단독 주제로는 겹친다.
- 남은 공백(조건부): (1) **전체 자세(6D) + 손목 특이점**, 6축 산업용 로봇(H2017, 해석 IK로 정답 확보 가능). (2) **IK 한 점이 아니라 via 점 궤적 수준**의 외삽(해 가지 선택, 특이점 통과 시 속도 증폭). (3) 실행 가능성은 검사할 수 있지만 **최적성 격차는 검사할 수 없는** 부분의 예측과 상한.

## 추가 (2026-11-05): 사용자 목표 확정 — "감지"가 아니라 "외삽에서도 잘 되게 하는 방법"
| 방법 | 선행 | 판단 |
|---|---|---|
| AI 초기값 + 고전 solver(DLS)로 마무리 | 2604.13405가 OOD에서 93–100%를 보임 | 이미 됨. 대신 느려짐 |
| 대칭(J1 회전 등)으로 안 배운 입력을 배운 영역으로 옮기기 | GGIK/E(n) 등변 모델(2307.01902). 로봇 간 일반화로만 평가했고 작업공간 외삽은 검증 안 됨 | 부분적으로 비어 있음. 다만 회전으로는 반경·높이·특이점 외삽을 못 덮음 |
| FK로 시험 때 스스로 고치기 | Neural IK(2205.10837), 자기지도 IK(2302.13346). 외삽 평가 없음 | solver 마무리와 사실상 같음 |
- 핵심 약점: IK와 기구학은 모델이 **완전히 알려져 있다**. 그래서 "외삽이 안 되면 solver로 고치면 된다"는 답이 이미 있다. 미지 물리를 전제로 한 외삽 연구와 잘 맞지 않는다.
- 맞는 지점은 **미지 성분이 들어간 최적 궤적**(페이로드, 마찰이 바뀌는 토크·에너지 최적 궤적)이다. 이건 앞의 H2017 동역학 검토와 합쳐진다.
