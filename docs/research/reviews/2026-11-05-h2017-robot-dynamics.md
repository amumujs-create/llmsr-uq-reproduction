# 두산 H2017 동역학을 외삽 연구에 쓰기 — 겹침·논문성 검토

작성: 2026-11-05
상태: 방향 검토만 함. 실험은 하지 않음.

## 제안
두산 공식 URDF/MuJoCo 모델(`doosan-robotics/doosan-robot2`, humble, `dsr_description2`)에 들어 있는 H2017의 링크 질량, 질량중심, 관성 텐서를 써서 외삽 연구를 한다.

## 가까운 선행연구
| 연구 | 내용 | 우리와 겹치는 부분 |
|---|---|---|
| DeLaN (Lutter et al. 2019~) | Lagrange 구조를 넣은 신경망. 새 작업으로 외삽 | "물리 구조를 넣으면 외삽이 낫다" |
| LIP kernel GP (Giacomuzzo et al., T-RO 2024) | 에너지 GP로 역동역학 추정. 표본 밖 성능 보고 | 같음 |
| Li et al., Mathematics 2024 | physics-inspired 신경망의 역동역학 외삽 분석. 모델링되지 않은 효과가 있으면 과소적합 | 외삽 분석 자체 |
| Context-aware DeLaN (2506.15249) | 공칭 모델 + 잔차, 미지 페이로드, sim→real | 페이로드 외삽, 잔차 보정 |
| Sparse E-L learning (2606.09640) | 페이로드 0/2개로 학습, 새 페이로드로 평가 | 페이로드 외삽 |
| LLMPhy, CoRAL | LLM으로 물리 파라미터 추정, 마찰 추정 | LLM + 로봇 물리 |
| LLM-SR 계열 (LLM-ODE 2603.20910, LLM-ACES 2606.25039, 2509.03036) | LLM으로 식 탐색. 로봇 매니퓰레이터 검증은 없음 | 식 탐색 |

## 판정
- **단독 주제("물리 prior로 로봇 동역학 외삽 개선")로는 겹친다.** 강체 동역학은 기저 파라미터에 대해 선형인 교과서 구조라서 물리 구조의 이점이 이미 확립돼 있다.
- **현재 주 방법(힌트 조립 `HA`, 검사 불가능 진술의 위험 제한)의 두 번째 세계로는 조건부로 쓸 수 있다.** 단일 도메인(CCPP)이라는 약점을 줄인다.
- URDF에는 마찰이 없다. MuJoCo의 damping과 frictionloss 값은 임의값으로 보인다. 그래서 시뮬레이션만으로는 학습 창 밖에서 바뀌는 성분(Stribeck→점성 마찰, 온도, 기어)이 우리가 넣은 가정이 된다. 실제 H2017의 관절 토크 로그가 있으면 이 약점이 크게 줄어든다.

## 최소 기여 조건
1. CCPP와 같은 프로토콜(좁은 학습 창, 사전 등록, 정답 없는 판단)을 로봇 세계에 그대로 적용한다.
2. 창 밖 성분이 학습 창에서 구별되지 않도록 설계한다. 예: 저속 구간 학습 → 고속 구간 외삽, 무부하 학습 → 20kg 부하 외삽, 일부 자세 학습 → 중력 토크가 큰 자세로 외삽.
3. DeLaN/LIP/공칭 URDF + 잔차 기준선과 비교한다.
4. 가능하면 실제 로봇 토크 데이터로 검증한다.

## 추가 (2026-11-05): 실제 H2017 데이터는 없음, 시뮬레이션만 가능
- H2017 시뮬레이션만으로 낸 결과는 "마찰을 가정해 넣은 장난감 세계"라는 지적을 받기 쉽다. 단독 근거로 쓰지 않는다.
- 권장 구성은 CCPP와 같다. **개발은 H2017 쌍둥이 시뮬레이터로, 실데이터 검증은 공개된 실제 로봇 토크 데이터로** 한다.
  - 후보: SARCOS(OpenML, 실제 로봇 100Hz, 7축), KUKA KR300 식별 벤치마크(DFKI), UR10 1kHz, Barrett WAM, Baxter(Zenodo), iCub. 라이선스와 페이로드·속도 범위는 아직 확인하지 않았다.
- 시뮬레이션 세계의 마찰 같은 미지 성분은 임의로 정하지 않는다. 문헌에 나온 다른 협동로봇의 마찰 식별값으로 근거를 대고, CCPP의 결빙 방지 세계처럼 대안 세계를 여러 개 사전 등록한다.
- 페이로드와 중력처럼 URDF에 이미 있는 성분만 외삽하면 기저 파라미터에 대해 선형이라 너무 쉽다. 학습 창 밖에서만 드러나는 성분(고속 점성 마찰, 큰 부하에서의 관절 유연성 등)이 있어야 방법을 시험할 수 있다.
