# 검토: 학습 데이터에 정보가 없는 과제만 골라 쓰기 (2026-11-12)

상태: 방향 검토. 문헌은 검색 요약 수준이며 본문을 읽지 않았다.

## 1. 제안

가상 발전소에서, 학습 데이터로 외삽하면 이상하게 예측되는 경우만 대상으로 실험한다.

## 2. 위험: 결과를 보고 고르면 안 된다

"데이터만 쓴 규칙이 틀린 경우"를 잡음 섞인 실제 채점 결과로 고르면 선택 편향이 생긴다.

- 기준선이 운 나쁘게 틀린 표본만 남는다. 다른 어떤 규칙이든 좋아 보인다.
- 실제 사용에서는 기준선이 틀릴지 미리 알 수 없다. 그 조건으로 고른 성능은 재현되지 않는다.
- 꺾임 있는 과제만 남기면 "항상 꺾인다고 말하는 규칙"이 이긴다.

관련 문헌(검색 요약): 어려운 사례만 고른 벤치마크는 문제 분포를 대표하지 못한다는 지적, 성능 저하 크기로 분포 이동을 체계적으로 고르자는 제안, 한 벤치마크에 맞춘 이득이 같은 방식으로 만든 숨은 벤치마크에서 재현되지 않는다는 지적이 있다.

## 3. 허용되는 형태

고르는 기준을 **세계의 성질**로 두고, 어떤 규칙의 점수도 쓰지 않는다. 잡음 없는 값으로 레짐 세계와 기본 세계를 비교한다.

- 깨끗함: 학습 구간 안 최대 차이가 기준 이하. 학습 데이터에 레짐 정보가 없다는 뜻.
- 중요함: 시험 구간에서 창 선형 적합의 오차가 기본 세계의 같은 창보다 기준 이상 큼. 외삽이 실제로 망가진다는 뜻.
- 기준은 LLM 답을 보기 전에 등록한다. 모든 규칙에 같은 과제를 쓴다.
- 꺾임 없는 대조 과제를 같은 창으로 반드시 둔다. 해를 재는 용도.

이 형태는 벤치마크 설계이지 결과 선택이 아니다. 연구자의 목표("데이터에 정보가 없을 때만 이기고 싶다")를 그대로 조작적 정의로 옮긴 것이다.

## 4. 게재 가능성

- 장점: 주장 범위가 분명해진다. "학습 데이터에 정보가 없다"를 수치로 보증할 수 있다. 사후 점검에서 드러난 누수 문제(decision-log 2026-11-12)를 없앤다.
- 약점: 켜짐이 급한 세계를 새로 만들어야 한다. 심사자가 "유리한 세계를 골랐다"고 볼 수 있다. 대응: 기준을 미리 공개하고, 기준을 통과하지 못한 세계의 결과도 부록에 싣는다.
- 실제 자료에는 잡음 없는 정답이 없어 같은 기준을 못 쓴다. 실제 CCPP에서는 구간 안 변화점 검정 같은 데이터 기반 대용 기준이 필요하다.
