# LLM은 힌트만, 기여는 조립 — 방향 검토

작성: 2026-11-04  
계기: 사용자 정리. "LLM에 크게 기대하지 않는다. LLM에게서는 힌트만 얻고, 그것을 잘 조립해서 외삽하고 싶다."

## 방향을 한 문장으로

**품질이 들쭉날쭉한 LLM 힌트 여러 개를 받아, 데이터로 검사할 수 있는 부분은 검사하고, 검사할 수 없는 부분은 손해 상한을 걸어 하나의 외삽 예측으로 조립하는 방법.** 힌트가 나빠도 데이터 적합보다 크게 나빠지지 않고, 힌트가 좋으면 이득을 본다.

- 지금까지의 결과와 같은 방향이다. 위험 제한 실험(`blend`, `budget`)이 조립의 마지막 단계다.
- 바뀌는 것은 논문의 중심이다. "어느 LLM이 얼마나 맞히나"(LLM 평가)가 아니라 **조립 방법**이 중심이 된다. LLM 신뢰도는 입력 조건으로 다룬다.

## 가장 가까운 연구

| 연구 | 하는 것 | 우리와 다른 점 |
|---|---|---|
| BoxLM (Li, Fox, Goodman, ICML 2024, arXiv 2402.17879) | LM이 확률 프로그램을 제안하고 비판한다. 데이터 적합 점수(LOO ELPD)로 고른다 | 데이터가 고를 수 있는 부분만 다룬다. 학습 창 밖 레짐처럼 데이터로 검사할 수 없는 부분의 처리가 없다. 외삽 평가 없음 |
| 생성 후 선별 (arXiv 2611.00643, 2026-10, 사전 등록) | LLM 주장을 많이 만들고 일부를 골라 남기면 참 비율이 오른다. NAS-Bench, HPOBench | 선별의 근거가 벤치마크 정답이다. 연속 예측의 조립과 손해 상한이 없다. **원문 확인 필요** |
| POPPER (arXiv 2502.09858) | LLM 가설을 순차 반증 검정으로 검증하고 오류율을 통제한다 | 가설 검정이다. 예측을 만들지 않는다 |
| 형상 지식 회귀 (arXiv 2409.17084), 단조성 지식 (arXiv 2010.15955) | 전문가의 단조·볼록 지식을 제약으로 넣어 회귀한다 | 지식이 맞다고 가정한다. 지식이 틀릴 수 있을 때의 손해 상한이 없다. LLM이 출처가 아니다 |
| LLM-SR 계열 | LLM이 식 자체를 만든다 | 정답 함수형을 LLM이 만드는 방식은 이 연구의 제약상 쓰지 않는다 |
| AutoElicit, LoID | LLM이 계수 prior를 준다 | 계수 수준이다. LoID는 CCPP 온도 외삽에서 실패를 보고했다 |

## 판정

- **조건부로 비어 있음.** "LLM이 제안하고 데이터가 고른다"는 BoxLM과 생성 후 선별 연구가 이미 했다. 그 부분만으로는 기여가 안 된다.
- 비어 있는 부분은 **데이터가 고를 수 없는 힌트(창 밖 레짐)를 어떻게 조립하느냐**다. 여기에 다음이 필요하다.
  1. 힌트를 형식(메커니즘, 쪽, 위치)으로 바꾸는 단계
  2. 창 데이터로 검사할 수 있는 부분 검사
  3. 여러 표본·모델 힌트의 합의 정도 반영
  4. 검사할 수 없는 부분에 손해 상한
- 최소 기여 조건: 힌트 품질 p가 0에서 0.7까지 퍼진 모델들(현재 7개 모델 수집)을 입력으로 넣었을 때, **정답 없이** 정한 조립 규칙이 다음을 모두 만족한다.
  - 모든 p에서 데이터 적합보다 크게 나빠지지 않는다(상한을 미리 정한다).
  - p가 높은 모델에서는 데이터 적합보다 낫다.
  - 단순 다수결, 최고 단일 모델(사후 선택), BoxLM식 창 적합 선택보다 낫거나 같다.

## 결빙 방지 세계의 위치

[결빙 방지 세계](../ccpp-anti-icing-world.md)는 계속 쓰되 역할이 바뀐다. LLM을 채점하는 벤치마크가 아니라 **조립 방법을 시험하는 세계**다. 힌트가 부분적으로만 맞는 경우(메커니즘은 맞고 방향은 틀림)가 생기므로 조립 규칙의 시험에 적합하다.
