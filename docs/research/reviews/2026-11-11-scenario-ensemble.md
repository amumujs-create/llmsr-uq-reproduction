# 검토: LLM 시나리오 앙상블 (2026-11-11)

상태: 방향 검토. 실험 없음. 문헌은 검색 요약 수준이며 본문을 읽지 않았다.

## 1. 제안

학습 구간에 꺾임 정보가 없을 때(δ > 0), LLM에게 가능한 상황을 여러 개 가정하게 하고, 각 가정으로 예측을 만들어 앙상블처럼 쓴다.

## 2. 선행연구

| 연구 | 하는 일 | 우리와의 차이 |
|---|---|---|
| Large Language Bayes (Domke, arXiv 2504.14025, NeurIPS 2025) | LLM이 후보 확률모형을 여러 개 뽑고 주변우도 가중으로 평균 | 가중치가 데이터에서 온다. 데이터가 후보를 구별 못 하는 외삽은 다루지 않음 |
| ModelSMC (arXiv 2602.18266) | LLM 제안 모형을 SMC 입자로 두고 우도 가중 평균 | 같음 |
| Automated Statistical Model Discovery (arXiv 2402.17879) | LLM이 모형 제안과 비평 반복 | 평균 없음. 구간 안 적합 기준 |
| Solomonoff 방식 순위 (arXiv 2512.17145) | 단순성과 적합도로 가설 가중 | 적합도 필요 |
| HypoGeniC (arXiv 2404.04326), Literature Meets Data (arXiv 2410.17309) | LLM 가설 생성, 문헌과 데이터 결합 | 분류 과제 |
| LLM-SR (arXiv 2404.18400) | LLM 지식으로 방정식 탐색 | 단일 최선 식 선택 |

"LLM이 후보를 여러 개 내고 평균한다"는 생각 자체는 이미 있다. 새롭지 않다.

## 3. 핵심 문제

기존 방법은 모두 데이터 우도로 후보에 가중치를 준다. 우리 설정(δ > 0)에서는 "꺾임 없음", "24도에서 꺾임", "27도에서 꺾임" 시나리오가 학습 구간 안에서 똑같은 예측을 한다. 우도가 같으므로 데이터는 가중치를 주지 못한다. 가중치는 LLM이 말한 빈도뿐이다.

따라서:

- **점 예측으로는 지금 규칙과 거의 같다.** 현재 HA는 표본 10~20개의 다수결과 0.5 혼합을 쓴다. 시나리오 평균은 혼합 비율을 LLM 빈도로 바꾼 것에 해당한다. 큰 이득을 기대할 근거가 없다.
- **새로 얻는 것은 폭이다.** 시나리오들이 벌어지는 범위를 "모른다"는 구간으로 쓸 수 있다. 앞선 구간 탐색(ccpp-twin-explore-info-interval.md)은 구간을 좁히려다 포함률이 무너졌다. 이번은 넓히는 방향이라 성격이 다르지만, 같은 실패 위험은 있다.
- **LLM이 틀린 쪽에 몰리면 앙상블도 틀린다.** 침묵 진단에서 gemma, llama는 민감도를 3~4배 작게 말했고 일부 모델은 반대쪽을 지목했다. 표본을 늘려도 편향은 줄지 않는다.

## 4. 게재 가능성

| 주장 | 평가 |
|---|---|
| 시나리오 평균이 점 예측을 개선 | 약함. 기존 혼합 규칙의 재표현 |
| 외삽에서는 우도가 평평해 LLM 사전분포가 유일한 가중치가 된다는 분석 | 중간. Large Language Bayes류가 다루지 않은 조건 |
| 시나리오 폭이 외삽 오차를 덮는 구간이 되는지 | 중간. 결과에 달림. 실패해도 진단으로 쓸 수 있음 |

독립 논문감은 아니다. 현재 논문의 부가 분석으로는 가치가 있다.

## 5. 권고

- 진행 중인 확인 실험(ccpp-twin-outside-confirmation.md)의 규칙, 지표, 문턱은 건드리지 않는다.
- 새 수집이 필요 없다. S0 답 20개와 S2 답 10개가 이미 표본이다.
- 하려면 채점 전에 별도 등록한다. 부가 분석으로 표시하고 주 판정에 쓰지 않는다. 지표 후보: 시나리오 평균의 상대 RMSE, 시나리오 최소~최대 범위의 포함률과 폭.
- 비교 기준선: R0, HA_fb_gt, 고정 혼합.
