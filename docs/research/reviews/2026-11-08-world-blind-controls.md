# 검토: 세계를 모르는 대조군 (가짜 경계·도메인 기본값·모델 기본값)

작성: 2026-11-08  
대상: 기여 계획 G2 — "LLM이 아니어도 되지 않나"에 답하는 대조군을 사전 등록한다.  
관련: [실데이터 §10](../ccpp-real-data.md) (사후 가짜 경계), [모양 수집 2단계 §9](../ccpp-shape-elicitation-2.md) (모델 기본 답), [힌트 조립 §13](../ccpp-hint-assembly.md)

## 1. 왜 필요한가

- 실데이터 사후 대조군(§10)에서 24–32°C 어디에 "위는 평평"을 둬도 LLM 다수결과 비슷한 이득이 났다. 같은 질문이 쌍둥이 검증(`HA`, 6칸)에는 아직 없다.
- 모양 수집 2단계에서 Qwen·Gemma는 세계와 무관하게 같은 답(`weaker`)을 냈고, 기본 세계(장치 없음)에서도 "25–30°C 위" 경계를 말했다. 그렇다면 `HA`의 이득이 **설명을 읽은 결과**인지, **세계와 무관한 기본 답이 우연히 정답(증발 24°C)과 가까운 결과**인지 구분해야 한다.
- 쌍둥이 위험 제한 실험의 "틀린 진술"(`miss`, `false_alarm`, `shift`, `swap`)은 모두 **세계별 정답을 알고 만든** 진술이다. 세계를 모르는 채 고정한 진술은 없었다.

## 2. 문헌에서 무엇을 대조군으로 쓰는가

| 연구 | 대조군 | 우리와의 관계 |
|---|---|---|
| [AutoElicit](https://arxiv.org/abs/2411.17284) (ICML 2025) | 무정보 사전분포 N(0,1) 하나. 무작위 사전분포 대조군은 없다 | 우리 `R0`(데이터 적합)에 해당. "아무 힌트나 줘도 되는가"는 묻지 않았다 |
| [Context is Key](https://arxiv.org/abs/2410.18959) | 같은 모델을 **맥락 없이** 다시 돌린다. 맥락을 빼면 LLM 예측기가 더는 수치 모델을 앞서지 못한다 | 우리 "모델 기본값" 대조군(장치 없는 세계의 답을 모든 세계에 씀)과 같은 논리다. 맥락 민감도를 잰다 |
| [Fu 외, EMNLP 2023](https://arxiv.org/abs/2311.01150) 지식 주입 재검토 | 정렬된 지식 대신 **무작위·무관한 지식**을 넣어도 비슷하거나 더 낫다 | 무작위 힌트 대조군이 없으면 "지식 덕분"이라고 말할 수 없다는 직접적 경고 |
| [LLM-Lasso](https://web.stanford.edu/~pilanci/papers/LLM-Lasso.pdf) | 무작위 특징 선택 기준선. 특징 이름 절반을 망가뜨린 적대 시험 | 이름을 망가뜨리는 것은 우리 "가짜 경계"와 같은 뜻이다. 교차검증이 망가진 조언을 걸러낸 것은 우리 창 검사 관문의 역할과 같다 |
| [LLM 특징 선택 연구 2610.28556](https://arxiv.org/html/2610.28556v1) | 특징 이름을 섞는다. 의미 라벨이 데이터와 분리돼도 선택을 끌고 간다 | 이름(설명)에 끌리는 현상을 재는 방법. 우리 쌍둥이 설명을 섞는 수집은 하지 않지만, 세계를 모르는 진술로 같은 질문을 묻는다 |

- 못 찾은 것: 외삽용 하이브리드 모델에서 "LLM 힌트 대 도메인 기본값 대 무작위 경계"를 함께 비교한 연구. 검색 결과에 없다고 해서 없는 것은 아니다.
- 결론: **대조군 세 종류(가짜 경계, 도메인 기본값, 맥락 없는 모델 답)는 문헌에서 각각 쓰이는 표준 장치**이고, 셋 중 하나라도 빠지면 심사에서 "LLM이 필요한가"라는 반론을 받는다.

## 3. 논문성

- 이 대조군 자체는 기여가 아니다. **C3("안전 조립")와 C4("실데이터 확인")를 지키는 방어 장치**다.
- 결과가 어느 쪽이든 쓸 수 있다.
  - `HA`가 세계를 모르는 대조군을 이기면: "LLM 위치가 설명에서 온 정보를 담는다"를 쌍둥이에서 말할 수 있다.
  - 이기지 못하면: C3의 "LLM"을 빼고 "검사 관문 + 보수적 반영"이 안전성을 만든다고 쓴다. C2(기본 답 끌림)와 들어맞는 결과이므로 이야기는 오히려 일관된다. 다만 "LLM 외부 지식이 필요하다"는 서론 논거는 약해진다.
- 새 수집이 없다. 기존 답과 쌍둥이로 계산만 한다. 비용이 거의 없다.

## 4. 위험

- **도메인 기본값이 정답에 너무 가깝다.** 실제 발전소 회귀의 꺾이는 점(8°C 아래, 27°C 위, [도메인 점검 §3·§5](../ccpp-domain-check.md))은 쌍둥이 정답(6·9°C 아래, 24°C 위)과 2–3°C 차이다. 쌍둥이의 경계가 같은 데이터 분위수에서 왔기 때문이다. 그래서 도메인 기본값 대조군은 **거의 오라클**이고, `HA`가 이기지 못해도 "LLM이 쓸모없다"가 아니라 "이 시스템에서는 도메인 기본값으로 충분하다"다. 사전 등록에 이 해석을 미리 적는다.
- **가짜 경계 중 최선값은 사후 선택이다.** 격자에서 가장 좋은 경계는 검증 자료를 보고 고른 것이라 낙관적이다. 판정은 격자 평균으로 하고 최선값은 보고만 한다.
- **`HA`는 이득이 작다**(최대 0.34 MW). 대조군이 해를 끼치면(`R0`보다 나쁘면) `HA`가 쉽게 이긴다. 그래서 "이긴다"는 "해를 안 끼친다"와 구분해서 적는다.
