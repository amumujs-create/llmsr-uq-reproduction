# 모양 수집 2단계 (기본 답 끌림 검증) — 겹침·논문성 검토

작성: 2026-11-08  
제안(연구자): 1단계의 사후 가설("모델이 고르는 모양은 기본 답 `weaker`에 끌린다")을 검증할 새 세계를 사전 등록한다.  
관련: [사전 등록](../ccpp-shape-elicitation-2.md), [1단계 §9](../ccpp-shape-elicitation.md), [진단+안전 조립 검토](2026-11-08-diagnosis-safe-assembly-framing.md)

## 검색한 것 (표준 검색 2회)

1. LLM의 질적 물리 추론에서 기본 답 편향, 효과 방향, 직관에 반하는 경우
2. LLM과 가스터빈 흡기 냉각, 발전기 고온 출력 감소 평가

## 가까운 연구

| 연구 | 내용 | 우리와의 관계 |
|---|---|---|
| PhysMRV (arXiv 2607.10190) | 시각-언어 모델이 증거가 애매하면 "물리적으로 정상"이라고 답하는 쪽으로 기운다. 균형 잡힌 정확도가 이 편향을 가릴 수 있다 | **기본 답 쪽으로 기우는 현상** 자체는 보고돼 있다. 우리는 텍스트만 쓰고, 정답 모양을 아는 세계에서 레짐 모양으로 측정한다 |
| 평행 물리 세계 물리 소양 (arXiv 2607.00276) | 바꾼 물리 법칙의 세계에서 변화 **방향**은 거의 맞히지만, 비율은 표준 물리 관계로 돌아가 틀린다 | 가장 가깝다. "방향은 맞고 크기·형태는 기존 지식으로 돌아간다"는 결과는 H와 같은 방향이다. 다만 가상 물리이고 레짐 경계가 아니다 |
| Salience bias (alphaXiv 2607.28478) | 눈에 띄는 명시 정보가 암묵적 상식 전제보다 우선한다 | `gen_hot` L2의 숫자처럼 명시 정보가 있을 때 결과를 해석하는 데 참고한다 |
| 반직관 장면의 언어 편향 (arXiv 2601.07737), InPhyRe (arXiv 2509.12263) | 다중 모달 모델의 물리 추론이 언어 사전 지식에 끌린다 | 같은 계열이지만 다중 모달 연구다 |
| 흡기 냉동, 고온 출력 감소 (특허, 제조사 자료) | 흡기 냉동기와 고온 출력 감소는 실제로 쓰는 장치·현상이다 | 새 세계 설정이 현실적이라는 근거로만 쓴다. LLM 평가는 찾지 못했다 |

## 겹침 판단

- "LLM이 기본 답이나 기존 지식으로 돌아간다"는 **일반 현상은 이미 보고돼 있다**(PhysMRV, 평행 물리 세계). 이 단계의 결과를 그 자체로 새 발견이라고 쓰면 안 된다.
- **찾지 못한 것:** 공학 시스템의 레짐 경계에서 위치와 모양을 나눠 채점하고, 정답 모양을 바꾼 대조 세계(약해짐, 멈춤, 가팔라짐, 반대)로 기본 답 끌림을 시험한 연구.
- **이 단계의 역할:** 독립된 기여가 아니다. 논문의 C2(진단)를 정확히 쓰기 위한 확인 실험이다. 결과가 어느 쪽이든 C2 문장을 정한다.

## 논문성 판단

- **H를 지지하는 결과가 나오면:** C2를 "모양은 기본 답에 끌린다"로 쓰고, 관련 연구에서 PhysMRV와 평행 물리 세계를 인용해 같은 현상이 공학 외삽에서도 나타난다고 연결한다. 설계 원칙(위치만 받는다)의 근거가 강해진다.
- **H가 기각되면:** 모양 실패는 반대 방향 레짐과 모델 하나에 한정된다. C2가 약해지지만, "안전 조립은 드문 큰 실패(결빙 방지, Llama)를 막는다"는 C3 서술로 옮길 수 있다.
- 새 수집은 모델당 210회다. 비용 대비 C2 문장의 정확도를 정하는 가치가 크다.

## 권고

1. 1단계와 같은 채점 틀(위치 → 모양)을 쓰고, 정답이 `weaker`가 아닌 세계 두 개와 대조 세계를 함께 묻는다.
2. 대조 세계로 조작 점검(Q4)을 사전 등록한다. 질문을 바꾼 효과를 가린다.
3. 메커니즘 이름에 붙은 고정 모양(`power_cap` → `near_zero`)을 따로 보고한다. 기본 답 끌림과 구분하기 위해서다.
4. 원고 관련 연구에 PhysMRV와 평행 물리 세계 연구를 넣는다. 원문은 G5와 함께 확인한다(이번 판단은 검색 요약에 기댔다).
