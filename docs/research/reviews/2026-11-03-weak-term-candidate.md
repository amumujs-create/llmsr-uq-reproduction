# 전달된 8편 비교와 약한 물리항 후보 기록

기록일: 2026-11-03  
상태: **전달받은 조사 노트 보존. 후보는 추천 철회·차별점 미확보 상태이며, 제안 실험은 미실행이다.**

## 1. 출처와 기록 범위

사용자가 이 대화에 붙여 넣은 이전 답변의 논문 비교와 후보 실험안을 정리했다. 해당 답변에는 “8편의 원문·부록과 일부 공개코드를 확인했다”는 설명이 있었으나, **이번 저장소 갱신에서 아래 원문·코드를 독립적으로 다시 확인한 것은 아니다.**

전달 내용에는 외부 컴퓨터의 연구노트 세 파일을 편집했다는 설명이 있다. 현재 이 저장소에서 그 로컬 파일들을 읽거나 동기화한 것은 아니며, 여기에는 실제로 전달된 텍스트만 반영한다. 외부 파일의 전체 내용·편집 이력·누락 부분까지 복구했다고 주장하지 않는다.

아래 연도, 조건, 확인 범위는 전달 노트의 기록이다. 정확한 정식 제목이 없는 항목은 설명명을 유지하며 임의로 제목을 만들지 않는다.

해석상의 구분:

- 관측 시간을 늘림, 표본 수를 늘림, 표본 수를 고정하고 상태 범위를 넓힘은 다른 조작이다.
- 잡음의 % 기준이 논문마다 다르면 숫자만으로 난도를 비교할 수 없다.
- 시험 대상의 초기 궤적을 받는 설정과 시험 목표값을 전혀 받지 않는 설정은 다르다.
- “확인하지 못함”을 “해당 논문에 없음” 또는 “문헌 전체에서 미해결”로 바꾸지 않는다.
- 이 표는 원논문 수치의 전달 기록이며 자체 실행으로 얻은 결과가 아니다.

## 3. 제안되었던 후보

> 관측에서 잘 검출되지 않는 물리항을 없다고 판단해도 되는가? 특히 그 항이 목표 외삽 영역에서 커진다면 어떤 기준으로 남기거나 버릴 것인가?

설명용 예시:

```text
F(x) = x + 0.5*x^3
x = 0.2: linear = 0.2, cubic = 0.004
x = 2.0: linear = 2.0, cubic = 4.0
```

작은 변형에서는 잡음에 가려진 항이 큰 변형에서 중요해질 수 있다는 예다. 이는 대수 계산이며 새 실험 결과가 아니다.

제안된 구분은 “항이 불필요하다는 증거”와 “항의 존재를 판단할 정보가 부족함”이다. 그러나 식별가능성, 베이지안 구조 불확실성, 예측 범위 계산에 이미 가까운 연구가 있다.

추가 핵심 비교로 [Kreutz et al.,2012 — Prediction profile likelihood](https://link.springer.com/article/10.1186/1752-0509-6-120)가 제시됐다. 후보의 문장은 다음 수준에서 보관한다.

> 같은 후보식·물리지식을 받은 기존 방법보다, 관측 검출 가능성과 외삽 영향력을 나눠 고려하는 항 선택·신뢰조절이 잘못된 확신을 줄이는가?

이 질문의 효과나 독창성이 확인된 것은 아니다.

## 4. 보관된 미실행 실험안

사용자가 선택한 시뮬레이션 우선 방향을 이 실험으로 대체하지 않는다. 다음은 이전 답변에서 제시된 선택적 원리 진단안이다.

| 항목 | 전달된 설정 |
|---|---|
| 첫 문제 | 비선형 스프링 힘 회귀. LLM·로봇 없이 원리 확인 |
| 데이터 수 | 학습 256개 고정, 별도 검증 수도 고정하되 구체적 검증 개수는 미제시 |
| 관측 범위 | x∈[−r,r], r=0.2,0.5,1.0 |
| 출력 잡음 | 표준편차 0.005,0.02,0.08. 범위가 바뀌어도 같은 힘 단위 유지 |
| 목표 외삽 범위 | **미확정. 전달 텍스트의 셀이 잘려 있음** |
| 실제 법칙 | cubic항 있음 / 없음 |
| 후보 지식 | 먼저 모든 방법에 동일한 {x,x³}; 이후 참항 누락·잘못된 후보식 |
| 반복 | 우선 조건당 20회, 이후 추가 확인 제안 |
| 후속 | Duffing 작은 진폭→큰 진폭. 정확한 미분과 잡음에서 추정한 미분 분리 |

원래 목표 외삽 셀에 전달된 문구는 다음뿐이다.

```text
모든 조건에서 동일한 (
```

x=2는 설명용 예시이며, 이를 시험 범위 또는 샘플링 분포로 추정해서 채우지 않는다. 목표 구간, 검증 표본 수, 잡음 분포의 세부, prior의 하이퍼파라미터, 구간의 정확한 대상과 산출 절차는 실행 전에 명세가 필요하다.

제안된 비교군:

1. 희소 회귀 항 선택 후 계수 재적합.
2. UQ-SINDy 계열의 구조·계수 불확실성.
3. E-SINDy 계열 앙상블.
4. 작은 후보집합의 모델 평균과 예측 프로파일 우도.

각 방법의 회귀 원리를 적용하는 계획이다. 원논문의 동역학 실험을 재현한 것으로 부르지 않는다. “정확한 모델 평균”은 작은 후보집합의 열거 가능성을 뜻하는 제안 문구이며, prior·우도·적분 방법을 명세하지 않은 상태에서 구현의 정확성을 확정하지 않는다.

평가 후보:

- 외삽 오차.
- 외삽에서 중요한 항을 잘못 버린 빈도.
- 명목 95% 구간의 실제 포함률과 폭.
- 구간 확장만으로 생긴 포함률 상승과 유효한 개선의 구별.
- 시험 정답을 이용한 보정·모델 선택 금지.

95% 구간이 조건부 평균에 대한 구간인지, 잡음이 포함된 새 관측값의 예측구간인지 전달 자료에서는 충분히 명확하지 않다. 비교할 때 이를 통일해야 한다.

LLM은 이후 후보 물리식·가정을 제공하는 교사로 붙이는 구상이었다. 같은 후보를 비LLM 방법에도 제공하여 지식 획득과 신뢰조절의 효과를 나누자는 조건이 함께 제시됐다.

## 5. 추천 철회와 현재 상태

전달된 대화에서 이 후보는 처음 추천됐으나, 이후 추천이 철회됐다. 이유는 다음과 같다.

- UQ-SINDy·E-SINDy·모델 평균·예측 프로파일 우도 대비 무엇이 추가로 해결되는지 제시하지 못했다.
- 관측범위와 잡음을 더 촘촘하게 바꾸는 것만으로 방법론적 차별점이 확보되지 않는다.
- “목표 외삽 영향력 고려”라는 표현이 기존 추론과 실제로 어떻게 다른지 아직 명세되지 않았다.

현재 기록은 **추천 근거 미확보로 보류**다. “신규성이 없다고 증명됨”, “기존 방법이 반드시 해결함”, “우리 실험에서 실패함” 중 어느 것도 뜻하지 않는다.

이전 답변의 1–3주 판정 제안은 보관된 일정 가정이며 현재의 완료 약속이 아니다. 원문 비교로 확인할 내용과 탐색 실험으로 확인할 내용이 남아 있다.

## 6. 다음 검토에 필요한 질문 — 새 추천 아님

- 가장 가까운 기존 방법의 실제 prior·우도·구조 선택 가정은 무엇인가?
- 목표 영역 정보는 모든 비교군에 동일하게 제공되는가?
- source에서 식별되지 않는 계수의 범위를 문헌이 얼마나 제한하는가?
- 잘못된 항 제거와 넓지만 정직한 구간의 차이를 어떤 비용 기준으로 평가하는가?
- 기존 모델 평균·프로파일 우도로 해결되는 경우 새 알고리즘 주장을 중단할 것인가?
- LLM이 추가로 제공하는 것은 후보 항, 계수 범위, 적용조건 중 무엇인가?

이 질문들은 확인할 작업이며 해결된 연구 공백 목록이 아니다.
