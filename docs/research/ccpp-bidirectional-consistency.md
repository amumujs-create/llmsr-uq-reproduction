# 양방향 적합 일치 필터: LLM 없는 사전 실험

작성: 2026-11-05  
상태: **설계와 예측을 실행 전에 커밋한다.** 결과는 §6에 덧붙인다.  
관련: [검토](reviews/2026-11-05-bidirectional-fit-consistency.md), [힌트 조립](ccpp-hint-assembly.md)

## 1. 질문

LLM이 낸 후보 식을 학습 창 안에서 두 방향으로 적합해 보고, 두 방향 모두 맞는 식만 남기면 외삽을 더 믿을 수 있는가?

LLM을 부르기 전에 후보 식 묶음으로 이 질문에 먼저 답한다. 묶음이 LLM 제안을 대신한다. 필터가 묶음에서 효과가 없으면 LLM 식에서도 효과를 기대하기 어렵다.

## 2. 설정

- **세계:** 기존 다섯 세계와 `ice`, `ice+cap_mild`. 실제 V, 잡음 4.3 MW, 반복 20회.
- **창·시험 구간:** 기존 격자와 같다(폭 2.5·5·10, 거리 5·10·15·20, 시험 구간 폭 2.5, 30행 미만 제외). 학습 표본과 잡음 seed도 같다.
- **창 나누기:** 학습 표본을 AT 중앙값으로 둘로 나눈다. 외삽 방향 쪽 절반이 "바깥", 반대쪽이 "안쪽"이다.

**후보 식 14개** (모두 OLS로 계수 적합, 입력 AT·V·AP·RH)

| 묶음 | 식 |
|---|---|
| 기본 | `lin`(선형), `quad`(AT² 추가), `cubic`(AT²·AT³ 추가), `density`(AP/(AT+273.15)·V·RH) |
| 저온 상한형 | `below_k`: AT 대신 max(AT, k). k = 4, 6, 8, 10, 12 |
| 고온 평탄형 | `above_k`: AT 대신 min(AT, k). k = 22, 24, 26, 28, 30 |

- k는 2°C 간격의 고른 격자다. 정답 위치에 맞춘 값이 아니다.
- 결빙 방지의 기울기 반전 모양은 묶음에 넣지 않았다. 그래서 `ice` 세계는 "맞는 식이 묶음에 없는 경우"를 보여 준다.

## 3. 점수와 선택 규칙

| 규칙 | 점수 (낮을수록 좋음) |
|---|---|
| `bi` (제안) | max(안쪽→바깥 RMSE, 바깥→안쪽 RMSE). 두 방향 모두 맞아야 낮다 |
| `fwd` | 안쪽→바깥 RMSE. 외삽 방향 한쪽만 본다 |
| `rcv` | 무작위 5겹 교차 검증 RMSE |
| `bic` | 학습 창 전체에 적합한 BIC |
| `lin` | 선택 없이 선형 |
| `best` | 시험 오차가 가장 작은 식(사후, 상한) |

- 고른 식은 학습 창 전체에 다시 적합해 시험 구간을 예측한다. 평가는 잡음 없는 출력에 대한 RMSE다.
- **일치 집합 K:** `bi` 점수가 최솟값의 1.05배 이하인 식들이다. 연구자가 제안한 "둘 다 일치하는 애들만"에 해당한다.
- **K의 퍼짐:** 시험 구간에서 K에 속한 식들의 예측 폭(행별 최대−최소)의 평균이다. 필터를 통과한 식끼리 외삽에서 얼마나 다른지를 잰다.

**셀 분류** (경계 위치 기준, 정답 경계는 `regime_rules.statements`)
- `visible`: 정답 경계가 학습 표본의 AT 범위 안에 있다.
- `hidden`: 학습 범위 밖에 있고, 학습 창과 시험 구간 사이(또는 시험 구간 안)에 있다.
- `none`: 학습 창에서 시험 구간까지 사이에 경계가 없다.

## 4. 예측 (실행 전 고정)

| | 예측 | 판정 기준 |
|---|---|---|
| B1 | 경계가 없으면 `bi`가 무작위 CV보다 낫다. 학습 구간에만 맞는 식(`cubic` 등)을 더 잘 거른다 | `none` 셀 평균 RMSE: `bi` < `rcv` |
| B2 | 경계가 숨어 있으면 `bi`는 선형보다 낫지 않다 | `hidden` 셀 평균 RMSE: `bi` − `lin` > −0.2 MW |
| B3 | 경계가 보이면 `bi`가 선형보다 크게 낫다 | `visible` 셀 평균 RMSE: `lin` − `bi` ≥ 0.5 MW |
| B4 | 필터는 숨은 경계를 고르지는 못해도 모호함은 드러낸다. K의 퍼짐이 오차와 같이 움직인다 | `hidden`+`none` 셀에서 K 퍼짐과 `bi` 오차의 Spearman ρ > 0.3, 그리고 퍼짐 평균이 `hidden` > `none` |

- B2가 맞으면, 필터로는 우리 문제의 핵심(창 밖 레짐 변화)을 풀 수 없다.
- B4가 맞으면, 필터의 쓸모는 "식 고르기"가 아니라 "LLM 힌트가 필요한 곳 표시하기"다. 이 경우 HA 규칙의 관문과 연결된다.

## 5. 한계

- 후보 식 묶음은 사람이 정했다. LLM이 낼 식의 분포와 다르다.
- 반으로 나눈 창은 원래 창보다 좁다. 폭 2.5 창은 1.25°C씩이라 두 방향 점수가 잡음에 크게 흔들린다. 폭별로도 나눠 본다.
- K의 기준(1.05배)은 임의로 정했다. 0.02·0.10배로도 민감도를 본다(탐색).
