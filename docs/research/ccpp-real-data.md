작성: 2026-11-08  
상태: **판정 완료(2026-11-08, §9).** 사전 등록 `2cf65af`, 코드 `289d73b`(실행 전 커밋). 한 번 실행했다. R1–R4 모두 충족. **사후 대조군(§10, 사전 등록 밖): 24–32°C 어디에 "위는 평평"을 둬도 비슷한 이득이 난다. LLM의 몫은 방향과 위치를 그 범위 안에 고른 것이다.**  
관련: [검토](reviews/2026-11-08-real-data-validation.md), [LLM 진술 수집](llm-statement-collection.md) §5, [위험 제한](ccpp-risk-limit.md), [힌트 조립](ccpp-hint-assembly.md), [강건성](ccpp-robustness-tail-consensus.md)

## 1. 질문

쌍둥이에서 고정한 진술 사용 규칙(창 검사 + blend 0.5)을 실제 CCPP에 그대로 쓰면, LLM 진술이 데이터 적합(`R0`)보다 외삽을 해치지 않고 나아지게 하는가?

## 2. 범위 (연구자 결정, 2026-11-08)

- **이미 받아 둔 답만 쓴다.** 새 수집은 하지 않는다.
- 실데이터 조건은 `L0` 설명에 "6년 운전 기록, 전부하"를 더한 것뿐이다. S2(감도) 답이 없으므로 **HA는 평가하지 않는다.** HA의 실데이터 검증은 이 연구의 한계로 적는다.
- 모델: 다섯 모델(`gpt-oss-120b`, `qwen3-30b-a3b-instruct`, `gpt-oss-20b`, `gemma3-27b`, `llama33-70b`). 모델당 실데이터 답 105개(D0 21개 + D1 창 4개 × 21개).

## 3. 평가 설정

- 입력과 출력 모두 실제 CCPP다(9,568행, 출력 `PE`).
- 창, 폭(2.5·5·10°C, 학습 146·300·1,000행), 거리(5·10·15·20°C), 시험 구간 폭 2.5°C, 30행 미만 시험 구간 제외는 쌍둥이 격자와 같다(`grid.windows`).
- 반복 20회. 반복마다 창 안에서 학습 행을 다시 뽑는다(쌍둥이와 같은 seed). 잡음은 더하지 않는다. 실제 출력에 이미 잡음이 있다.
- **채점은 관측 출력 대비 RMSE다.** 잡음 없는 정답이 없으므로 모든 규칙이 같은 잡음 바닥(약 4.3 MW)을 공유한다. 규칙끼리의 차이만 해석한다.
- 진술 사용 방식은 쌍둥이와 같다(`risk_limits.run`의 창 검사, `compose`, blend 0.5). 코드에서 바꾸는 것은 "출력을 시뮬레이터 대신 관측값으로 쓴다" 하나다. 쌍둥이 결과가 바뀌지 않는지 회귀 테스트로 확인한다.

## 5. 지표

- 평균 RMSE (전체, 창 설정별)
- `harm`: 행 단위로 `R0`보다 1 MW 넘게 나쁜 비율
- `CVaR95`, `crash`(R0보다 4.3 MW 넘게 나쁜 행의 비율): [강건성](ccpp-robustness-tail-consensus.md) §3과 같은 정의
- 행 하나 = (창 설정, 폭, 거리, 반복)

**예측의 근거 (이미 본 실데이터 정보)**
- 도메인 점검에서 실데이터의 구간별 기울기를 봤다. 중간(8–25°C) −2.06, 27°C 위 −0.81, 8°C 아래 −1.45 MW/°C다. 고온 쪽 완만해짐이 저온 쪽보다 뚜렷하다. 그래서 R2는 고온 힌트의 이득을, R4는 저온 힌트의 무이득을 예측한다.
- 격자 문서에서 `hot->cold` 폭 2.5 거리 10의 `R0`(15.5 MW)와 비례식(5.5 MW)을 봤다. 고온 창이 평평해서 창 기울기로 저온까지 가면 크게 틀린다. 고온 경계 진술이 이것을 고칠 수 있다.
- 실데이터 창 요약(D1 프롬프트에 들어간 것)의 기울기를 봤다. `hot->cold` 창 +0.10(표준오차 0.59), 나머지 −1.6–−2.0이다.
- **LLM 규칙의 실데이터 결과는 보지 않았다.**

## 9. 결과 (2026-11-08, 한 번 실행)

코드: `analysis/llm_statements/real_validation.py`. 출력: `runs/real/real.{txt,json}`. 규칙마다 680행(창 설정 4 × 폭 3 × 거리 × 반복 20, 시험 30행 이상)이다.
- `risk_limits.run`에 "관측 출력" 방식을 더했다. 쌍둥이 결과는 이전과 비트 단위로 같다(`assert_frame_equal`, `check_exact=True`).
- 테스트 4개를 더했다. 그중 하나는 선형 출력을 넣으면 `R0` 오차가 0이고, 빈 진술이 `R0`와 같은지 확인한다.
- **점검:** `hot->cold` 폭 2.5 거리 10의 `R0`는 15.16 MW로, 격자 문서의 15.5 MW와 비슷하다. 표본 방식(20회 다시 뽑기)이 달라 조금 다르다.
- **데이터셋 인식:** 단어 단위로 찾았을 때 다섯 모델 모두 0건이다. 처음 손으로 찾을 때 "UCI"가 "reducing" 안에서 잡혔다. 그래서 단어 경계를 넣었다.

**전체 (관측 출력 대비 평균 RMSE, MW; `R0` 10.91)**

**창 설정별 (blend 0.5, MW)**

| | `cold->hot` | `hot->cold` | `mid->cold` | `mid->hot` |
|---|---:|---:|---:|---:|
| `R0` | 10.15 | 16.28 | 6.77 | 6.54 |
| `POOL` | 10.07 | **13.00** | 6.77 | **5.40** |
| 120b `S0maj` (8°C 아래) | **8.67** | 16.32 | 7.30 | 6.54 |

**사전 예측 판정**

| | 결과 | 판정 |
|---|---|---|
| R1 다섯 모델 `S0maj` ≤ `R0` + 0.10 | 9.65–10.55, 모두 `R0`(10.91)보다 낮음 | **충족** |
| R2 `POOL` < `R0` | 9.65 < 10.91 | **충족** |
| R3 다섯 모델 `crash` ≤ 0.05 | 최대 0.016 (Llama) | **충족** |
| R4 120b는 저온 방향 창에서 이득 없음 | 12.81 ≥ 12.58 − 0.10 | **충족** |

**해석**
1. **고온 경계 힌트가 실데이터 외삽을 1.26 MW(12%) 줄였다.** 이득의 대부분은 `hot->cold` 창(16.28 → 12.85–13.96)에서 나왔다. 고온 창(31–34°C)이 평평해서 창 기울기만으로 저온까지 가면 크게 틀린다. "30°C 위는 평평"이라는 진술이 창을 평평한 구간으로 보고, 경계 아래에서는 정상 기울기로 잇게 한다. `mid->hot`도 6.54 → 5.10–5.67로 나아졌다.
2. **데이터만 쓰는 사전(`coef_prior`)보다 낫다.** `hot->cold`에서 14.94 대 12.85–13.96이다. 창 밖 정보가 데이터 안의 정보보다 많이 준다는, 양방향 일치 실험의 결론과 같은 방향이다.
3. **120b의 저온 진술은 엇갈린다(R4, 예측대로).** `cold->hot`에서는 10.15 → 8.67로 가장 좋다(창 4.5–6.9°C가 "평평" 구간이라 고온 쪽으로 정상 기울기를 쓴다). `mid->cold`에서는 6.77 → 7.30으로 나빠진다. 실제 8°C 아래 기울기는 −1.45로 평평하지 않기 때문이다.
4. **창 요약을 주면 이득이 사라진다(`D1maj`, 보조).** 120b, 20b, Llama는 창 요약을 보면 "경계 없음"으로 바꿔 `R0`가 된다. qwen과 gemma는 `hot->cold`에서 경계를 창 끝(33.8°C, 34°C)에 놓아 효과가 없다. 창 요약이 창 밖 지식을 오히려 지운다. 쌍둥이에서 D1이 저온 거짓 경보를 줄였던 것과 같은 작용이지만, 여기서는 맞는 힌트까지 지웠다.
5. **꼬리는 작다.** `crash`는 Llama 0.016이 최대다. Llama(25°C 위)는 경계가 이른 만큼 `harm`이 0.068로 가장 크다.

**주의할 점**
- 실데이터의 레짐 정답을 모른다. 이득은 "고온 쪽에서 실제 기울기가 완만해진다"(27°C 위 −0.81)와 맞는다. 이 사실은 사전 등록 전에 알고 있었고 예측에 썼다(§6).
- 네 모델이 같은 진술(28–30°C 위)을 냈으므로 이 이득은 사실상 진술 하나의 결과다. 모델 다섯 개가 독립 증거 다섯 개는 아니다.
- HA는 평가하지 않았다. 실데이터에서 검증된 것은 "다수결 진술 + 창 검사 + blend 0.5"다.
- 발전소 하나의 사례다.

## 10. 사후 대조군 (2026-11-08, 사전 등록 밖)

§9를 본 뒤 연구자가 검토를 요청해 추가했다. **사전 등록에 없던 분석이며 R1–R4 판정을 바꾸지 않는다.** 쌍둥이 단계에는 틀린 진술 대조군이 있었는데 실데이터 등록에는 빠졌다. 그래서 "경계를 아무 데나 둬도 같은 이득이 나는가"를 확인하지 못했다.

코드: `analysis/llm_statements/real_posthoc.py`. 출력: `runs/real/posthoc.{txt,json}`.
- LLM 없이 경계 하나를 손으로 고정했다. "X°C 위는 평평"은 X = 18–36(2°C 간격), "X°C 아래"는 X = 4–16이다.
- §9와 같은 규칙(창 검사 + blend 0.5), 같은 표본(반복 20)으로 채점했다.
- **점검:** 29°C 위 = 9.650(§9 `POOL`), 30°C 위 = 9.654(qwen·20b), 8°C 아래 = 10.550(120b). §9와 같다.
- 구간은 34개 창 조건(설정 × 폭 × 거리)을 다시 뽑는 bootstrap이다. 조건들이 같은 데이터를 겹쳐 쓰므로 **실제보다 좁다.**

**해석**
1. **이득 자체는 우연이 아니다.** `POOL` 구간은 0을 넘지 않는다(낙관적 구간이라는 점은 위에 적었다).
2. **이득은 LLM 고유의 것이라고 보기 어렵다.** 24–32°C 사이 어디에 "위는 평평"을 둬도 −0.8 ~ −1.25 MW다. LLM이 한 일은 방향("위")과 위치(25–30°C)를 이 범위 안에서 고른 것이다.
   - 18–36°C에서 위치를 균등하게 고르면 평균 차이는 −0.49 MW다. LLM 다수결(−1.26)이 이보다 낫다.
   - 방향까지 무작위로 고르면 기대 이득은 더 작다("아래" 경계는 대부분 0 근처이거나 해롭다).
3. **이득은 한 설정에 몰려 있다.** `hot->cold`를 빼면 `POOL`의 평균 차이는 −0.29 MW다. `mid->cold`는 진술이 닿지 않아 모든 고온 진술에서 효과가 0이다.
4. **120b의 저온 진술은 이득이 불확실하다.** 구간이 0을 포함한다. 6°C 아래로 옮기면 조금 낫다(−0.48).

**원고에 쓸 수 있는 주장과 쓸 수 없는 주장**
- **쓸 수 있다:** "LLM의 고온 평탄 경계는 사후 대조군에서 이득이 나는 범위(24–32°C) 안에 있었고, 같은 범위에서 무작위로 고른 경계보다 나았다."
- **이 대조군 없이 쓰면 안 된다:** "LLM 힌트가 실데이터 외삽 오차를 12% 줄였다." 같은 이득은 도메인 지식으로 고른 고정 경계로도 얻는다.
- **추가로 약한 점**
  - R1(≤ `R0` + 0.10)과 R4("이득 없음" 예측)는 맞히기 쉬운 기준이었다.
  - 27°C 위 기울기 변화는 등록 전에 이미 알았다(§8).
  - 데이터셋 인식은 이름 언급만 셌다. 검토 문서가 권고한 직접 질문은 하지 않았다.
