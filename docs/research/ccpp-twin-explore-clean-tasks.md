# 탐색: 학습 구간에 레짐 정보가 없는 과제 후보 (2026-11-12)

**상태: 설계용 탐색.** LLM 답을 쓰지 않았고 어떤 규칙도 채점하지 않았다. 잡음 없는 세계 값만 썼다. 진행 중인 확증([등록](ccpp-twin-outside-confirmation.md))은 그대로다.

배경: [검토](reviews/2026-11-12-info-free-task-selection.md), 누수 점검(decision-log 2026-11-12).

## 1. 기준

코드 `analysis/ccpp_twin/explore/clean_tasks.py`, 출력 `analysis/ccpp_twin/runs/explore_clean_tasks.txt`.

- 누수 = 학습 구간 안 |레짐 세계 − 기본 세계|의 최댓값. **깨끗함: 0.5 MW 이하.**
- 망가짐 = 창 전체 선형 적합의 시험 구간 오차. **중요함: 레짐 세계 오차가 기본 세계의 같은 창보다 3 MW 이상 큼.**
- 꺾임 위치 k는 평균 차이가 1 MW에 처음 닿는 온도로 잡았다. 등록 실험의 명목 위치와 다르다(예: 등록 증발 냉각기 24°C, 여기서는 19°C).
- 창 끝과 k의 거리 1, 2, 4°C, 폭 5, 10°C. 시험 구간은 등록과 같은 정의.

## 3. 읽는 법

1. **급하게 켜지는 세계에서는 조건에 맞는 과제가 충분하다.** 학습 구간에는 레짐 흔적이 0.5 MW 미만이고, 데이터만 쓰면 9–13 MW 틀린다. 레짐이 없으면 같은 창에서 0.5–1.5 MW다.
2. **등록된 증발 냉각기와 발전기 고온 한계는 기준에 맞지 않는다.** 서서히 시작해서 깨끗한 창이 없고, 시험 구간 효과도 작다.
3. **등록된 칠러는 이미 깨끗하다.** 진행 중인 확증에서 칠러 과제는 "정보 없음" 해석이 가능하다.
4. **꺾임 위치가 9.5–14.5°C, 21.5–25.5°C로 퍼진다.** 고정 기본값(8°C, 27°C)이 발전소마다 다르게 틀리는 조건을 만들 수 있다.
5. 시험 자료는 모든 후보에서 346행 이상이다.

## 4. 한계

- 세계를 급하게 켜지도록 바꾼 것은 설계 선택이다. 실제 설비가 얼마나 급하게 켜지는지는 문헌 확인이 필요하다. 운전원이 켜고 끄는 증발 냉각기는 급한 쪽이 자연스럽지만 확인하지 않았다.
- 누수 기준 0.5 MW와 망가짐 기준 3 MW는 임의로 잡았다. 등록 때 확정해야 한다.
- 새 세계에는 LLM 답이 없다. 설명문(제한 값, 설정 온도)을 새로 쓰고 수집해야 한다.
- 실제 CCPP에는 잡음 없는 정답이 없어 이 기준을 그대로 못 쓴다.
