## 1. 목적

[설계 기록](ccpp-extrapolation.md)의 D5·D6을 구현한다. 정답을 아는 세계에서 다음을 분리해 확인한다.

- A1: 외삽 구간에서 같은 메커니즘이 이어지는가, 레짐이 바뀌는가
- A2: 비례식(출력 ∝ 공기 밀도)이 먼 거리의 평균 경로에 가까운가
- A3: CCPP 출력 곡선의 양 끝이 평평한 S자가 어떤 물리에서 나올 수 있는가
- A4: 진공도(V) 등 공변량의 범위 이탈이 방향 비교를 왜곡하는가
- A5: 줄일 수 없는 잡음과 모델 오차의 분리

## 2. 이전 시도와의 차이

| 항목 | 이전 시도 (prior_module) | 이번 v0 |
|---|---|---|
| 물리 | 축소 Brayton(가스터빈만), P = C₁/T − C₂ | **복합 사이클**: 가스터빈 + 배열회수보일러(HRSG) + 증기터빈, V가 증기터빈 효율에 영향 |
| 레짐 | 없음 | **켜고 끌 수 있는 모듈**: 저온 출력 상한, 고온 흡기 증발냉각 |
| 입력 | 합성 입력, 또는 실제 X를 쓰는 설계안만 존재(미구현) | **실제 CCPP 입력 그대로 사용**(empirical X). 공변량 기하가 실제와 같다 |
| Y | 통계적 teacher 설계안 | 물리 식으로 계산한 출력 + 이름 붙은 잡음 |

## 3. 물리 모델

입력: AT(°C), AP(mbar), RH(%), V(cm Hg). 출력: 순출력 PE(MW)와 구성 성분.

### 3.1 가스터빈 (Brayton)

1. 흡기 온도 T₁ = AT + 273.15 K. 증발냉각 모듈이 켜지면 T₁ ← T₁ − ε·(T_db − T_wb). 습구온도 T_wb는 Stull(2011) 근사식.
2. 습공기 밀도 ρ = P/(R_d·T₁)·(1 + w)/(1 + 1.608w), 습도비 w = 0.622·p_v/(P − p_v), p_v = RH·p_sat(T₁).
3. 공기 질량유량 m = ρ·Q_vol (흡기 체적유량 고정, 고정 IGV 가정).
4. 압축기: T₂ = T₁·[1 + (π^κ − 1)/η_c], κ = (γ − 1)/γ. 압축 일 W_c = m·c_p,a·(T₂ − T₁).
5. 연소기: 터빈 입구 온도 T₃ 고정. 연료/공기비 f = c_p,g(T₃ − T₂)/(η_b·LHV − c_p,g·T₃), 연소가스 유량 m_g = m(1 + f).
6. 터빈: T₄ = T₃·[1 − η_t(1 − π^−κ)], 터빈 일 W_t = m_g·c_p,g·(T₃ − T₄).
7. 가스터빈 출력 P_gt = η_gen·(W_t − W_c).
8. **저온 상한 모듈**(선택): P_gt ← softmin(P_gt, P_gt,max). 저온에서 발전기·기계 정격 또는 IGV 제어로 출력이 묶이는 상황.

### 3.2 증기 사이클

1. 회수 열량 Q_hr = m_g·c_p,g·(T₄ − T_stack), T_stack 고정.
2. 증기터빈 효율 η_st(V) = η_st,0 − k_V·(V − V_ref). V가 클수록(진공 악화) 효율이 떨어진다.
3. 증기터빈 출력 P_st = η_gen·η_st(V)·Q_hr.

### 3.3 순출력과 잡음

PE = P_gt + P_st − P_aux + ε. ε는 관측되지 않는 운전 상태를 나타내는 잡음이며 SD를 설정한다. 잡음 난수열은 이름과 seed로 고정한다.

## 4. 순환 문제를 피하는 장치

- 모델에 줄 prior 카드는 **단순화된 식**이다: 비례식(PE ∝ ρ), V의 선형 효과. 시뮬레이터는 압축 일, 연료 유량, 증기 사이클, 레짐 모듈을 포함하므로 prior와 같지 않다.
- prior와 시뮬레이터의 차이를 설정으로 조절한다: 레짐 모듈 켜기/끄기, 증기 사이클 비중, 잡음 크기.
- 시뮬레이터 파라미터는 공개 문헌 수준의 대표값에서 시작하고, 실제 CCPP와의 맞춤은 **출력 수준(평균, 범위) 정도로만** 한다. 실제 곡선을 세밀하게 맞추면 “실제를 외운 시뮬레이터”가 되어 해석력이 떨어진다.

### v0 모양 비교 결과 (2026-11-04)

실제 CCPP 입력 9,568행을 그대로 넣고 잡음 없이 계산했다. 시뮬레이터 파라미터는 실제 PE로 맞추지 않았다(기본값 그대로). 실제 PE는 모양 비교에만 썼다.

| 설정 | 평균 PE | 실제 대비 RMSE | 국소 기울기: 저온 5.5°C / 중간 15.5°C / 고온 33.5°C |
|---|---:|---:|---|
| 실제 CCPP | 454.4 | — | −1.03 / −2.46 / −0.40 |
| 기본 (모듈 없음) | 449.5 | 9.36 | −1.89 / −3.44 / −2.10 |
| 저온 상한 | 449.0 | 9.21 | 0.14 / −3.44 / −2.10 |
| 증발냉각 | 452.7 | 6.05 | −1.89 / −3.34 / −0.18 |
| 둘 다 | 452.1 | 5.82 | 0.14 / −3.33 / −0.18 |

해석:

1. **고온 끝 평탄화는 흡기 증발냉각 가설로 재현된다.** 고온 국소 기울기가 −2.1 → −0.2로 바뀌어 실제(−0.4~−0.6)와 비슷해졌다. 실제 발전소에 증발냉각기가 있는지는 확인하지 않았다.
2. **저온 끝 평탄화의 일부는 모듈 없이도 나온다.** 기본 모델에서도 5.5°C 기울기가 −1.9로 중간(−3.4)보다 완만하다. 실제 입력의 V·RH·AP가 저온에서 함께 움직이기 때문으로 보인다. 즉 S자의 저온 쪽은 일부가 **공변량 기하의 효과**다(A3·A4와 관련).
3. **저온 상한 모듈(기본값)은 너무 강하다.** 기울기가 0.1로 실제(−1.0)보다 평평해진다. 상한 크기는 실험 축으로 두고, 실제 PE로 맞추지는 않는다.
4. **중간 기울기는 실제보다 가파르다**(−3.3~−3.4 대 −2.3~−2.6). 고정 T₃·고정 체적유량 가정 때문일 수 있다. 쌍둥이의 목적이 실제 재현이 아니라 원인 분리이므로 그대로 두되, 비례식 기울기(−1.4~−1.7)와의 차이가 실제보다 크다는 점은 해석 시 반영한다.

## 6. 가정과 한계

- 고정 체적유량, 고정 T₃, 고정 압력비, 상수 비열은 단순화다. 실제 발전소 제어(IGV, 배기온도 제어, 부분부하)는 레짐 모듈 두 개로만 근사한다.
- 실제 CCPP 발전소에 증발냉각기가 있는지, 저온 출력 상한이 있는지는 확인하지 않았다. **두 모듈은 S자 모양의 원인에 대한 가설**이며, 시뮬레이터로 “이런 물리라면 이런 모양이 나온다”를 보이는 용도다.
- V는 실제 데이터의 값을 그대로 쓰므로 V와 AT의 관계는 실제와 같다. V의 원인(냉각수 온도 등)은 모델링하지 않는다.
