# 사전 등록: 모양 라이브러리 조립 (`HA_shape`)

작성: 2026-11-08  
상태: **사전 등록.** 결과 RMSE는 이 문서를 커밋하기 전에 계산하지 않았다. 다만 **모양 답 자체는 이미 채점해서 안다**([모양 수집 §9](ccpp-shape-elicitation.md), [2단계 §9](ccpp-shape-elicitation-2.md)). 그래서 어느 모델이 어느 모양을 줄지는 알고, 그 모양이 결과 RMSE에 어떻게 작용하는지만 모른다.  
관련: [검토](reviews/2026-11-08-series-composition-extrapolation.md), [힌트 조립 §13](ccpp-hint-assembly.md), [대조군 §9](ccpp-world-blind-controls.md)

## 1. 질문

`HA`는 경계 너머 기울기를 **고정 계수 0**(평평)으로 둔다. 이것을 LLM이 고른 모양으로 바꾸면(`HA_shape`) 결과가 좋아지는가, 나빠지는가? 데이터 없이 정한 고정 계수 0.5(`HA_half`)와 비교하면 LLM 모양은 정보를 더 담는가?

C2("모양은 기본 답에 끌린다")는 구조 채점의 결과이고, C3("모양은 데이터가 정한다")는 결과 채점의 설계 원칙이다. 이 실험은 둘을 같은 결과 지표(RMSE)로 잇는다.

## 2. 규칙 (데이터 전에 고정)

- **경계는 `HA` 그대로다.** 바꾸는 것은 경계 너머 기울기 계수뿐이다. 창 검사·`blend` 0.5·세계·창·반복(20)·seed는 `HA` 검증과 같다.
- **모양 → 계수:** `near_zero` 0.0, `weaker` 0.5, `same_or_stronger` 1.0(진술이 효과를 내지 않음), `opposite` −1.0(기울기 부호 반전). 그 밖의 답이나 항목이 없으면 `HA` 기본값 0.0(대체 횟수를 보고한다).
- **모양 찾기:** 모양 수집 1단계(`runs/shape`, 세계·수준마다 21표본)에서 `HA` 경계와 같은 쪽, 3°C 안의 항목을 모아 `response_beyond` 다수결을 쓴다. 동률이면 기본값. 경계를 **정답이 아니라 `HA`가 정한 위치**에 맞춘다. 2단계 답은 세계가 셋뿐이라 쓰지 않는다.
- **경계가 둘인 진술**(`evap+cap_mild`)은 경계마다 계수를 따로 둔다. `compose`에 경계별 계수를 넣을 수 있게 확장했다(스칼라를 주면 기존과 같다. 테스트로 고정).
- **비교군:** `HA`(계수 0), `HA_half`(모든 경계 0.5, 데이터·LLM 없음), `SHAPE_ORACLE`(`HA` 경계에 쌍둥이 정답 모양: 저온 상한 `near_zero` 0.0, 증발 `weaker` 0.5).

**쌍둥이의 실제 경계 너머 기울기 비율(정상 기울기 −2.64 대비):** 증발 24°C 위 0.58(RH 30)–0.96(RH 90), RH 50에서 0.75. 저온 상한 아래 약 −0.1(출력이 거의 평평). 즉 증발 세계에서는 `HA`의 계수 0보다 0.5가 진실(0.75)에 가깝고, 상한 세계에서는 0이 맞다.

## 3. 지금 아는 것 (모양 답)

- Gemma·20b·120b·Qwen: 증발 경계에서 `weaker`(0.79–1.00), 상한 경계에서 `near_zero`(0.76–1.00).
- Llama: 증발 경계에서 모두 `same_or_stronger`(모양 정답률 0.00). 상한 위치 항목 없음.
- 검증 모델 셋의 `HA`에는 상한 부품이 없다. 그래서 모양이 작용하는 경계는 사실상 **증발 경계뿐**이다. `HA_shape`는 Gemma·20b에서 증발 계수 0 → 0.5, Llama에서 0 → 1.0(증발 이득이 사라짐)이 될 것으로 안다.

## 4. 예측 (검증 6칸)

| | 예측 | 판정 | 확신 |
|---|---|---|---|
| J1 안전 | `HA_shape` 해 비율 ≤ 0.05 | 6칸 모두 | 높음. 계수는 −1~1이고 `blend` 0.5가 막는다 |
| J2 기본 답의 손해 | Llama 2칸에서 `HA_shape` > `HA` | 2칸 모두 | 중간. `same_or_stronger`가 증발 이득(≈0.3 MW)을 지운다 |
| J3 우연의 이득 | Gemma·20b 4칸에서 `HA_shape` ≤ `HA` | 3칸 이상 | 중간. `weaker` 0.5가 0보다 진실(0.75)에 가깝다 |
| J4 LLM 모양 대 고정 0.5 | `HA_shape` < `HA_half` | **3칸 이하** (LLM 모양이 고정 계수보다 낫지 않다) | 중간 |

보고만: `SHAPE_ORACLE` − `HA`(정답 모양이 주는 상한), 대체 횟수, 세계별 분해, 개발 칸.

**결과별 해석 (미리 적음)**
- **J2·J3·J4 모두 충족:** 모양을 받아 쓰면 기본 답이 진실과 맞는 모델은 이득을, 반대 기본 답을 가진 모델은 손해를 본다. 그리고 고정 0.5가 LLM 모양만큼 좋다. → C3 원칙("모양은 데이터나 고정 규칙이 정한다") 유지. C2를 결과 지표로 뒷받침. `HA`의 계수 0은 증발 세계에서 비효율이지만, 바꾸려면 새 검증 자료가 필요하다(사후 변경 금지). `HA_half`는 비교군으로만 보고한다.
- **J4 실패(LLM 모양이 고정 0.5를 4칸 이상 이김):** 같은 방향 모양에 한해 LLM 모양이 세계 정보를 담는다. C2의 "모양은 믿을 수 없다"를 "반대 방향 모양과 기본 답이 다른 모델에 한해"로 좁힌다.
- **J2 실패(Llama가 손해를 보지 않음):** 창 검사와 `blend`가 틀린 모양을 흡수한다. 안전 주장(C3)이 강해지고, 모양 수신의 위험은 작다고 적는다.
- **J3 실패:** `weaker`(0.5)가 0보다 나쁘다. 쌍둥이 비율 0.75와 맞지 않으므로 창 검사 기각이나 RH 의존이 원인인지 세계별 분해로 본다. 결론을 내지 않는다.
- **J1 실패:** 모양 수신이 해를 끼친다. C3의 "모양은 받지 않는다" 원칙의 직접 근거가 된다.

## 5. 한계

- 모양 답을 이미 봤다. 예측 J2·J3은 모양 라벨에서 거의 따라 나오고, 불확실한 것은 결과 RMSE 크기뿐이다.
- 검증 모델의 `HA`에 상한 부품이 없어 상한 모양은 시험되지 않는다. 개발 칸(120b, Qwen)에서만 보인다.
- 모양 1단계의 질문은 `HA` 수집(S0·S2)과 다른 질문이다. 같은 모델의 다른 표본이라 "같은 답의 모양"은 아니다.
- 계수 대응(0 / 0.5 / 1 / −1)은 임의다. 특히 `weaker` = 0.5는 쌍둥이 비율(0.58–0.96)과 우연히 가깝다.
- 시스템 하나, 검증 칸 6개.

### 7.3 해석 (사전에 적은 해석 §4 적용)

- **J2·J3·J4 모두 충족:** 모양을 받아 쓰면 기본 답이 진실과 맞는 모델(Gemma·20b, `weaker`)은 고정 0.5와 같은 값을 얻고, 반대 기본 답을 가진 모델(Llama, `same_or_stronger`)은 증발 이득의 약 40%(0.12–0.14 MW)를 잃는다. LLM 모양이 고정 0.5를 이긴 칸은 1개(0.005 MW)다. → **C3 원칙 유지: 모양은 데이터나 고정 규칙이 정한다.** C2("모양은 기본 답에 끌린다")가 결과 지표에서도 확인된다.
- **J1 충족:** 틀린 모양도 해 비율을 올리지 않았다. Llama의 `HA_shape` 해 비율은 0.000이다. `same_or_stronger`(계수 1.0)는 진술을 무효로 만들어 `R0`에 가까워지는 방향이고, `blend` 0.5가 나머지를 막는다. 모양 수신의 위험은 "이득 상실"이지 "해"가 아니다.
- **예상과 다른 점 (사후 관찰, 판정 아님):** §2에서 증발 세계의 실제 기울기 비율이 0.75이므로 계수 0.5가 0보다 나을 것으로 봤는데, gemma L1·Llama L1에서는 `SHAPE_ORACLE`(0.5)이 `HA`(0)보다 0.035 나빴다. 이유로 짐작되는 것은 `blend` λ = 0.5다. 최종 예측은 `p0 + 0.5 × delta`이므로 계수 0인 진술도 데이터 기울기의 절반을 남긴다. 계수 0.5를 주면 실효 기울기가 0.75 근처가 되는데, 창 밖 시험 구간(24°C + 5–20°C)에서는 RH가 높아 실제 비율이 0.87–0.96에 가깝거나, 반대로 창 검사가 통과시키는 창의 기울기가 이미 평균보다 완만한 경우가 섞여 있을 수 있다. 세계별 분해(`evap` 6.478 대 6.665)만 적어 두고 원인은 판정하지 않는다.

### 7.4 원고에 주는 영향

- **C2와 C3이 같은 지표로 이어진다.** "모양은 기본 답에 끌린다(구조)"가 "모양을 받아 쓰면 기본 답이 다른 모델은 이득을 잃고, 같은 모델도 고정 계수보다 낫지 않다(결과)"로 이어진다. 원고 §5(진단)와 §6(안전 조립) 사이의 연결 문단으로 쓴다.
- **`HA`의 계수 0은 바꾸지 않는다.** `SHAPE_ORACLE`조차 거의 이기지 못했다. "모양은 데이터가 정한다"의 실제 뜻은 "`blend`가 데이터 기울기를 절반 남긴다"이고, 이것이 모양 정보 없이도 충분했다.
- **급수 조립 질문의 답:** 항을 더하는 것도, 모양을 더 받는 것도 외삽을 강하게 만들지 않았다. 외삽 오차를 좌우하는 것은 큰 꺾임의 **위치**([대조군 §9](ccpp-world-blind-controls.md)의 "8°C 아래")다. 모양 정보의 한계 이득은 정답 모양을 줘도 0.02 MW 안이다.
- 한계는 §5 그대로다. 특히 계수 대응(0.5)은 임의이고, 상한 모양은 시험되지 않았다.
