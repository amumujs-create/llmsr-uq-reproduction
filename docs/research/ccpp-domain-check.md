# CCPP 쌍둥이의 도메인 근거 점검 (2026-11-04)

[쌍둥이 설계](ccpp-twin-design.md) · [LLM 진술 수집 §12.4](llm-statement-collection.md) · [결정 기록](decision-log.md)

## 왜 하나

`gpt-oss-120b`가 쌍둥이 설정과 다른 답을 했다(§12.4).

- 가스터빈 민감도: 0.5 %/°C (쌍둥이 0.64 %/°C)
- 결빙 방지 가열·배기 측 한계: “작동한다”

이것이 LLM의 오류인지, 쌍둥이가 현실과 다른 것인지 가려야 한다. 그래서 쌍둥이 매개변수를 문헌과 실제 CCPP 데이터에 대조한다.

자료의 한계: 검색은 2026-11-04에 했고, 대부분 학술 시뮬레이션·특허·업계 기사다. OEM 성능 곡선은 구하지 못했다. 숫자는 범위로만 쓴다.

## 1. 실제 발전소 구성

- UCI CCPP 데이터(Tüfekci 2014)의 발전소: 정격 480 MW. ABB GT13E2 가스터빈 2기(각 160 MW), 이중압 배열회수보일러 2기, 증기터빈 1기(160 MW). 2006–2011년 전부하 운전 9,568행. 근거: [arXiv 1907.11653](https://arxiv.org/pdf/1907.11653), [condvis 문서](https://search.r-project.org/CRAN/refmans/condvis/html/powerplant.html). Tüfekci 원문은 확인하지 못했다.
- 쌍둥이(데이터 중앙값 조건, 15°C): 가스터빈 342.8 MW, 증기터빈 123.7 MW, 순출력 461.5 MW.

| 항목 | 실제 (정격 기준) | 쌍둥이 (15°C) | 판정 |
|---|---|---|---|
| 가스터빈 몫 | 320 / 480 = 67% | 343 / 466 = 74% | 쌍둥이가 가스터빈 쪽으로 약간 치우침 |
| 가스터빈 출력 | 2 × 160 = 320 MW (ISO 15°C) | 343 MW | 쌍둥이가 7% 높음 |
| 순출력 범위 | 데이터 420–496 MW | 대체로 410–490 MW | 비슷함 |

## 2. 가스터빈 출력의 외기온도 민감도

| 출처 | 값 |
|---|---|
| [포그 냉각 연구 (중형·항공 전환형)](https://rpsonline.com.sg/proceedings/9789810838133/html/039.php) | 0.5–0.9 %/°C |
| [나이지리아 시뮬레이션](https://journals.unizik.edu.ng/ujtpms/article/download/5978/4965/13605) | 0.54–0.9 %/°C |
| [Power Engineering 기사](https://www.power-eng.com/operations-maintenance/why-keeping-cool-keeps-output-high/) | 약 0.4 %/°F ≈ 0.47 %/°C (변환이 기사 안에서 일관되지 않음) |
| [이라크 발전소 연구](https://rengj.mosuljournals.com/index.php/rengj/article/view/32), [WCE 2018 모델](https://www.iaeng.org/publication/WCE2018/WCE2018_pp626-629.pdf) | 1.05, 1.22 %/°C |
| 복합발전 전체: [10°C당 ISO 출력의 5–10%](https://czasopisma.pan.pl//Content/116173/PDF/04_paper.pdf) | 0.5–1.0 %/°C |

- 쌍둥이: 가스터빈 −2.19 MW/°C = **0.64 %/°C**, 순출력 −2.67 MW/°C = 0.58 %/°C.
- `gpt-oss-120b` (`S2`): **0.5 %/°C**.
- 실제 CCPP, 8–25°C 다중회귀의 외기온도 계수: −2.06 MW/°C ≈ 0.45 %/°C (순출력 기준).

**판정: 쌍둥이와 LLM 모두 문헌 범위(대략 0.5–0.9 %/°C) 안에 있다.** LLM 답이 틀렸다고 할 수 없다. 반대로 쌍둥이 값도 틀렸다고 할 수 없다. 둘 다 실제 순출력 민감도(0.45 %/°C)보다 약간 크다.

→ **채점에 쓸 함의:** 민감도를 “쌍둥이 값 ±0.7 MW/°C”로 채점하면, 현실적인 답이 틀린 것으로 처리될 수 있다. 문헌 범위 채점(0.5–0.9 %/°C)을 병행해야 한다.

## 3. 저온 출력 상한

- 추운 날에는 공기 밀도가 커져 가스터빈 출력이 명판을 넘을 수 있다. 제어계는 발전기를 보호하려고 출력 한계를 둔다. 발전기 출력은 고정자 전류로 정해지기 때문이다. ([control.com Frame 5 토론](https://control.com/forums/threads/base-load-limit-of-frame-5-gas-turbine.48401/post-200022))
- 출력 한계나 터빈 입구온도 한계에 닿으면 IGV(입구 안내 깃) 일정이 바뀐다. ([US11619178](https://patents.google.com/patent/US11619178))
- 상한이 시작되는 온도(꺾이는 점)는 OEM 제어 사양에 달려 있다. 이번 검색에서는 구체적인 값을 찾지 못했다.

**실제 CCPP에서의 흔적 (다중회귀, 외기온도 구간별)**

| 구간 | n | 외기온도 계수 | 기압 계수 |
|---|---:|---:|---:|
| 8°C 미만 | 610 | −1.45 | **−0.095** |
| 8–25°C | 6,189 | −2.06 | +0.071 |
| 27°C 이상 | 1,817 | −0.81 | +0.275 |

- 저온에서 외기온도 기울기가 30% 완만해진다.
- 더 눈에 띄는 것은 기압 계수다. 기압이 높으면 공기 밀도가 커져 출력이 늘어야 한다. 그런데 8°C 미만에서는 부호가 음수로 바뀐다. **출력이 공기 밀도에 반응하지 않는 상한 상태와 맞는 신호다.**
- 다만 표본이 작고, 변수 사이 상관이 크며(외기온도–진공 상관 0.84), 결빙 방지 가열(4절)과도 구분되지 않는다. 증거가 아니라 단서로만 쓴다.

**판정: 저온 상한 모듈은 물리적으로 근거가 있다.** 쌍둥이의 꺾이는 점(6°C, 9°C)은 데이터 분위수로 정한 값이라 OEM 근거는 없다. 실제 데이터의 단서는 대략 8°C 아래를 가리킨다.

## 4. 흡기 결빙 방지 가열 (쌍둥이에 없음)

| 출처 | 작동 조건 |
|---|---|
| 특허 [US9359959B2](https://patents.google.com/patent/US9359959B2/en) 등 | 대략 −15 ~ 8°C, 상대습도 약 65% 이상 |
| 다른 특허 | 4°C 미만, 상대습도 70% 이상 |
| [Braden 제품 자료](https://www.energy-xprt.com/products/gas-turbine-anti-icing-system-509061) | 4°C 미만, 상대습도 50% 이상 |

- 실제 CCPP: 외기온도 최저 1.8°C, 8°C 미만 구간의 상대습도 중앙값 85%. **실제 발전소에서 결빙 방지 가열이 작동했을 조건이 데이터에 있다.**
- 8°C 미만에서 상대습도 80% 이상인 행의 평균 출력이 1.9 MW 낮다(484.0 대 485.9). 습도 자체의 효과와 섞여 있어 판단할 수 없다.

**판정: LLM이 “결빙 방지 가열이 작동한다”고 한 것(60–90%)은 실제 발전소에 대해서는 그럴듯한 답이다.** 쌍둥이 채점에서 거짓 경보가 되는 것은 쌍둥이가 이 메커니즘을 빼서다.

## 5. 흡기 증발냉각

- 증발냉각은 건구온도와 습구온도 차이가 클 때(덥고 건조할 때) 효과가 있다. 습구온도가 0°C 이상이고, 거의 전부하일 때 켠다. ([특허 6837056](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/6837056), [7353655](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/7353655))
- 켜는 온도의 구체적인 값은 찾지 못했다. 현장과 OEM마다 다르다.
- 쌍둥이: 시작 24°C, 효율 0.85. 효율 85–90%는 매체식 냉각기의 흔한 값이지만, 이번 검색에서 직접 근거는 찾지 못했다.

**실제 CCPP:** 27°C 이상에서 외기온도 기울기가 −0.81로 크게 완만해진다(중간 −2.06). 그런데 증발냉각이라면 습할수록 냉각이 덜 되므로, 상대습도 계수가 더 음수가 되어야 한다. 실제로는 −0.127 → −0.059로 **오히려 약해졌다.** 이 발전소에 증발냉각기가 있는지는 확인되지 않았다. 고온 평탄화의 원인은 다른 것일 수 있다(배기온도 제어, 진공 등).

**판정: 증발냉각 모듈은 물리적으로 타당한 가설이다. 하지만 실제 CCPP에서는 습도 신호가 맞지 않는다.** 쌍둥이 설계 문서의 기존 한계(증발냉각기 존재 미확인)는 그대로 유효하고, 반대 신호가 하나 추가됐다.

## 6. 종합

| 쌍둥이 요소 | 문헌 근거 | 실제 CCPP 신호 | LLM(`gpt-oss-120b`) 답 |
|---|---|---|---|
| 가스터빈 민감도 0.64 %/°C | 범위 안 (0.5–0.9) | 순출력 0.45 %/°C | 0.5 %/°C, 범위 안 |
| 저온 상한 | 있음 (발전기 보호) | 기압 계수 부호 반전, 기울기 완만 | 상한 세계에서 정확 |
| 증발냉각 24°C | 메커니즘 있음, 시작 온도 근거 없음 | 고온 평탄화는 있으나 습도 신호 반대 | 시작 온도 24°C(`L2`에서 주어짐), `L1` 20°C |
| 결빙 방지 (없음) | 있음 (−15 ~ 8°C, 습도 높을 때) | 작동 조건이 데이터에 있음 | “작동” 60–90% |
| 배기·증기 측 한계 (없음) | 이번에 확인 안 함 | — | “작동” 30–90% |

## 7. 연구에 주는 함의

1. **쌍둥이 정답으로만 채점하면 대형 LLM의 현실적인 도메인 지식이 오류로 처리된다.** 채점을 둘로 나눈다.
   - (a) 쌍둥이 정답 채점: 지금과 같다. 쌍둥이 세계에 대한 진술 신뢰도를 잰다.
   - (b) 문헌 범위 채점: 메커니즘 존재와 수치가 현실적인지를 따로 잰다.
2. **쌍둥이에 결빙 방지 모듈을 추가할 근거가 있다.** 그러면 방해 항목이 아니라 정답 메커니즘이 하나 더 생긴다. 저온 쪽 경계가 두 원인(상한, 결빙 방지)으로 겹치는 어려운 세계를 만들 수 있다.
3. **실제 CCPP에서 레짐 경계의 단서가 데이터에서 나온다.**
   - 저온: 기압 계수 부호 반전. 창 밖 레짐을 “다른 입력 변수의 반응 변화”로 검사하는 신호가 될 수 있다.
   - 이것은 지금 쓰는 창 검사(외기온도 기울기만 봄)보다 넓다. 단서 수준이므로 검증이 필요하다.
4. 문헌 점검이 논문의 도메인 분석 절이 된다. 남은 일:
   - OEM 성능 곡선(GT13E2) 확보
   - Tüfekci 원문 확인
   - 증발냉각 시작 온도의 근거 확보
   - 배기·증기 측 한계 문헌 확인
