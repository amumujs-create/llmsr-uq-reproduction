# 사전 등록(초안): 쌍둥이 변화점 확증 — 꺾임이 창 안이면 데이터로 충분하고, 창 밖이면 데이터는 침묵한다

작성: 2026-11-11 (계산 전, 코드 작성 전). **지위: 초안 — 연구자 확정 전.** 확정되면 이 줄을 "확정"으로 바꿔 커밋한 뒤 코드를 쓰고 한 번만 계산한다.  
관련: [탐색 기록](ccpp-twin-explore-info-interval.md)(이 등록의 출처), [정보 축 등록·결과](ccpp-twin-information-axis.md), [기여 계획](paper-contribution-plan.md).

새 LLM 수집 없음. 판정 K1–K7은 모두 LLM과 무관하다.

## 1. 질문과 이 등록의 성격

[탐색](ccpp-twin-explore-info-interval.md)에서 다음이 보였다(탐색 수치, 판정 아님).
- 추운 쪽 출력 상한 세계에서 꺾임이 창 안·가장자리이면 변화점 통계량이 켜지고, 데이터만 쓴 변화점 외삽이 선형(`R0`)과 위치 정답 조립(`ORACLE`)을 이긴다.
- 꺾임이 창 밖이면 통계량은 켜지지 않고 규칙은 `R0`와 같다. 이때는 위치 지식만 도움이 된다.
- 증발 냉각 세계에서는 꼴이 조각 선형이 아니라 같은 규칙이 해롭다.

이 등록은 **그 관찰을 새 seed와 한 번도 계산하지 않은 세계 변형에서 재현하는 확증**이다. 규칙·문턱은 탐색에서 골랐으므로 독립 발견이 아니며, 원고에는 "탐색에서 고른 규칙을 새 seed에서 확증"이라고 적는다. 주장은 방법의 승리가 아니라 **경계**(데이터로 충분한 곳 / 외부 지식이 필요한 곳 / 규칙이 틀리는 곳)다.

## 2. 세계

| 세계 | 변형 | 꺾임 k | 방향 | δ 격자 | 역할 |
|---|---|---|---|---|---|
| `cap_strong` | `soft2.0`(기본, `cap_softness_mw` = 2.0) | 9.0°C | 추운 쪽 | −2, 0, +2, +4 | 주 판정 |
| `cap_strong` | `soft0.5` | 9.0°C | 추운 쪽 | 같음 | 주 판정 |
| `cap_strong` | **`soft1.0`** | 9.0°C | 추운 쪽 | 같음 | **탐색에서 계산한 적 없는 변형.** 주 판정 |
| `base` | — | 가짜 k = 9 | 추운 쪽 | −2, 0, +2, +4 | 꺾임 없는 대조군 |
| `evap` | `ramp3.0`(기본), `ramp0.5` | 24.0°C | 더운 쪽 | −4, −2, 0, +2 | 범위 한계(K7) |

V는 실제값. σ ∈ {0.5, 1.0, 2.15, 4.3} MW. n ∈ {150, 500, 2000}(풀 < n이면 칸 없음). w ∈ {5, 10}°C. **반복 20.** 창·시험 구간·δ 부호는 [정보 축 등록 §3](ccpp-twin-information-axis.md) 그대로(`info_axis.window_bounds`, `test_mask`, 시험 행 < 30이면 칸 없음, 시험 오차는 clean 기준).

**seed.** 잡음 `confirm1|noise|{module}|{variant}|{sigma}|{rep}`, 표본 `confirm1|sample|{module}|{k}|{delta}|{w}|{n}|{rep}`(`grid._seed`). 탐색(`explore|…`)·등록(`noise|…`, `sample|info|…`) seed와 겹치지 않는다.

## 3. 규칙 (고정)

| 이름 | 정의 |
|---|---|
| `R0` | 창 OLS(AT, V, AP, RH) 외삽 |
| **`CP`** | 창 안에서 AT 연속 두 기울기 변화점 + V·AP·RH 선형을 적합. 매듭 후보는 창 안 AT 값, 양쪽 조각 최소 **max(20, ⌊n/10⌋)** 점, 후보가 400개를 넘으면 균등 간격 400개. `I = BIC(선형, 모수 5) − BIC(변화점, 모수 7)`. **I > 10이면** 변화점 적합의 외삽 쪽 기울기로 외삽(`info_axis.predict_cp`), 아니면 `R0`. 탐색의 `R_cp_seg`, 문턱 10과 같다 |
| `ORACLE` | 정답 진술(`TRUTH`)을 `HA` 기계로(관문 `GUARD_MARGIN` 2.0 + blend 0.5). `base`에서는 빈 진술 = `R0` |
| `D_real` | 고정값 "8°C 아래 + 27°C 위" (대조군 규약 그대로) |

지표: 칸 행마다 상대 RMSE = 규칙 / `R0`. **발화** = I > 10. **해** = 상대 RMSE > 1.10. 평균과 중앙값 모두 보고.

**보고용(판정 아님).** 최소 조각 5점 변형(`CP_5`), 문턱 0 변형, 매듭 추정 오차, `ORACLE` 거부율, 개발 칸 `gpt-oss-120b|L1`(`cap_strong`에서 진술이 있는 유일한 칸; 검증 6칸은 `cap_strong`에서 빈 진술이라 `R0`와 같다).

## 4. 예측과 판정 (모두 1회, LLM 무관)

합치는 축을 적지 않은 곳은 n·w를 합친다. "세 상한 변형 모두"는 `soft2.0`·`soft0.5`·`soft1.0` 각각에서 성립해야 한다는 뜻이다. 괄호는 탐색 수치(문턱에 여유를 둔 근거, `soft1.0`은 탐색 수치 없음).

| | 예측 | 판정 기준 |
|---|---|---|
| K1 창 안이면 켜진다 | 상한 세계 δ = −2, σ ≤ 2.15에서 발화 비율이 높다 | 세 상한 변형 모두 발화 비율 ≥ 0.70 (탐색 0.88, 0.95) |
| K2 창 밖·꺾임 없으면 침묵 | 상한 세계 δ ≥ +2와 `base` 전체에서, σ ≥ 1.0일 때 발화 비율이 낮다 | 세 상한 변형 각각 ≤ 0.05, `base` ≤ 0.05 (탐색 0.00, ≤ 0.01) |
| K3 창 안이면 데이터가 이긴다 | 상한 세계 δ = −2, σ ≤ 2.15: `CP`가 `R0`와 `ORACLE`보다 좋다 | 세 상한 변형 모두 `CP` 평균 < 0.70 **그리고** `CP` 평균 < `ORACLE` 평균 **그리고** `CP` 중앙값 < `ORACLE` 중앙값 (탐색 0.47·0.37 대 0.65·0.67) |
| K4 가장자리 | 상한 세계 δ = 0, σ ≤ 2.15: `CP`가 `R0`보다 좋다 | 세 상한 변형 모두 `CP` 평균 < 0.85 (탐색 0.58, 0.67). `ORACLE`과의 비교는 보고만(탐색에서 평균은 엇갈림) |
| K5 해 없음 | `CP`의 해 비율이 낮다 | 세 상한 변형 각각(모든 δ·σ) ≤ 0.05, `base`(모든 δ·σ) ≤ 0.05 (탐색 ≤ 0.01) |
| K6 창 밖이면 위치 지식만 | 상한 세계 δ ≥ +2(모든 σ): `CP`는 `R0`와 같고 `ORACLE`은 이긴다 | 세 상한 변형 모두 \|`CP` 평균 − 1\| ≤ 0.02 **그리고** `ORACLE` 평균 < 0.75 (탐색 1.00, 0.58) |
| K7 범위 한계 | 증발 세계에서는 같은 규칙이 서지 않는다 | `ramp0.5` δ ∈ {−4, −2}(모든 σ) `CP` 해 비율 ≥ 0.30 (탐색 0.48, 0.84) **그리고** `ramp3.0` 전체 `CP` 평균 > 0.85 (탐색 0.91–0.95) |

**종합 판정.** K1·K2·K3·K5·K6이 모두 성립하면 "상한 세계 경계 주장이 확증됐다"고 쓴다. K4는 보조. K7이 성립하면 범위 한계를 확증된 사실로 쓰고, 불성립이면 "증발 세계의 해는 확증되지 않음"으로 쓴다(주장을 넓히지는 않는다).

## 5. 미리 적는 해석

- **K3 불성립, K1 성립**: 통계량은 켜지지만 외삽이 이기지 못한다 → 탐색의 이득은 seed 운이었다. 경계 주장에서 "데이터로 충분"을 빼고 "데이터가 꺾임을 감지한다"까지만 쓴다.
- **K1 불성립**: 검정력이 탐색보다 낮다 → 조건(σ, n)별 발화 곡선을 그대로 보고하고, 주장을 성립한 조건으로 좁히지 않는다(사후 선택 금지). 불성립으로 적는다.
- **`soft1.0`만 불성립**: 탐색에서 본 두 변형에 맞춰진 결과일 수 있다 → 주장을 "두 변형에서 재현, 새 변형에서 불성립"으로 적고 일반화하지 않는다.
- **K2 또는 K5 불성립**: 문턱 10이 거짓 발화를 막지 못한다 → 문턱을 사후에 올리지 않는다. `CP`는 "해 없음"을 주장할 수 없다고 적는다.
- **K6에서 `ORACLE` ≥ 0.75**: 위치 지식의 이득이 탐색보다 작다 → 등록 결과(§9.2)의 δ ≥ 0 이득과 비교해 차이를 보고한다.
- **K7 불성립(증발 세계에서 해가 적음)**: 좋은 소식이 아니라 탐색과 불일치다. 증발 세계에 대한 어떤 긍정 주장도 하지 않는다.
- **모두 성립**: 원고 C5를 "δ와 꼴"로 쓴다. 꺾임이 창 안이고 조각 선형이면 변화점 검정이 LLM 없이 충분하다. 창 밖이면 데이터는 침묵하고, LLM이 그 위치를 고정값보다 잘 주지 못한다는 기존 등록 결과와 합쳐 진단 문단을 완성한다.

## 6. 한계 (미리 적음)

- 규칙(최소 조각, 문턱 10)과 σ·n 범위는 탐색에서 골랐다. 이 등록은 재현 확증이지 독립 검정이 아니다. 새로운 것은 seed와 `soft1.0` 변형뿐이다.
- 쌍둥이에서만 한다. 실자료(CCPP 실측, BDG2)는 이 등록 밖이다. BDG2 `R_cp`는 평균이 크게 해로웠고(§10) 여기서 그 결과를 뒤집지 않는다.
- 추운 쪽 꺾임은 자료 하한(1.8°C) 때문에 δ < −2를 만들 수 없다. "창 안"은 δ = −2 하나다.
- σ = 0.5에서 쌍둥이 기본 곡선의 약한 휘어짐이 `base` 발화를 만든다(탐색 0.15–0.17). 그래서 K2는 σ ≥ 1.0으로 한정했고, σ = 0.5의 `base` 발화 비율은 그대로 보고한다. K5(해)는 σ = 0.5를 포함한다.
- `CP`에는 LLM이 없다. 이 등록이 성립해도 "LLM 조립이 이긴다"는 결과는 생기지 않는다.
