# 사전 등록: 창 밖 구간 전용 — 데이터가 모르는 곳에서 LLM 진술이 이기는가

작성: 2026-11-11 (계산 전, 코드 작성 전). 연구자 지시("내가 말한 것에 맞게 계획 세우고 다시 해 봐")로 확정.  
관련: [검토](reviews/2026-11-11-data-silent-regime.md), [정보 축 등록·§9.7 사후 집계](ccpp-twin-information-axis.md), [세계를 모르는 대조군](ccpp-world-blind-controls.md).

새 LLM 수집 없음. 기존 S0·S2 답과 같은 `HA` 규칙(`assemble` + 관문 `GUARD_MARGIN` 2.0 + blend 0.5). 이 문서를 커밋한 뒤 코드를 쓰고 한 번만 계산한다.

## 1. 목표 (연구자 정의)

**데이터에 정보가 없을 때 LLM의 도움으로 이긴다. 데이터 안에 정보가 있을 때는 이길 필요가 없다.**

그래서 이 등록은 **꺾임이 창 밖(δ > 0)인 경우만** 본다. 변화점 통계량·전환 규칙·구간은 다루지 않는다.

## 2. 미리 밝히는 것 (이미 본 것)

- [§9.7 사후 집계](ccpp-twin-information-axis.md)에서 `evap`·`cap_strong`(추운 쪽)·`base`의 δ ∈ {2, 4, 8} 결과를 이미 봤다. 조립 진술 내용(어느 칸이 무엇을 말했는지)도 안다. 아래 지표(과제별 같은 무게)는 그것을 본 뒤 골랐다.
- 그래서 이 등록은 **새 seed, 새 δ 격자, 새 과제 구성에서의 확증**이다. 아직 계산한 적 없는 것: `evap+cap_mild`·`cap_mild`·`cap_strong`(더운 쪽) 과제, δ = 1, 비교군 `D_aware`·`P_side`, seed 전체.
- 계산 전 내 예상: H0–H4는 성립할 가능성이 높고, **H5는 불확실하며 실패할 수 있다.** 상한 세계에서 검증 모델이 침묵하기 때문이다.

## 3. 과제 (세계 × 외삽 방향)

| 과제 | 종류 | 세계 | 방향 | 창 기준 k | 정답 |
|---|---|---|---|---|---|
| `evap\|hot` | 꺾임 | `evap` | 더운 쪽 | 24.0 | 24°C 위 평평 |
| `evap+cap_mild\|hot` | 꺾임 | `evap+cap_mild` | 더운 쪽 | 24.0 | 24°C 위 평평 |
| `cap_strong\|cold` | 꺾임 | `cap_strong` | 추운 쪽 | 9.0 | 9°C 아래 평평 |
| `base\|hot` | 꺾임 없음 | `base` | 더운 쪽 | 24.0(가짜) | 없음 |
| `base\|cold` | 꺾임 없음 | `base` | 추운 쪽 | 9.0(가짜) | 없음 |
| `cap_strong\|hot` | 꺾임 없음 | `cap_strong` | 더운 쪽 | 24.0(가짜) | 그쪽에는 없음 |
| `cap_mild\|hot` | 꺾임 없음 | `cap_mild` | 더운 쪽 | 24.0(가짜) | 그쪽에는 없음 |

- 제외: 6°C 꺾임의 추운 쪽(`cap_mild`, `evap+cap_mild`)은 시험 행 15개. `evap`의 추운 쪽은 넓은 창이 24°C 램프에 닿아 창 안이 비선형이 된다.
- **δ ∈ {1, 2, 4}°C** (모두 창 밖). 창·시험 구간은 [정보 축 등록 §3](ccpp-twin-information-axis.md)의 정의 그대로(`info_axis.window_bounds`, `test_mask`; 시험은 k에서 2.5°C 떨어진 폭 2.5°C 띠, clean 기준).
- w ∈ {5, 10}, n ∈ {50, 150, 500}, σ ∈ {2.15, 4.3, 8.6}, V 실제값, **반복 20.** 과제당 1,080행, 합계 7,560행.
- seed: 잡음 `outside1|noise|{세계}|{σ}|{rep}`, 표본 `outside1|sample|{과제}|{δ}|{w}|{n}|{rep}`(`grid._seed`). 이전 실행과 겹치지 않는다.

## 4. 규칙

| 이름 | 정의 | LLM |
|---|---|---|
| `R0` | 창 OLS(AT, V, AP, RH) 외삽. 데이터만 | 무관 |
| `HA` | 칸(모델 × 수준)별 조립 진술 + 관문 + blend 0.5 (기존 그대로, `controls.build_external`) | 사용 |
| `ORACLE` | 세계의 정답 진술(`TRUTH`)을 같은 기계로 | 무관 |
| `D_real` | **세계를 모르는 고정값**: 모든 세계에 "8°C 아래 + 27°C 위" | 무관 |
| `D_aware` | **설명을 읽는 고정 규칙**: 세계에 증발 냉각기가 있으면 "27°C 위", 출력 상한이 있으면 "8°C 아래", 둘 다면 둘 다, 없으면 빈 진술. 숫자는 `D_real`과 같다. L1 설명만 읽으면 사람이 적용할 수 있는 규칙 | 무관 |
| `P_side` | 가짜 경계 중 **외삽 쪽**만: 더운 쪽 "18…36°C 위" 10개, 추운 쪽 "4…16°C 아래" 7개. 각각 같은 기계로 계산한 뒤 상대 RMSE 평균 | 무관 |

모든 비교군은 `HA`와 같은 관문·blend를 거친다(`info_axis.predict_statement`).

## 5. 지표

- 행마다 **상대 RMSE = 규칙 / `R0`**. 해 = 상대 RMSE > 1.10.
- **과제 평균** = 그 과제의 모든 행(δ·w·n·σ·rep) 평균. **꺾임 평균** = 꺾임 과제 3개의 과제 평균을 같은 무게로 평균. **전체 평균** = 과제 7개를 같은 무게로 평균. **꺾임 없음 해 비율** = 꺾임 없는 과제 4개 행의 해 비율.
- 이유: 현장에서는 어느 세계인지 모르고 고정값은 장치가 없는 발전소에도 적용되므로 과제마다 같은 무게를 준다. 절대 MW 합산(이전 K1)은 오차가 큰 한 세계가 지배한다. 절대 MW 표도 보고한다.
- 판정 칸: 검증 6칸(gemma3-27b, llama33-70b, gpt-oss-20b × L1·L2). 개발 칸(gpt-oss-120b, qwen3-30b)은 보고만.

## 6. 예측과 판정

| | 예측 | 기준 |
|---|---|---|
| H0 전제 (LLM 무관, 1회) | 위치를 알면 창 밖에서 이기고, 세계를 모르는 고정값은 꺾임 없는 곳에서 해롭다 | `ORACLE` 꺾임 평균 < 0.75 **그리고** `D_real` 꺾임 없음 해 비율 ≥ 0.30 |
| H1 해 없음 | `HA`는 어느 과제에서도 해가 드물다 | 전체 행 해 비율 ≤ 0.10인 칸 ≥ 5/6 |
| H2 데이터만 쓴 것보다 낫다 | 꺾임 과제에서 `HA`가 `R0`를 이긴다 | `HA` 꺾임 평균 ≤ 0.95인 칸 ≥ 4/6 |
| H3 세계를 모르는 고정값보다 낫다 | 전체에서 `HA`가 `D_real`을 이긴다 | `HA` 전체 평균 < `D_real` 전체 평균인 칸 ≥ 4/6 |
| H4 무작위 위치보다 낫다 | 꺾임 과제에서 `HA`가 `P_side`를 이긴다 | `HA` 꺾임 평균 < `P_side` 꺾임 평균인 칸 ≥ 4/6 |
| H5 설명을 읽는 고정 규칙보다 낫다 | 꺾임 과제에서 `HA`가 `D_aware`를 이긴다 | `HA` 꺾임 평균 < `D_aware` 꺾임 평균인 칸 ≥ 4/6 |

**종합.** H0·H1·H2·H3·H4가 모두 성립하면 "목표 주장 성립(1단계)": 데이터가 모르는 곳에서 LLM 진술은 해 없이 데이터와 세계를 모르는 기본값·무작위 위치를 이긴다. H5까지 성립하면 "강한 주장 성립": 설명을 읽는 사람 규칙도 이긴다.

**함께 보고(판정 아님).** 과제별·δ별 표(평균·중앙값·해), 메운 비율 (1 − `HA`)/(1 − `ORACLE`), 절대 MW, 개발 칸, 칸별 조립 진술, 관문 거부율.

## 7. 미리 적는 해석

- **H0 불성립**: 전제가 틀렸다(위치를 알아도 못 이기거나 고정값이 해롭지 않다). 나머지 판정은 보고만 하고 목표 주장을 세우지 않는다.
- **H2 불성립, H1 성립**: LLM은 안전하지만 이기지 못한다 — 침묵이 원인이면 칸별 진술 표로 보인다. 목표 주장 불성립. 지금 가진 진술로는 "해 없음"까지만 쓴다.
- **H3만 성립하고 H2 불성립**: 침묵이 해로운 고정값을 이긴 것이다. 긍정 결과로 쓰지 않는다.
- **H2·H3·H4 성립, H5 불성립**: "LLM의 값은 설명에서 장치 유무를 읽는 것이고, 그 일은 사람 규칙도 한다. 위치는 문헌 기본값이 더 낫다." 1단계 주장만 쓴다. 다음은 **기본값이 정해지지 않는 새 세계**에서의 수집(연구자 서버 필요)이다.
- **H5 성립**: 강한 주장. 다만 꺾임 과제가 셋(둘은 같은 증발 꺾임)이라 일반화는 새 세계 뒤에만 한다.
- 어떤 경우에도 지표·기준·과제 목록을 계산 뒤에 바꾸지 않는다. 다른 집계는 "사후"로 표시한다.

## 8. 한계 (미리 적음)

- 지표와 과제 구성은 §9.7 사후 집계를 본 뒤 골랐다(§2). 독립 발견이 아니라 새 seed·새 구성에서의 확증이다.
- 꺾임 과제 3개 중 2개가 같은 24°C 증발 꺾임이다. 서로 독립이 아니다.
- L2 설명에는 증발 냉각기 가동 기준 "약 24°C"가 들어 있다. L2 칸의 증발 위치는 추론이 아니라 읽기다. L1 칸과 나눠 보고한다.
- `D_aware`의 숫자(8°C, 27°C)는 실제 발전소 회귀에서 온 값이고 쌍둥이 정답(9°C, 24°C)과 다르다. 다른 기본값을 쓰면 결과가 달라질 수 있다. 기본값을 사후에 바꾸지 않는다.
- 쌍둥이 한정. 실자료는 이 등록 밖이다.

### 10.4 해석 (§7에 미리 적은 대로)

- **전제는 선다(H0).** 창 밖에서 위치를 알면 오차가 선형의 0.62배가 된다. 세계를 모르는 고정값은 꺾임 없는 과제 행의 절반에서 해롭다.
- **LLM 진술은 해가 없고(H1), 세계를 모르는 고정값보다 낫고(H3), 6칸 중 4칸이 선형을 이긴다(H2).**
- **H4·H5는 침묵 때문에 불성립.** 이긴 3칸(gemma L1, llama L1·L2)은 증발 과제에서 `ORACLE` 수준(0.64–0.67)이고 `D_aware`(0.87)를 크게 이긴다. 그러나 검증 6칸 모두 상한 과제에서 빈 답이라 꺾임 평균이 0.76–0.78에 머물고, `D_aware`(0.816)와의 차이가 작다. 나머지 3칸은 증발 과제에서도 침묵하거나 먼 위치(32°C)를 말했다.
- **미리 적은 경우에 해당: "H2·H3 성립, H4/H5 불성립".** LLM의 값은 설명에서 장치 유무를 읽고 틀릴 때 침묵하는 것이다. 말할 때는 위치가 문헌 기본값보다 좋다(증발: 24–25°C 대 27°C). 말하지 않는 것이 병목이다(상한: 6/6칸 침묵).
- 사후 관찰(판정 아님): 꺾임 과제에서는 외삽 쪽 아무 위치(`P_side` 0.82)도 `D_aware`(0.82)만큼 이득이다. 즉 꺾임이 있는 쪽을 알기만 하면 위치는 덜 중요하고, **"그쪽에 꺾임이 있는가"가 핵심 정보**다. 꺾임 없는 과제에서 `P_side`는 2.5–4.0으로 크게 해롭다.

- 쓸 수 있다: "데이터가 모르는 구간에서 LLM 진술 조립은 해가 없고(6/6), 세계를 모르는 기본값보다 낫다(6/6). 말한 칸은 증발 과제에서 정답 수준이다."

**결론: 모델이 침묵한 것이 아니다. 우리 조립 규칙이 답을 버렸다.**

1. **모든 모델이 "상한에 도달한다"고 답했다.** S2 답에서 "가스터빈 출력 제한이 운전 범위에서 도달된다"고 한 비율은 상한이 있는 세계(`cap_mild`, `cap_strong`, `evap+cap_mild`)에서 0.90–1.00, 없는 세계(`base`, `evap`)에서 0.00이다(열 칸 모두). 장치 유무와 방향은 완벽하게 가린다.
2. **위치를 간접 계산하다가 버려진다.** `HA`는 상한 위치를 모델이 준 세 숫자로 계산한다: 위치 = 15 − (상한 − 15°C 출력) / |기온 민감도|. 그리고 민감도가 문헌 범위(0.4–1.2 %/°C)를 벗어나거나 계산된 위치가 2–37°C를 벗어나면 그 답을 버리고, 남은 답이 과반이 아니면 경계를 내지 않는다.
3. **검증 모델은 민감도를 3–4배 작게 말한다.** 쌍둥이의 값은 약 −2.2 MW/°C(약 0.64 %/°C)다.

4. **읽는 법.**
   - 관문은 제 일을 했다(틀린 숫자에서 나온 위치를 막음). 그러나 위치와 함께 **"그쪽에 상한이 있다"는 맞는 사실까지 버렸다.** §10.4의 사후 관찰(꺾임이 있는 쪽만 알아도 위치와 거의 무관하게 이득)과 합치면, 버린 것이 바로 가장 값진 정보였다.
   - 직접 물은 답(S0)은 대안이 못 된다. gemma·qwen·llama L1은 상한 세계에서 반대쪽(더운 쪽)을 말한다. gpt-oss-20b만 직접 답이 정답 근처다.
   - 그래서 상한 위치만 놓고 보면 LLM은 문헌 기본값(8°C)보다 낫지 않다(가장 좋은 칸이 6.7–8.0°C). 증발 위치는 LLM이 낫다(24–25°C 대 27°C).

5. **여기서 나오는 규칙 후보(사후 설계, 미등록).** "장치가 있다고 과반이 답했는데 위치가 관문을 못 넘으면, 경계를 버리지 말고 기본 위치로 둔다." 이 규칙은 이 답들을 보고 만든 것이므로 **같은 답으로 판정하면 안 된다.** 등록한다면 새 seed만으로는 부족하고(진술이 같다), 새 모델 또는 새 세계의 수집이 있어야 독립 검정이 된다. 그리고 이 규칙에서 LLM이 `D_aware`를 넘는 부분은 증발 위치(24–25 대 27°C)뿐이라는 점을 미리 적어 둔다.
