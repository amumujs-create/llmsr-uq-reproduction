# 전체 경과 정리 (2026-11-03 ~ 2026-11-12)

상태: 정리 문서. 새 계산 없음. 수치는 [결정 기록](decision-log.md)과 각 실험 문서에서 옮겼다. 사전 등록 판정과 탐색(사후)을 구분해 적었다.

## 1. 한 줄 결론

"학습 데이터가 모르는 구간을 LLM 진술로 고친다"는 긍정 주장은 사전 등록 실험에서 반복해서 성립하지 않았다. 성립한 것은 "엄격한 조립 규칙은 해가 없다"와 여러 진단 결과다. 안전과 이득은 맞바꿈 관계이고, 그 비율은 LLM이 꺾임 유무를 가려내는 정확도에 묶여 있다.

## 5. 반복해서 확인된 사실

1. **창 안 데이터만으로는 창 밖 꺾임을 알 수 없다.** 창 안 지표(AUROC 0.63–0.64), 양방향 일치 필터, BIC 변화점, 꺾이는 회귀, 2차식 모두 실패했다. 표본 500개에서도 같다.
2. **꺾임이 있다는 사실만 알아도 이득은 크다.** 위치가 3–5°C 틀려도, 위치 없이 "창 끝부터 평평"만 써도 상대 오차 0.6 안팎이다. 모양 정보의 추가 이득은 거의 없다.
3. **거짓 경보의 손해는 크고 검사할 수 없다.** 11-04에 피해율 82%, 11-12에 6–7배로 다시 확인했다. 손해 한도는 MW 단위로만 있다.
4. **LLM은 장치가 있으면 있다고 잘 말한다.** 그러나 없어도 있다고 자주 말한다. 숫자(민감도, 설정 온도)는 약하다. 방향과 모양은 모델별 기본 답에 끌린다.
5. **엄격한 조립은 안전하다.** 검증 6칸, 확인 8칸 중 7칸에서 해 비율 0.10 이하. 대가는 침묵이다.
6. **사람이 정한 기본값이 LLM 위치와 같거나 낫다.** K1 실패, H5 실패, H6 실패가 같은 내용이다.
7. **실제 자료에서도 LLM의 몫은 분리되지 않았다.** CCPP는 24–32°C 어디든 비슷했고, BDG2는 세 모델이 반대쪽을 답했다.

## 6. 성립하지 않은 주장

| 주장 | 근거 |
|---|---|
| LLM 위치가 도메인 기본값보다 낫다 | K1 0/6, H5 3/6 → 0/4 |
| LLM 위치가 무작위 위치보다 낫다(새 모델) | H4 2/8 |
| 설명에 숫자가 있으면 사람 읽기만큼 한다 | H6 0/4 |
| 대체 규칙으로 침묵을 풀면 해 없이 이득 | `HA_fb` H1 0/6 |
| 정보량 통계로 데이터와 LLM을 전환 | 정보 축 T4, T5 실패 |
| 두 번째 시스템에서 재현 | BDG2 B3–B7 실패 |
| 꺾임 유무 판단만 쓰면 낫다 | 탐색. 해 비율 0.18–0.37 |

## 7. 남은 일이 의미가 있는가

**조립 규칙을 더 다듬는 일은 의미가 작다.** 열흘 동안 규칙을 여섯 번 바꿨고(`HA` v1, v2, `XM`, `HA_shape`, `HA_fb`, `HA_fb_gt`) 결과는 같은 선 위를 움직였다. 엄격하면 침묵하고, 풀면 해가 난다. 오늘 탐색은 그 이유를 수치로 보였다. LLM의 판단 정확도가 그대로면 규칙으로는 이 선을 벗어나지 못한다.

**의미가 남아 있는 일은 세 가지다.**

| 일 | 왜 의미가 있나 | 비용 |
|---|---|---|
| 새 발전소 답(아직 안 연 것)으로 진단 주장을 확인 | 깨끗한 확인 자료가 이것 하나 남았다. "잘못된 긍정 비율", "손해 한도", "꺾이는 모형은 못 고친다"를 등록 후 한 번에 확인할 수 있다 | 등록 문서와 채점 코드. 새 수집 없음 |
| LLM에 주는 정보를 바꾸는 실험 | 판단 정확도를 움직일 수 있는 유일한 손잡이다. L2에서 잘못된 긍정이 0.30 → 0.19로 줄었다 | 새 수집 필요 |
| 쌍둥이 `base` 세계가 현실적인지 확인 | 실제 CCPP는 고온에서 기울기가 준다. 꺾임 없는 고온 과제가 LLM에 불리한 반사실일 수 있다 | 실제 자료 재분석. 사전 등록 필요 |

## 8. 논문 선택지

| 선택지 | 주장 | 가진 근거 | 상위 저널 가능성 |
|---|---|---|---|
| A. 방법 논문 | LLM 진술로 외삽을 개선 | 없음. 등록 실험에서 반복 실패 | 낮음 |
| B. 진단 논문 | 창 밖 꺾임에서 바깥 지식의 값은 유무 판단 하나이고, 현재 LLM은 그 판단에서 잘못된 긍정이 많다. 안전과 이득의 맞바꿈과 손해 한도를 제시 | 사전 등록 16건, 모델 9개, 쌍둥이와 실제 자료 2종 | 중간. 엄격한 부정 결과와 분석 틀로 승부 |
| C. 문제를 바꿈 | 진술 대신 문서에서 숫자를 뽑는 과제 등 | 없음. 새로 시작 | 미지수 |

현재 자료로 쓸 수 있는 것은 B다. B를 강하게 하려면 §7의 첫 번째 일(깨끗한 확인)이 필요하다.

## 11. 덧붙임 (같은 날, 등록 준비 뒤)

이 문서를 쓴 뒤 [깨끗한 창 진단 확인](ccpp-twin-clean-diagnostic.md)을 등록하면서 기존 다섯 모델의 새 발전소 답을 처음 열었다. §9의 "기존 다섯 모델 답은 아직 읽지 않았다"는 더 이상 맞지 않는다.

개발 결과는 §7의 비관적 판단과 일부 다르다. 위치 없이 두 질문의 유무 판단이 일치할 때만 쓰는 규칙이 다섯 모델 중 셋에서 해 없이 큰 이득을 냈다. 다만 그 묶음에는 장치가 전혀 없는 발전소가 없다. 확인은 새 네 모델로 한 번 한다. §8의 선택지 A(방법 논문)가 살아날지는 그 결과에 달렸다.
