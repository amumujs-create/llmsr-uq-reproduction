# 탐색: 구조는 LLM, 숫자는 보조 모형 (2026-11-12)

**상태: 사후 탐색.** 이미 본 개발용 답(기존 다섯 모델)을 썼다. 판정이 아니며 어떤 등록 판정에도 쓰지 않는다. 진행 중인 확증([등록](ccpp-twin-outside-confirmation.md))의 규칙, 지표, 문턱은 그대로다. 씨앗은 `explore_sim1`로 `outside3`와 겹치지 않는다.

배경 검토: [reviews/2026-11-12-llm-simulator-assist.md](reviews/2026-11-12-llm-simulator-assist.md)

## 1. 질문

LLM은 출력 제한이 걸린다는 구조는 맞히고 민감도 숫자는 틀린다(§11, ccpp-twin-outside-regime.md). 숫자를 LLM 밖에서 가져오면 침묵이 풀리고 고정 기본값(8°C)을 이기는가.

## 2. 방법

코드 `analysis/ccpp_twin/explore/sim_assist.py`, 출력 `analysis/ccpp_twin/runs/explore_sim_assist/summary.txt`.

S2 답 과반이 출력 제한에 걸린다고 한 칸에서:

- 여유 h = 답들의 100 × (제한 MW / 15°C 출력 − 1)의 중앙값. L2는 설명의 343 MW를 쓴다.
- `SIM@c`: 꺾임 위치 = 15 − h / c. c는 보조 모형의 가스터빈 민감도(%/°C). 쌍둥이의 실제 값은 약 0.64. c를 0.40~1.00으로 흔들어 불일치를 본다.
- `DATA_t`, `DATA_p`: c를 학습 구간에서 추정. 각각 단순 기울기, 다변수 회귀의 온도 계수를 평균 출력으로 나눈 값.
- 위치가 2~37°C 밖이면 8°C로 대체(`HA_fb_gt`와 같음). LLM의 민감도 답은 쓰지 않는다.

과제는 등록 실험의 일곱 개. `cap_mild|cold`(실제 6°C)는 3.5°C 아래 시험 자료가 15건뿐이라 뺐다. 그래서 출력 제한 꺾임 과제는 `cap_strong|cold`(실제 9°C) 하나다.

## 4. 읽는 법과 함정

1. **보조 모형이 정확하면 정답 위치 수준에 온다.** c = 0.64에서 L2 칸 0.642, ORACLE 0.603, 고정 기본값 0.709. 침묵하던 칸은 1.000에서 내려온다.
2. **고정 기본값 대비 이득은 작다.** 0.709에서 0.642. 기본값 8°C가 정답 9°C와 가깝기 때문이다.
3. **민감도를 22% 낮게 잡으면 기본값보다 나빠진다.** c = 0.50에서 0.843.
4. **c가 클수록 좋아 보이는 것은 혼합 0.5의 부작용이다. 근거로 쓰지 않는다.** `SIM@1.00`은 0.464로 ORACLE보다 낮게 나왔다. 확인 결과(σ 4.3, 폭 5, n 150, 20회): 혼합 0.5에서는 위치를 10~12°C로 틀리게 줄수록 좋아지고, 혼합 1.0에서는 정답 9°C가 최선이다(δ = 2에서 8°C 0.44, 9°C 0.31, 10°C 0.36, 11°C 0.55). 절반만 반영하니 위치를 과하게 잡는 쪽이 보상된 것이다.
5. **학습 구간 단순 기울기가 보조 모형 없이 같은 일을 한다.** `DATA_t` 0.628. 다변수 계수(`DATA_p`)는 0.728로 기본값보다 못하다. 어느 쪽을 쓸지 사전에 정할 근거가 아직 없다.
6. **L1의 좋은 수치는 우연이다.** L1 설명에는 제한 값이 없다. 모델이 지어낸 여유(3.6~4.2%)가 `cap_strong`의 4.08%와 가까웠을 뿐이다. `cap_mild`(6.12%)였다면 위치가 8.5~9.4°C로 나와 정답 6°C에서 멀다. qwen L1은 6.67%를 말해 0.997이 됐다.
7. **과제 하나, 이미 본 답이다.** 일반화 근거가 아니다.

## 5. 잠정 결론

- 구조와 숫자를 나누는 생각은 작동한다. 침묵이 풀리고 해는 늘지 않는다.
- 지금 과제로는 고정 기본값과의 차이를 보일 수 없다. 기본값이 정답과 1°C 차이이기 때문이다.
- 차이를 보이려면 제한 값이 다른 세계가 여러 개 필요하다. 예: 제한 350, 353, 357 MW이면 꺾임이 약 12, 10.5, 8.6°C로 달라지고, 고정 8°C는 앞의 둘에서 크게 틀린다. 12°C 근처는 시험 자료도 충분하다.
- 제한 값이 설명에 있어야 한다(L2). 없으면 이 방법은 쓸 수 없다.
- 혼합 0.5가 위치 평가를 왜곡한다는 점은 따로 다뤄야 한다. 등록된 규칙은 바꾸지 않는다.
