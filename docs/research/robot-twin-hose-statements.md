# 툴 호스 쌍둥이: 가상 진술 × 위험 제한 규칙 (탐색, 2026-11-12)

**상태: 탐색이다. 사전 등록이 아니다.** 실제 LLM 답은 쓰지 않았다. 진술은 정답을 변형해 만든 가상 진술이다. CCPP처럼 이 실험의 사전 등록판은 LLM 수집 전에 따로 커밋해야 한다. 여기서 정한 문턱값(관문 χ² 4, 넘침 2°, 잡음 0.2/1.0 Nm)은 임의값이다.

코드 `analysis/robot_twin/hose_statements.py`, 출력 `runs/hose_statements.txt` / `.json` (20회 반복, 4초). 배경: [호스 설계 §7–8](robot-twin-hose-design.md), [CCPP 위험 제한](ccpp-risk-limit.md)

## 결론
1. **압력 질문(과제 B)에서 진술은 대부분 검사할 수 없다.** 작은 각도에서 압력을 건 데이터로 관문을 돌렸다.
   - 잡음 0.2 Nm: 맞는 진술 통과율 32%
   - 잡음 1 Nm: 맞는 진술 통과율 6%

   압력 효과가 꺾임 근처에서만 드러나기 때문이다. 그래서 이 과제는 "검사할 수 없는 진술의 위험"을 시험하기에 맞다.
2. **로봇에서는 손해가 한쪽으로만 크다. 이 비대칭을 쓰는 규칙(`safe`, 한계를 좁히는 진술만 받음)이 가장 좋았다.**
   - 손익분기 신뢰도 p\*: `safe` 0.25. 전부 믿기(`R2`), `blend`, `budget`은 모두 0.6이다.
   - 맞는 진술에서 한계를 넘는 비율(넘침)이 0이다.
   - CCPP에는 없는 로봇 고유의 위험 제한이다.
3. **도메인 기본값이 손해를 낸다.** "압력을 걸면 호스가 줄어든다"(−4%)를 늘 믿는 진술(`default_shrink`)의 결과다.
   - `R2`의 평균 오차가 12.4°다. 기본 예측 `R0`(압력 무시)의 8.1°보다 나쁘다.
   - 넘침은 0이다. 손해는 작업 공간을 잃는 쪽으로만 난다.
4. **잡음이 작으면 진술 없이 데이터만으로도 된다.** 압력 창에서 ε를 고르는 `est`의 결과다.

   | 잡음 | `est` 평균 오차 | `R0` 평균 오차 |
   |---|---|---|
   | 0.2 Nm | 5.0° | 8.1° |
   | 1 Nm | 12.6° | 8.1° |

   잡음 1 Nm에서는 `est`가 `R0`보다 나쁘다. 그래서 LLM 진술이 가치 있는 영역은 다음 두 경우다.
   - 잡음이 큰 경우
   - 압력 데이터가 없는 경우
5. **각도 질문(과제 A)은 위치 진술이 거의 전부다.** 데이터만으로 하는 추세 외삽(`trend`)은 평균 오차가 103–127°다. "시험한 범위에 머무르기"(`R0`)는 14.7°이고 넘침이 0이다. 한계를 늦게 말하는 진술(`late_10`, `late_20`)은 창으로 검사할 수 없다. 그래서 `R2`와 관문이 모두 100% 넘친다.

## 1. 과제

| | 과제 B (주 과제, 조건 외삽) | 과제 A (각도 외삽) |
|---|---|---|
| 보는 데이터 | 압력 0의 전 구간(k0와 호스 길이를 앎) + 압력을 건 작은 각도 창 [5°, k0/2] | 압력 0의 느슨한 창 [k−d−w, k−d], d ∈ {10, 20}, w ∈ {20, 40} |
| 맞힐 것 | 압력을 걸었을 때의 k1 | k |
| 진술 | 압력에 따른 길이 변화 ε_s | 팽팽해지는 각 k_s |
| 정답 세계 | ε ∈ {−4, −2, 0, +2}% × 자세 3 × 여유 4 | 자세 3 × 여유 4 |
| `R0` | k0 (압력 무시) | 창 끝 (시험한 범위에 머무르기) |
| 검사 가능한 부분(관문) | 압력 창의 SSE가 ε = 0보다 4σ² 넘게 줄어야 통과 | k_s가 창 밖이어야 통과 |
| 진술 종류 | `correct`, `miss`(0), `half`, `double`, `sign_flip`, `default_shrink`(−4%), `false_shrink` | `correct`, `early/late_10`, `early/late_20`, `inside_window` |

규칙은 D = k_진술 − k_R0에 적용한다. 규칙 종류: `R0`, `R2`(D 전부), `blend_0.5`, `budget_5/10`(|D| ≤ 5/10°), `safe`(D < 0일 때만), `gate`(관문 통과 시 D 전부). 데이터만 쓰는 비교 규칙은 B의 `est`(압력 창으로 ε 선택), A의 `trend`(힘 추세 2차식의 0점)다.

**K1 주의:** 예측기는 기구학과 고정점을 알고, B에서는 호스 길이도 안다. 그래서 B에서 ε_s가 맞으면 답이 기하로 정확히 나온다. 모르는 것은 ε뿐이다. 이것은 의도한 설계다. LLM이 맞혀야 하는 것은 "호스가 압력에 어떻게 반응하는가"다.

## 2. 결과 요약 (평균 오차 ° / 넘침 비율)

**과제 B, 잡음 0.2 Nm**

| 진술 | `R0` | `R2` | `blend_0.5` | `budget_10` | `safe` | `gate` | `est` |
|---|---|---|---|---|---|---|---|
| correct | 8.1 / 0.50 | 0.0 / 0 | 4.0 / 0.46 | 2.3 / 0.21 | 1.9 / 0 | 4.3 / 0.23 | 5.0 / 0.25 |
| sign_flip | 8.1 / 0.50 | 18.0 / 0.75 | 13.0 / 0.69 | 15.4 / 0.75 | 10.0 / 0.50 | 8.3 / 0.50 | 5.0 / 0.25 |
| default_shrink | 8.1 / 0.50 | 12.4 / 0 | 8.4 / 0.25 | 9.3 / 0.21 | 12.4 / 0 | 5.3 / 0.29 | 5.0 / 0.25 |
| p\* (틀림 = sign_flip) | — | 0.6 | 0.6 | 0.6 | **0.25** | 0.1 | 0 |

- 잡음 1 Nm에서는 관문 통과율이 0–6%로 떨어져 `gate` ≈ `R0`(p\* 0.05, 맞는 진술에서 7.0°)다. `est`는 12.6°로 `R0`보다 나빠진다.
- `R0`의 넘침 0.50은 ε < 0 세계(정답 한계가 좁아짐)에서 압력을 무시하면 넘친다는 뜻이다.

**과제 A (두 잡음에서 거의 같음)**

| 진술 | `R0` | `R2` | `blend_0.5` | `budget_10` | `gate` | `trend` |
|---|---|---|---|---|---|---|
| correct | 14.7 / 0 | 0.0 / 0 | 7.3 / 0 | 4.7 / 0 | 0.0 / 0 | 103–127 / 0.7–0.8 |
| late_20 | 14.7 / 0 | 20.0 / 1.00 | 2.7 / 0.53 | 4.7 / 0 | 20.0 / 1.00 | |
| early_20 | 14.7 / 0 | 20.0 / 0 | 17.3 / 0 | 20.0 / 0 | 14.7 / 0 | |

- `R0`가 항상 짧게 잡기 때문에 `blend`·`budget`의 p\*가 0이다. 이것은 `R0`를 "시험한 범위에 머무르기"로 정의해서 생긴 결과다. 규칙이 좋아서 생긴 결과가 아니다.
- 과제 A의 관문은 잡음과 무관하다(창 안에 꺾임이 있는지만 본다). 늦게 말하는 진술은 걸러낼 수 없다.

## 4. 한계와 다음
- 진술 오류의 종류와 비율은 가정이다. 실제 LLM이 어떤 오류를 내는지(예: 늘 "줄어든다")가 결과를 정한다. LLM 수집이 필요한 이유다.
- 잡음 크기(두산 외력 추정 잡음)를 모른다. 관문의 쓸모가 이 값에 달려 있다.
- 과제 B의 `R0`는 k0를 정확히 안다고 가정했다. 실제로는 압력 0 데이터에서 k0를 추정할 때도 오차가 생긴다.
- `safe` 규칙의 이득은 "좁히는 쪽 손해가 작다"는 비대칭 비용에서 나온다. 논문에서는 넘침 비용과 작업 공간 손실 비용을 따로 보고해야 한다.
- 다음 단계: 이 설계를 사전 등록판으로 정리한다. 설명 수준(L0–L2)과 질문 문구를 정하고, 서버에서 LLM 진술을 수집한다.

## 5. 추가 실험 (2026-11-12): 과제 B 스윕
연구자 지시("실험 더 돌리기"). 코드 `analysis/robot_twin/hose_statements_sweep.py`, 출력 `runs/hose_statements_sweep.txt`(20회 반복). 탐색이며 사전 등록이 아니다.

### 5.0 요약과 결론
- **검사(관문)는 잡음이 작고 모형이 맞을 때만 쓸모 있다.** 쌍둥이 모형이 실제와 조금만 달라도 관문이 틀린 진술을 통과시킨다. 예: 토크 1.25배, 강성 3배 등. 이때 부호가 틀린 진술의 통과율은 17–62%다.
- **한계를 좁히는 진술만 받는 `safe` 규칙이 가장 튼튼하다.** 한계를 넘는 비용이 클수록 더 그렇다. 기하만 쓰고 강성 모형을 쓰지 않아서 모형 불일치의 영향을 받지 않는다.
- **데이터만으로 하는 추정(`est`)은 조건이 좋을 때만 이긴다.** 잡음이 0.2 Nm 이하이거나, 압력을 걸고 한계 근처(0.75–0.9 k0)까지 시험한 경우다. 모형이 틀리면 15–18°로 망가진다(`R0` 8.1°).

### 5.1 E1 잡음 — 잡음이 커질수록 관문은 `R0`로 수렴한다
| σ (Nm) | 0.05 | 0.1 | 0.2 | 0.5 | 1 | 2 |
|---|---|---|---|---|---|---|
| 맞는 진술 통과율 | 0.65 | 0.52 | 0.32 | 0.14 | 0.06 | 0.02 |
| 부호 틀린 진술 통과율 | 0.05 | 0.04 | 0.03 | 0.01 | 0 | 0 |
| `gate` 오차, 맞는 진술 (°) | 0.8 | 2.1 | 4.2 | 6.1 | 7.0 | 7.6 |
| `est` 오차 (°) | 1.3 | 2.7 | 4.8 | 8.8 | 12.8 | 14.6 |

`R0`는 8.1°다. 데이터만 쓰는 추정은 σ ≈ 0.5 Nm부터 `R0`보다 나빠진다.

### 5.2 E2 창 크기 — 한계 근처까지 압력을 걸고 시험하면 검사가 된다
σ = 0.5 Nm에서 창 끝이 0.25 → 0.5 → 0.75 → 0.9 k0로 커질 때 결과는 이렇다.
- 맞는 진술 통과율: 0.03 → 0.12 → 0.34 → 0.60
- `est` 오차: 13.7 → 9.2 → 5.2 → 2.2°

어디까지 시험할지는 안전과 정보의 교환이다.

### 5.3 E3 모형 불일치 — 관문의 약점
| 진실 | 맞는 진술 통과 | 부호 틀린 진술 통과 | `est` 오차 | `gate` p\* |
|---|---|---|---|---|
| 모형과 같음 | 0.33 | 0.02 | 4.8° | 0.05 |
| 토크 × 1.25 (케이블의 옆 힘) | 0.38 | **0.17** | 15.2° | 0.25 |
| EI × 3 | 0.44 | **0.31** | 16.0° | 0.35 |
| EI ÷ 3 | 0.38 | **0.62** | 17.8° | 0.65 |

압력 효과(0.05–3 Nm)가 모형 오차보다 작다. 그래서 관문이 "모형 오차를 설명해 주는 진술"을 고른다. 관문은 모형 불일치에 대한 보정이나 견고성 검사 없이는 쓸 수 없다. CCPP의 창 검사에는 없던 실패 방식이다.

### 5.4 E4 k0를 데이터로 추정 — 모형이 맞으면 손해가 없고, 틀리면 맞는 진술도 빗나간다
- 압력 0 데이터에서 호스 길이를 맞추면, 모형이 맞을 때 결과가 §5.1과 같다(맞는 진술 `R2` 0.0–0.2°).
- 토크 × 1.25나 EI × 3이면 길이가 틀리게 맞춰진다. 그러면 맞는 진술도 `R2`로 4.4–5.5° 빗나간다.

### 5.5 E5 비대칭 비용 — 넘침 비용 c ≥ 3이면 `safe`가 대부분의 신뢰도에서 최선이다
손실 = 짧게 잡은 각 + c × 넘친 각.
- σ = 1 Nm, c = 3: p 0.3–0.9에서 모두 `safe`가 최선이다. c = 10이면 모든 p에서 `safe`가 최선이다.
- σ = 0.2 Nm: p ≤ 0.5에서는 `est`가, p ≥ 0.7에서는 `safe`가 최선이다(c = 1이고 p = 0.9면 `R2`).
- `safe`의 손익분기 p\*: c = 1에서 0.25, c = 3에서 0.1, c = 10에서 0.05.

## 6. 추가 (2026-11-12): 모형 불일치에 강한 관문
연구자 지시("불일치 관문 만들기"). 코드는 다음 세 개다. 탐색이며 사전 등록이 아니다.
- `analysis/robot_twin/hose_gate_mismatch.py`: 출력 `runs/hose_gate_mismatch.txt`, 20회 반복

### 6.0 요약과 결론
- **"압력 0에서 보정한 뒤 검사"하면 모형 계열 안의 불일치(토크 배율, EI)는 해결된다.** 부호가 틀린 진술의 통과율이 15–69%에서 0–6%로 내려간다(σ = 0.2 Nm).
- **계열 밖의 불일치(모양, MuJoCo 케이블)는 보정만으로 부족하다. 분산을 부풀려야 한다.** 압력 0 데이터에서 보정한 뒤 남은 잔차로 관문 문턱을 키우면, 부호 틀린 진술의 통과율이 1–4%가 된다. 대가로 맞는 진술의 통과율도 10–27%로 낮아져 이득이 줄어든다.
- **로봇 쪽에서는 여전히 `safe`(좁히는 진술만 받음)가 가장 튼튼하다.** 케이블 진실에서 오차 3.5–4.6°로, `R0`(8.6–8.8°)의 절반이다.
- 데이터만 쓰는 ε 추정은 계열 밖에서 12–14°로, `R0`보다 나쁘다.

### 6.1 관문
- `gate_nom`: 공칭 모형을 쓴다. 호스 길이만 압력 0 데이터로 맞춘다(§5 E4와 같다).
- `gate_cal`: 압력 0(ε = 0을 아는 조건)에서 보정한다.
  - 토크 = c1·A + c2·B. A는 느슨한 구간의 미는 힘 토크(EI당), B는 팽팽한 뒤의 토크다.
  - c1, c2와 길이(±5%)를 함께 맞춘 뒤 고정하고 ε_s를 검사한다.
  - **c2는 0.5–2배로 묶는다.** 묶지 않으면 "길이를 늘리고 팽팽한 뒤 강성을 키운" 해가 케이블의 딱딱한 벽에 똑같이 맞는다. 그러면 길이가 탐색 범위 끝으로 간다. 진단: 케이블 3칸에서 길이 비 1.03, k 오차 최대 +18°. 묶은 뒤에는 기하가 맞는 케이블 9칸에서 k 오차가 −3.0~+0.5°다.
- `gate_cal_infl`: `gate_cal`과 같다. 다만 분산을 max(σ², 창 각도에서의 압력 0 보정 잔차²)로 둔다.

### 6.2 진실 세계
- 계열 안: `exact`, `torque x1.25`, `EI x3`, `EI /3`
- 계열 밖:
  - `shape`: e_c × 2, α = 0
  - `cable`: MuJoCo 케이블, 예측 모형도 감김 항 없음. 기하는 맞는다.
  - `cable+wrap`: 같은 케이블, 예측 모형은 감김 항 0.06 m. 기하 불일치로 k가 2.5–20° 다르다.
- 모든 진실은 케이블 파일에 있는 9칸만 쓴다.

### 6.4 해석
- CCPP의 창 검사는 "모형이 맞다"는 전제를 숨기고 있었다. 압력 효과가 모형 오차보다 작은 곳에서는 그 전제가 깨진다. 그러면 관문이 모형 오차를 설명해 주는 틀린 진술을 받아들인다.
- 정답을 아는 조건(압력 0)에서 보정하는 것은 계열 안의 불일치에만 통한다. 계열 밖에서는 남은 잔차만큼 문턱을 키우는 것이 최소한의 보호다. 대신 검출력을 잃는다.
- 그래서 검사할 수 있는 부분이 약할 때 위험을 묶는 것은 비대칭 규칙(`safe`)이다. 이것이 로봇판의 주된 기여 후보다.

### 6.5 한계
- 이득 범위 0.5–2와 χ² 문턱 4는 임의값이다. 케이블 진실에서 c2가 상한 2에 붙는 칸이 있다(케이블의 벽이 모형보다 딱딱함).
- 케이블은 실제 호스가 아니다. 감김 항은 케이블 장면에 없다.
- 테스트(정답을 아는 입력): 계열 안 진실에서 보정이 c1 = 1.25·3·EI, c2 = 1.25를 정확히 복원한다. 상한을 넘는 이득은 상한으로 잘린다.
