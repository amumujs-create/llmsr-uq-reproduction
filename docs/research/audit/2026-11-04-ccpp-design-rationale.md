# CCPP 외삽 연구의 설계 근거와 가정 — 2026-11-04

상태: **설계 기록. 실험은 아직 이 설계대로 실행하지 않았다.**

근거 분석: [CCPP 외삽 방향 분석](2026-11-04-ccpp-direction-analysis.md) · [코드 검토와 연구 방향](2026-11-03-code-review-and-directions.md)

이 문서는 **왜 이렇게 설계했는지**와 **그 설계가 성립하려면 무엇이 참이어야 하는지**를 적는다. 가정마다 근거, 확인 방법, 틀렸을 때 무너지는 주장을 함께 둔다. 가정이 틀린 것으로 드러나면 해당 주장을 철회하고 이 문서를 고친다.

## 1. 연구 질문

> 학습 범위가 좁고 외삽 구간의 정답이 없을 때, 물리 지식으로 외삽 경로를 고정하는 것이 언제 데이터 적합보다 나은가? 그리고 그것을 시험 정답 없이 판단할 수 있는가?

## 2. 설계 결정과 그 이유

| # | 결정 | 이유 | 근거 |
|---|---|---|---|
| D1 | 실데이터는 CCPP를 쓴다 | 공개 실데이터이고 물리(가스터빈 출력 ∝ 공기 밀도)가 알려져 있다. 좁은 학습 창에서 데이터 적합이 크게 실패하고 물리 구조가 크게 개선한 기록이 있다 | prior_module `54992a5`: 먼 구간 RMSE 데이터 NN 56.8 대 물리 구조 6.9–10.0 MW |
| D2 | 학습 창은 **좁게, 출력 곡선의 끝에** 둔다 | 실제 공정은 좁은 운전 범위에서만 데이터가 쌓이는 경우가 많다. 좁은 창에서 데이터 기울기가 외삽 경로를 대표하지 못하는 상황이 연구 질문의 핵심이다 | 조건 맞춘 비교: 폭 2.5°C에서는 양방향 모두 물리식 우세 |
| D3 | **방향을 하나로 고르지 않는다.** 양 끝과 여러 폭·거리를 모두 보고한다 | 방향 선택 자체가 결과를 만든다는 비판을 막는다. 주장은 방향이 아니라 조건(창 폭, 국소 기울기의 대표성)이다 | 폭 5·10°C 저온→고온에서는 데이터 적합이 이겼다. 이 결과도 보고한다 |
| D4 | 물리 prior는 **기울기를 물리로 고정**한 비례식으로 시작한다 | AP/T를 회귀 변수로만 넣고 기울기를 데이터로 추정하면 이득이 없었다. 이득은 좌표가 아니라 고정된 기울기에서 왔다 | 고온→저온 폭 2.5: AP/T 적합 17.3, 비례식 5.5, 원 변수 적합 15.5 MW |
| D5 | **시뮬레이션으로 먼저 개발**하고 실데이터는 마지막에 쓴다 | 실데이터에서는 실패 원인(좌표, 기울기, 레짐, 잡음, 공변량 이동)을 분리할 수 없다. 시뮬레이터는 정답을 알고 원인을 하나씩 켜고 끌 수 있다 | 사용자 결정 (2026-11-03) |
| D6 | 시뮬레이터는 **CCPP 쌍둥이**로 만들고 prior보다 복잡하게 한다 | prior와 같은 식으로 만들면 “정답 식을 줬더니 맞혔다”가 되어 해석할 것이 없다 | llm_prior 합성 실험의 한계 기록 |
| D7 | 평가는 **외삽 거리 구간별**로 하고 구간별 행 수와 불확실성을 함께 보고한다 | 데이터가 가까운 구간에 몰려 있어 pooled 지표가 먼 구간의 오차를 가린다 | 정방향 시험 956행 중 34°C 이상 36행. 사용자 관찰 |
| D8 | 방법은 **시험 정답을 쓰지 않는다.** 선택·가중은 학습 데이터와 시험 입력 X만 쓴다 | 실제 배포 조건과 같아야 한다. 10/08 실험의 VAL 선택기는 가까운 VAL만 보고 8/8 틀렸다 | `54992a5`의 ObservedSelector 기록 |

## 3. 성립해야 하는 가정

| # | 가정 | 왜 필요한가 | 지금까지의 근거 | 확인 방법 | 틀리면 무너지는 주장 |
|---|---|---|---|---|---|
| A1 | 외삽 구간에서도 **같은 메커니즘이 이어진다** (새 레짐 없음) | 물리 비례식이 외삽 경로를 대표하려면 메커니즘이 같아야 한다 | 1°C 평균 출력이 4–34°C에서 끊김 없는 S자 곡선 | 시뮬레이터에 레짐 있음/없음 세계를 만들어 비교. 실데이터는 구간별 잔차 구조 확인 | “물리 prior가 먼 외삽을 개선한다” |
| A2 | 비례식은 국소적으로는 틀려도 **먼 거리의 평균 경로에 가깝다** | D4의 이득이 여기서 나온다 | 비례식 기울기 −1.4~−1.7, 실제 경로 평균 약 −2. 중간 구간 실제 −2.5는 재현 못 함 | 학습 창 위치·폭·거리 격자 전체에서 비례식 오차를 거리별로 측정 | “기울기 고정이 좁은 창에서 이긴다”의 일반성 |
| A3 | **S자 곡선의 양 끝이 평평한 것은 실제 물리 현상**이다 (측정·선별 착시가 아님) | 창 위치의 효과(D2)를 해석하려면 곡선 모양이 진짜여야 한다 | 국소 기울기 저온 끝 약 −1.0, 고온 끝 약 −0.4~−0.6. 끝 구간은 표본이 적음 | 끝 구간 기울기의 부트스트랩 구간. 쌍둥이 시뮬레이터에서 같은 모양이 물리로 재현되는지 | “창이 평평한 끝에 걸리면 데이터 기울기가 경로를 대표하지 못한다”는 설명 |
| A4 | **다른 입력(V, AP, RH)의 이동**이 방향 비교를 왜곡하지 않는다 | 방향 간 차이를 창 폭과 기울기 대표성으로 설명하려면 공변량 이동이 통제돼야 한다 | 폭 2.5°C에서 시험 V가 학습 V 범위를 벗어나는 비율: 저온→고온 59%, 고온→저온 9%. **아직 통제되지 않음** | V 범위를 맞춘 하위 표본으로 재비교. 시뮬레이터에서 V를 고정한 세계와 움직이는 세계 비교 | 방향·조건에 대한 설명 전체 |
| A5 | 학습 잔차 약 4.3 MW는 **줄일 수 없는 잡음**이다 (관측되지 않는 운전 상태) | 개선 상한을 계산하는 기준이다 | 여러 모형의 학습 잔차 SD 4.3–4.9 MW | 창별 잔차 SD 비교. 모델 오차와 잡음의 분리는 시뮬레이터에서 | 개선 여지(5–20%, 좁은 창에서는 그 이상) 추정 |
| A6 | **데이터 기울기의 불확실성**과 **데이터–물리 기울기 차이**는 시험 정답 없이 계산할 수 있고, 물리식이 이기는 조건을 예측한다 | 정답 없는 판단(D8)의 핵심이다 | 고온 좁은 창: 데이터 −0.26 대 물리 −1.42로 크게 다름 → 물리 우세. 저온 넓은 창: −2.31 대 −1.68로 비교적 가까움 → 데이터 우세. **사례 수가 적어 아직 가설** | 격자 전체에서 두 지표가 “어느 쪽이 이겼는가”를 얼마나 맞히는지(AUROC 등) | 연구의 주 기여 |
| A7 | 쌍둥이 시뮬레이터의 결론이 **실제 CCPP로 이어진다** | D5의 전제다 | 없음 | 시뮬레이터 지도에서 실제 CCPP 결과의 위치가 일관되는지 마지막에 확인 | 시뮬레이션 결과의 실제 적용 주장 |
| A8 | 닫힌형 선형 비교의 결론이 **NN 기반 구조에도 유효**하다 | 분석은 선형으로 했고 10/08 결과는 NN 구조다 | 10/08 AffineZ(NN head + 고정 기울기)도 같은 방향의 결과 | 같은 격자에서 NN 구조로 재확인 | 방법을 NN으로 확장할 때의 근거 |

## 4. 배제해야 할 대안 설명

| 대안 설명 | 현재 상태 | 배제 방법 |
|---|---|---|
| 방향 자체의 효과 | 조건 맞춘 비교로 대부분 설명됨 (좁은 창은 양방향 모두 물리식 우세) | 격자 전체 보고 |
| 학습 행 수 | 같은 행 수 비교에서도 차이 유지 | 행 수 축을 격자에 포함 |
| V 등 공변량의 범위 이탈 (A4) | **미통제** | V 범위 맞춤 재비교, 시뮬레이터 |
| 데이터 밀도에 의한 평가 착시 (D7) | 확인됨 | 거리 구간별 지표와 행 수, 구간별 불확실성 |
| 최적화·초기화 문제 | 닫힌형 비교에서는 해당 없음 | NN 단계에서 반복 seed와 동일 예산 |
| 시험 구간 정보 누설 | 판단용 분석에서 시험 정답을 사용함 | 방법 개발에는 사용 금지. CCPP는 개발용으로 취급 |

## 5. 사전에 고정할 실험 격자

결과를 보기 전에 아래를 고정하고 기록한다.

- 학습 창 위치: 저온 끝, 중간, 고온 끝
- 학습 창 폭: 2.5, 5, 10°C
- 학습 행 수: 창 폭별로 고정한 부분표본 크기와 반복 수
- 외삽 거리: 5, 10, 15, 20°C (2.5°C 폭 평가 구간)
- 비교군: 원 변수 선형, 물리 좌표 선형(기울기 추정), 비례식(기울기 고정), Ridge, MLP, Engression, XGBoost, persistence
- 지표: 거리 구간별 RMSE와 행 수, 부트스트랩 구간, 방법 간 paired 차이
- 정답 없는 판단 지표: 데이터 기울기의 표준오차, 데이터–물리 기울기 차이, 시험 입력의 공변량 이탈 정도

## 6. 이 문서를 고치는 규칙

- 가정이 확인되면 “지금까지의 근거”에 결과와 출처를 추가한다.
- 가정이 반증되면 해당 행에 반증 결과를 적고, “틀리면 무너지는 주장”을 결과 문서와 결정 기록에서 철회한다.
- 설계를 바꾸면 결정 표(§2)에 새 행을 추가하고 바꾼 이유를 적는다. 기존 행은 지우지 않는다.
