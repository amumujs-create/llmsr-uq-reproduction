## 1. 질문

데이터가 모르는 구간(꺾임이 창 밖)에서, **지금 고정한 조립 규칙**이 그 규칙을 만들 때 **보지 않은 답**으로도 이기는가.

앞의 두 실행은 같은 다섯 모델의 답에서 규칙을 만들고 쟀다. 이 등록이 독립 확증이 되는 이유는 둘이다: (a) **새 모델 네 개**, (b) 주 질문·장치별 질문(S0·S2)을 한 번도 묻지 않은 **새 세계 두 개**.

## 2. 고정하는 규칙 `HA_fb_gt`

커밋 71dee23의 코드 그대로다(`outside_fallback.fallback(…, mechs=("gt_limit",))`). 바꾸지 않는다.

1. `HA`(`assemble.assemble`): 장치별 질문(S2)의 답에서 경계를 만들고, 가스터빈 출력 제한은 민감도 관문(0.4–1.2 %/°C)을, 나머지 장치는 직접 질문(S0) 다수결과의 일치(3°C 이내)를 거친다.
2. 대체: S2 답의 과반이 "가스터빈 출력 제한에 도달한다"고 했는데 1의 결과에 아래쪽 경계가 없으면 "8°C 아래"를 넣는다. **다른 장치에는 대체를 적용하지 않는다.**
3. 창 검사 관문(`GUARD_MARGIN` 2.0) + blend 0.5.

이 규칙을 고른 근거와 그 약점: [`HA_fb` §9.4](ccpp-twin-outside-fallback.md)에서 보고용으로만 계산한 변형이고, 기존 다섯 모델의 답을 본 뒤 고른 것이다. 그래서 기존 다섯 모델의 수치는 이 등록의 판정에 쓰지 않는다.

## 4. 새 세계

쌍둥이 모듈은 [모양 수집 2단계 §2](ccpp-shape-elicitation-2.md)에서 이미 만들었다. 그때는 모양을 묻는 다른 질문만 했다. 주 질문(`QUESTION`)과 장치별 질문(`S2_QUESTION`)은 이 세계들에 대해 어떤 모델에도 묻지 않았다.

| 세계 | 장치 | 정답(평평 진술의 언어로) | 설명 |
|---|---|---|---|
| `chill` | 흡기 냉동기, 20°C 위에서 흡기를 20°C로 냉각 | "20°C 위 평평" | L1: 장치만. L2: 설정 온도 약 20°C |
| `gen_hot` | 공랭 발전기 고온 제한, 28°C 위에서 출력이 **더 가파르게** 떨어짐 | 평평 진술 없음(빈 진술) | L1: 장치만. L2: 28°C에서 316 MW, 1°C당 3 MW 감소 |

- 질문 문구는 기존과 글자 그대로 같다(`QUESTION`, `S2_QUESTION`). 설명은 `L0` + `L1_NEW`(+ `L2_GT` + `L2_NEW`)이며 2단계에서 쓴 문장 그대로다(결빙 방지 문장은 주 수집과 맞추기 위해 넣지 않는다).
- 표본: 직접 질문 20회(온도 0.7) + 1회(온도 0), 장치별 질문 10회 + 1회. 세계 2 × 수준 2 → 모델당 128회.
- `gen_hot`은 **범위 한계 과제**다. 우리 진술 언어는 "평평"뿐이라 이 세계에서 맞는 행동은 침묵이다. 모델이 "28°C 위"를 말하면 조립은 평평을 넣고 해를 끼친다.

## 5. 과제·비교군·지표

**주 과제 8개**(창·시험·δ·w·n·σ·반복은 [창 밖 구간 전용 §3](ccpp-twin-outside-regime.md)과 같다: δ ∈ {1, 2, 4}, w ∈ {5, 10}, n ∈ {50, 150, 500}, σ ∈ {2.15, 4.3, 8.6}, 반복 20; 과제당 1,080행):

- 꺾임 4개: `evap|hot`(24), `evap+cap_mild|hot`(24), `cap_strong|cold`(9), **`chill|hot`(20)**
- 꺾임 없음 4개: `base|hot`, `base|cold`, `cap_strong|hot`, `cap_mild|hot`

**범위 한계 과제 1개**: `gen_hot|hot`(k = 28). 주 판정에 넣지 않는다.

seed 접두 `outside3`.

| 비교군 | 정의 |
|---|---|
| `R0` | 창 OLS 외삽 |
| `ORACLE` | 정답 진술을 같은 기계로. `chill`은 "20°C 위", `gen_hot`은 빈 진술 |
| `D_real` | 모든 세계에 "8°C 아래 + 27°C 위" |
| `D_aware` | 설명에 장치가 있으면 그쪽 기본 위치(상한 8°C 아래; 증발 냉각기·냉동기·고온 제한 27°C 위) |
| `D_read` | `D_aware`에서, **설명에 숫자가 적혀 있으면 그 숫자**를 쓴다. L2 설명 기준: 증발 24°C, 냉동기 20°C, 고온 제한 28°C. 상한은 온도가 적혀 있지 않으므로 8°C 그대로. 꼼꼼히 읽는 사람의 규칙 |
| `P_side` | 외삽 쪽 가짜 경계 평균 |

지표는 앞과 같다: 행별 상대 RMSE(규칙/`R0`), 해 = > 1.10, 과제 평균을 같은 무게로 평균(**꺾임 평균** = 꺾임 4개, **전체 평균** = 주 과제 8개).

## 6. 예측과 판정

N = 판정 칸 수, N₁ = 그중 L1 칸, N₂ = L2 칸. "⅔ 이상" = ⌈2N/3⌉칸 이상.

| | 기준 |
|---|---|
| H0 전제 (LLM 무관, 1회) | `ORACLE` 꺾임 평균 < 0.75 **그리고** `D_real` 꺾임 없음 해 비율 ≥ 0.30 |
| H1 해 없음 | 주 과제 전체 행의 해 비율 ≤ 0.10인 칸이 N − 1 이상 |
| H2 선형보다 낫다 | 꺾임 평균 ≤ 0.95인 칸이 ⅔ 이상 |
| H3 세계를 모르는 고정값보다 낫다 | 전체 평균 < `D_real` 전체 평균인 칸이 ⅔ 이상 |
| H4 무작위 위치보다 낫다 | 꺾임 평균 < `P_side` 꺾임 평균인 칸이 ⅔ 이상 |
| H5 숫자가 없을 때 사람 기본값보다 낫다 | **L1 칸**에서 꺾임 평균 < `D_aware` 꺾임 평균인 칸이 ⌈2N₁/3⌉ 이상 |
| H6 숫자가 있을 때 사람 읽기에 뒤지지 않는다 | **L2 칸**에서 꺾임 평균 ≤ `D_read` 꺾임 평균 + 0.03인 칸이 ⌈2N₂/3⌉ 이상 |
| S 범위 한계 (보고, 주 판정 아님) | 예측: `gen_hot|hot`에서 해 비율 > 0.10인 칸이 절반 이상 |

**종합.** H0–H4 모두 성립 → "목표 주장 확증(1단계)". 여기에 H5·H6까지 성립 → "강한 주장 확증".

**계산 전 예상(정직하게).** H0 성립. H1·H3은 성립 가능성이 높다(대체가 출력 제한에만 걸린다). H2·H4는 새 모델이 증발·냉동기 위치를 말하느냐에 달렸다. H5는 `chill`에서 갈린다: 기본값 27°C는 시험 띠(22.5–25°C)에 닿지 않아 `D_aware`가 `R0`와 같아지므로, 모델이 L1에서 20°C 근처를 말하면 이긴다(2단계에서 기존 모델의 L1 `chill` 위치 정답률은 0.00–0.38이었다 → 낙관할 근거는 약하다). H6은 모델이 L2의 숫자를 그대로 읽으면 성립한다. S는 예측대로 해가 날 것으로 본다.

## 7. 미리 적는 해석

- **H0–H4 성립**: 목표 주장을 독립 자료로 확증. 원고에 "데이터가 모르는 구간에서 해 없이 데이터·세계를 모르는 기본값·무작위 위치를 이긴다"를 쓴다.
- **H5 불성립**: "숫자가 없으면 LLM 위치는 문헌 기본값보다 낫지 않다." 1단계 주장만.
- **H6 불성립**: 숫자가 적혀 있어도 조립이 그것을 잃는다 → 조립 단계의 손실로 보고.
- **H1 불성립**: 고정한 규칙이 새 모델에서 안전하지 않다. 목표 주장 불성립. 어느 장치·세계에서 해가 났는지 보고하고 규칙은 고치지 않는다.
- **H2 불성립(침묵)**: 새 모델도 말하지 않는다. "해 없음"까지만.
- **S에서 해가 없음**: 모델이 `gen_hot`에서 침묵했다는 뜻 — 좋은 소식이지만 주 판정에 넣지 않는다. **S에서 해가 큼**: 진술 언어(평평만)의 한계로 원고 한계 절에 쓴다.
- 판정 뒤의 다른 집계는 모두 "사후"로 표시한다.

## 9. 한계 (미리 적음)

- 규칙은 기존 다섯 모델의 답을 본 뒤 골랐다. 독립인 것은 새 모델의 답과 새 세계다. 세계 설명·질문 문구·쌍둥이는 같다.
- 꺾임 과제 4개 중 2개가 같은 24°C 증발 꺾임이다.
- `deepseek-r1d-32b`는 Qwen2.5 기반이라 기존 qwen3과 계열이 가깝다.
- 기본값 8·27°C는 실제 발전소 회귀에서 온 숫자다. `chill`에서 27°C가 시험 띠에 닿지 않는 것은 세계 설정의 결과이며, 이 때문에 H5가 LLM에 유리해질 수 있다. 그래서 숫자를 읽는 `D_read`와의 비교(H6)를 따로 둔다.
- `D_aware`·`D_read`는 사람이 설명을 읽고 정한 표다(§5). 사람 규칙의 상한이 아니라 한 가지 구현이다.
- 쌍둥이 한정. 실자료는 이 등록 밖이다.

**시점 정정(2026-11-12 00:55):** 이 절을 쓸 때 새 모델 답이 아직 없다고 알고 있었다. 실제로는 세 모델(Mistral Small 3.2, Phi-4, Granite 3.3)의 수집이 2026-11-11 20:46–21:07에 원격 저장소에 올라와 있었다. 이 절을 쓰는 동안 그 답은 이 컴퓨터로 받지 않았고 열어 보지 않았다. 이 절의 근거는 LLM 답과 무관한 잡음 없는 세계 값뿐이다. 채점(`outside_confirm.py`)은 아직 실행하지 않았다.

- 증발 냉각기는 24°C 중심, 폭 3°C의 완만한 켜짐(`evap_ramp_c`)이라 구간 안 기울기가 이미 휜다. δ = 1에서는 데이터만으로 레짐 효과의 절반가량을 잡는다.
- 출력 제한은 δ ≥ 2에서 사실상 깨끗하다.

### 11.7 사후 메모 (판정에 쓰지 않음)

- `chill` 침묵의 유력한 원인은 설계다. 분해 질문 S2에는 냉동기 항목이 없다(출력 제한, 방빙, 증발 냉각, 배기 제한뿐). 조립 규칙은 출력 제한이 아닌 부품을 S2와 S0가 같은 쪽, 가까운 위치로 일치할 때만 남긴다. 냉동기 20°C가 들어갈 S2 칸이 없으므로 S0가 20°C를 말해도 남지 않는다. 이 점은 §9 한계에 적지 않았고, 등록 때 놓친 것이다. S0 답이 실제로 20°C를 말했는지는 따로 세지 않았다.
- 따라서 H6 불성립의 일부는 모델이 아니라 질문과 조립의 구조에서 왔을 수 있다. 이것은 추정이며 확인하지 않았다.
